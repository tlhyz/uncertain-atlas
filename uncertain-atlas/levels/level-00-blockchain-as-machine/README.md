# Level 0 · 区块链作为一台机器

优先级：必学  
门禁：无（这是第一课）  
毕业后再开：Level 1 工程密码学

---

## 你学完应该能做什么

不看笔记，用自己的话讲清楚：

1. 一条链首先是一台**复制状态机**，不是一个「更快的数据库」。
2. 交易是「签名过的状态变更请求」，不是「转账按钮」。
3. 「我点了发送」「节点看见了」「打进某个块」「再也不大可能被撤」是四件不同的事。
4. 双花、假余额、假确认，分别破坏哪一层保证。
5. 为什么现在还不能为「不确定」挑选共识算法。

还不能做的事：

- 选择 UTXO 还是 Account
- 选择 PoW 还是 BFT
- 评价哪条公链更先进
- 开始写链的代码当主业

## 怎么学

1. 按编号读，一课一课来。
2. 读完用自己的话复述「核心问题」的答案，再做题。
3. 卡在术语时，先回到直觉段，不要去搜币圈解释。
4. 本 Level 几乎不要求看源码。源码入口是预告，不是作业。

## 本 Level 用到的最少词表

先混个脸熟。正式定义在各课里：

| 词 | 先记住的口语 |
|---|---|
| 状态 | 此刻大家都该承认的那本账 |
| 交易 | 我想改账的一张签名申请 |
| 区块 | 排好序的一批交易，加上证明「这批从哪来」的头 |
| 节点 | 保存并检查副本的一台机器 |
| 共识 | 让诚实副本不要各写各的 |
| 最终性 | 再改这笔已经非常难，或按规则不可能 |
| 双花 | 同一笔授权被当成两次有效花费 |
| 分叉 | 同一高度出现两个都像合法的历史 |
