# 边界（Boundaries）

建议档。糊边界 = 假学习。

---

## 五层保证（课程 L0.8）

| 层 | 本层保证 | 不得写成 |
|---|---|---|
| 协议 | 规范谓词：合法块 / 合法票 / Apply | 实现没崩 |
| 实现 | 编码、崩溃恢复、配额、平台宽度 | 协议已拒绝合法块 |
| 部署 | 检查点从哪来、是否开 UPnP、默认气限 | 全节点已验证 |
| 经济 | 罚没公式、解绑、激励 | 证据形状 = 已罚 |
| 密码 | 算法标签、ctx、OTS 不复用 | 「后量子所以更最终」 |

## ABCI 四门（若抄分离）

| 门 | 改什么 | 不是 |
|---|---|---|
| CheckTx | 本地池守卫 | 已进块 |
| PrepareProposal | 可改 raw 列表；可不确定 | PBS；已交差 |
| ProcessProposal | 不改列表；Accept/Reject | 块非法（REJECT = prevote nil） |
| FinalizeBlock + Commit | 才改提交状态 | 回了 AppHash = 本头已印 |

见不变量 33。v1 可以不启用 vote extension（不变量 34）。

## 产品句边界

允许：「高度 H 上，我们承认意图 T；依据对象是 Y。」  
禁止：「已经到了 / 不可逆」而未写 Y。  
Y 必须来自 `tracks/finality/` 已有行或一条写进规范的对象。

RPC 余额、钱包绿勾、付款 URI、签过的消息，都在 **A9 / 部署+实现**，不在协议最终性。
