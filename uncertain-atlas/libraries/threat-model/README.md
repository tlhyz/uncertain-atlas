# 「不确定」威胁模型（草稿）

对手与假设，不是功能列表。

## 对手

1. 能骗用户签字、做假 RPC 的网络对手。  
2. 能发垃圾交易打验签 CPU 的对手。  
3. 少于协议阈值的拜占庭验证者。  
4. 能造成长时间网络分区的对手。  
5. 能让节点断电、时钟漂移的部署对手。  
6. 长期的密码学对手：收集公钥，等待椭圆曲线作废。  
7. 持有升级钥匙或社会工程的治理对手。

## 不自动覆盖

- 用户自己把助记词发给钓鱼网站（用户层）。协议应不假装能救。  
- 「主网还在跑」不等于安全。

## 第一版结算机最怕（建议）

1. 假最终性文案导致商家放货。  
2. 无上限验签。  
3. 非规范编码分裂客户端。  
4. 升级后门。  
5. 冷账户无法迁移。
