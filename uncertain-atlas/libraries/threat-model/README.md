## 第一版结算机最怕（建议）

1. 假最终性文案导致商家放货。  
2. 无上限验签。  
3. 非规范编码分裂客户端。  
4. 升级后门。  
5. 冷账户无法迁移。  
6. 实现上限变成未写明共识（BIP 50 类）。

## 后量子特有

量子对手不自动获得验证者席位。他获得的是**伪造旧算法授权**的能力。  
BFT 的 2/3 算术仍在；被污染的是票与用户 tx 的字节。  
因此：用户签与投票签要分开记账（工程账本第 1–2 行）。
