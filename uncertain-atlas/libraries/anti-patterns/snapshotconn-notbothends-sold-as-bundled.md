# 反模式：把给人快照或给自己装回不是已经必须两头都做 not already both-ends / not already restored / not already and-or-done 正式三事（334 余量）说成已经必须两头都做 / 已经装完 / 已经两头都做了

**层次**：实现 / 文案。  
**分类**：推断（产品）+ 建议（产品）。  
**例**：[给人快照或给自己装回 not already both-ends ≠ bundled（334）](../../tracks/implementation/worked-example-snapshotconn-notbothends-vs-bundled.md)。

## 卖法

把用来给人快照 / 能给人 / 给人快照 写成已经必须两头都做 interchangeable / 已经 both-ends interchangeable / 已经必须给自己装交差 interchangeable / 334 snapshotconn bundled interchangeable / 33 four gates interchangeable / snapshotconn-sold-as-required interchangeable；把用来给自己装回 / 能装回 / 装回口 写成已经装完 interchangeable / 已经 restored interchangeable；把写了「和 / 或」 / 和或写法 / 两头写法 写成已经两头都做了 interchangeable / 已经 and-or-done interchangeable，或已经和 334 snapshotconn bundled / snapshotconn-sold-as-required interchangeable / 759 snapshotconn-notbothends interchangeable。

## 为什么错

官方把给人快照或给自己装回单句、already both-ends、already restored、already and-or-done 写成三件独立的实现事。把它们卖成 already both-ends interchangeable / already restored interchangeable / already and-or-done interchangeable，会把 not already both-ends、not already restored、not already and-or-done 三条路一起吞掉。

## 产品

**建议（产品，不是事实）**：不确定第一条结算机如果给人看给人快照或给自己装回不是已经必须两头都做 not already both-ends / not already restored / not already and-or-done 正式三事（334 余量），必须分开 not already both-ends、not already restored、not already and-or-done 三件事，不要和 334 / 33 / 321 / 758 / 760 糊成一句。
