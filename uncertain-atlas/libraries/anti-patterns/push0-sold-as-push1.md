# 反模式：把压零指令写成已经是带立即数的压 0

**标识：** `push0-sold-as-push1`
**等级：** 重要
**相关模式：** [`name-the-push0`](../design-patterns/name-the-push0.md)
**相关课文：** [L5.1](../../courses/level-05-ethereum/L05-M01-evm-and-gas.md)
**相关不变量：** 217、216、208、176

## 错误句

「多了一条压零指令，所以已经是带立即数再压一个零。」「规范写没有立即数，所以跳转目的分析已经改了。」「已经部署碰巧用了这个字节，所以分叉后还一样。」「EIP-3855 就是 EIP-5656 / 不变量 216。」

## 为什么错

官方页写：给 EVM 加一条把常数 0 压进栈的指令。今天可以用带立即数的压 0 做到，更贵，也多一个字节。本页没有立即数，官方写跳转目的分析不受影响。这是以前没有的新指令；已经部署、碰巧用了这个字节的合约，分叉后行为可能变。用程序计数或返回数据长度凑零，值可以随上下文变，不是已经是常数零。规范没有把本页写成已经是带立即数的压 0，也没有把没有立即数写成已经改了跳转分析，也没有把本页写成 5656 或数前导零。

看见压零指令不是已经是带立即数的压 0；看见没有立即数不是已经改了跳转目的分析；看见已经部署碰巧用了这个字节不是行为已经不变；EIP-3855 不是 EIP-5656 也不是不变量 216。

## 正确替代

[`name-the-push0`](../design-patterns/name-the-push0.md)。需要内存拷时用[不变量 216](../invariants/README.md)。需要数前导零时用[不变量 208](../invariants/README.md)。

## 会在哪炸

把专用压零当成带立即数的压 0，会把「印好的卡片」写成「旧两格已经删掉」。把没有立即数当成跳转分析已改，会把安全说明听成共识分析器已经换。把本页写成 5656 / 208，会把内存拷和数位操作码混进常数零。
