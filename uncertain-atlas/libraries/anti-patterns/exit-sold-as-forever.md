# 反模式：把签过的自愿退出写成已经永远有效

**标识：** `exit-sold-as-forever`
**等级：** 重要
**相关模式：** [`name-the-exit-domain`](../design-patterns/name-the-exit-domain.md)
**相关课文：** [L5.2](../../courses/level-05-ethereum/L05-M02-el-cl-finality.md)、[L1.2](../../courses/level-01-crypto/L01-M02-signatures.md)
**相关不变量：** 213、193、154、192

## 错误句

「看见签过的自愿退出，所以已经永远有效。」「域锁在某一次分叉，所以已经改了执行层。」「分叉两边都能重放，所以已经丢资金。」「用后继分叉域预签，所以本页之后仍然有效。」「EIP-7044 就是 EIP-7002 / 4895 / 7685。」

## 为什么错

官方页写：把自愿退出的签名域锁在某一次分叉上，好让签过的退出以后一直能用。当时进块只在两代升级里有效。本页只改共识层处理函数，不改执行层。官方写分叉两边能重放，没有资金风险，也不影响链的安全。已经用后继分叉域预签的纸条，本页之后不再被认成有效。规范没有把看见签过的退出写成已经永远有效，也没有把域锁写成已经改了执行层，也没有把两边能重放写成已经丢资金，也没有把本页写成 7002、4895 或 7685。

看见签过的自愿退出不是已经永远有效；看见域锁在某次分叉不是已经改了执行层；看见分叉两边都能重放不是已经丢资金；EIP-7044 不是 EIP-7002 也不是 EIP-4895 也不是 EIP-7685。

## 正确替代

[`name-the-exit-domain`](../design-patterns/name-the-exit-domain.md)。需要执行层退出请求时用[不变量 193](../invariants/README.md)。需要提款操作时用[不变量 154](../invariants/README.md)。需要请求总线时用[不变量 192](../invariants/README.md)。

## 会在哪炸

把预签当成已经永远有效，会把「印章钉死」写成「已经离职」。把域锁当成已经改了执行层，会把共识层处理函数和执行层请求糊成一句。把两边能重放当成已经丢钱，会漏掉官方写没有资金风险。把本页写成 7002 / 4895 / 7685，会把活动钥自愿退出、提款凭证请求、系统提款、总线混进一句。
