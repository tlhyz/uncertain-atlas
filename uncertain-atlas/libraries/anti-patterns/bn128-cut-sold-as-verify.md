# 反模式：把 bn128 预编译降价写成已经在验签

**标识：** `bn128-cut-sold-as-verify`
**等级：** 重要
**相关模式：** [`name-the-bn128-cut`](../design-patterns/name-the-bn128-cut.md)
**相关课文：** [L5.1](../../courses/level-05-ethereum/L05-M01-evm-and-gas.md)
**相关不变量：** 228、199、116、227

## 错误句

「bn128 加 / 乘 / 配对降价了，所以算法已经换过。」「便宜了，所以已经在验签。」「便宜了，所以隐私 / 扩容产品已经齐了。」「EIP-1108 就是 EIP-2537 / 不变量 199 / EIP-196 原文。」

## 为什么错

官方页写：椭圆曲线算术预编译当时被标价过高；给它们重新标价，会帮助一批隐私和扩容方案。2018 年客户端实现变快了，气价应当跟着下调。加、乘更新的是 196 的表，配对更新的是 197 的表。底层算法没有改，也不要求再部署新密码库。本页是给当时还在推进的通用曲线算术当即时补丁。更便宜可以用来拿计算换存储，也可以降低简短证明的验证费；这是动机，不是已经在验签，也不是这些产品已经上线。2537 是后来另一条曲线的算术预编译。

看见 bn128 预编译降价不是已经换了算法；看见更便宜不是已经在验签；看见本页不是已经是通用曲线算术；EIP-1108 不是 EIP-2537 也不是不变量 199，也不是 EIP-196/197 原文。

## 正确替代

[`name-the-bn128-cut`](../design-patterns/name-the-bn128-cut.md)。需要 BLS12 算术时用[不变量 199](../invariants/README.md)。需要子群谓词时用[不变量 116](../invariants/README.md)。需要模幂改价时用[不变量 227](../invariants/README.md)。

## 会在哪炸

把降价当成已经换算法，会把「水电费便宜了」听成「厨具已经换了」。把便宜当成已经在验签，会把动机听成验签指令已经上线。把 1108 当成 2537，会把 bn128 改价听成已经是另一条曲线。
