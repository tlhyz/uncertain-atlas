# 反模式：把 给人快照或给自己装回 not already must-do-both / not already restored / not already settled 正式三事（334 余量） 卖成 已经必须两头都做 / 已经装完 / 已经交差

**层次**：实现 / Snapshot Connection。  
**分类**：建议（产品）。  
**对应例**：[worked-example-snapshot-conn-notboth-vs-bundled.md](../../tracks/implementation/worked-example-snapshot-conn-notboth-vs-bundled.md)。

官方把四门里有 Snapshot Connection / 给人快照或给自己装回 / 应用选择不实现 三条核心句写成三件独立的实现事。把它们卖成已经必须两头都做 / 已经装完 / 已经交差，会把三条路一起吞掉。

## 产品

**建议（产品，不是事实）**：不确定第一条结算机如果给人看给人快照或给自己装回 正式三事（334 余量），必须分开 not already must-do-both、not already restored、not already settled 三件事，不要和 334 / 321 / 38 / 932 / 934 糊成一句。
