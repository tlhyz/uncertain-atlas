# 反模式：把内存拷贝指令写成已经是身份预编译

**标识：** `mcopy-sold-as-identity`
**等级：** 重要
**相关模式：** [`name-the-mcopy`](../design-patterns/name-the-mcopy.md)
**相关课文：** [L5.1](../../courses/level-05-ethereum/L05-M01-evm-and-gas.md)
**相关不变量：** 216、169、208、176

## 错误句

「多了一条内存拷贝指令，所以已经是身份预编译。」「规范写像用了中间缓冲，所以实现必须真分配一块。」「能重叠拷，所以已经是 calldata / 返回数据拷。」「EIP-5656 就是 EIP-2929 / 不变量 208。」

## 为什么错

官方页写：给 EVM 加一条专门拷内存区间的指令。更早用身份预编译靠 CALL 拷；官方仍写对 CALL 的开销让预编译不能当合理替代。专用指令只动内存，不是已经改了 CALL。拷的时候像用了中间缓冲，所以可以重叠；安全段写实现不要真用中间缓冲，那是拒绝服务面。栈顺序和 calldata / 返回数据拷一样，但本页拷的是内存到内存。规范没有把本页写成已经是身份预编译，也没有把「像缓冲」写成必须真分配，也没有把本页写成 2929 或数前导零。

看见内存拷贝指令不是已经是身份预编译；看见「像用了中间缓冲」不是已经必须真分配；看见能重叠拷不是已经是 calldata / 返回数据拷；EIP-5656 不是 EIP-2929 也不是不变量 208。

## 正确替代

[`name-the-mcopy`](../design-patterns/name-the-mcopy.md)。需要冷热时用[不变量 169](../invariants/README.md)。需要数前导零时用[不变量 208](../invariants/README.md)。

## 会在哪炸

把专用指令当成身份预编译，会把「桌子自己有尺子」写成「柜台已经关掉」。把「像缓冲」当成必须真分配，会把语义听成拒绝服务面。把本页写成 2929 / 208，会把冷热和新算术操作码混进内存拷。
