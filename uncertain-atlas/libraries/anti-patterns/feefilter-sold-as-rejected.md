# 反模式：看见跳过库存通告就当成已经拒进池 / 已经照做 / 已经是精确最低费率

**层次**：内存池 / 失败模式。  
**分类**：事实（对象）+ 推断（事故）。  
**来源**：[BIP-133](https://github.com/bitcoin/bips/blob/master/bip-0133.mediawiki)。  
**例**：[费率过滤 ≠ 已经拒进池](../../tracks/mempool/worked-example-feefilter-vs-rejected.md)。

## 塌法

1. 看见跳过了库存通告，就当成已经拒进池，或当成已经共识非法，或当成已经进不了块。
2. 看见发了费率过滤器，就当成对等节点已经照做，或当成协议版本够了就已经在发。
3. 看见布隆过了，就当成已经过了费率门，或当成内存池查询已经不受它管。
4. 看见费率过滤器，就当成已经是本节点精确的最低费率，或当成已经匿名。
5. 看见强制转发例外，就当成已经关掉全部策略。
6. 看见本页，就当成已经写了策略大类，或当成已经是替换信号。

## 为什么会出事

官方写：这条消息只让发送方少发一次库存通告。过滤是许可，不是必须。和布隆相加。广播最低费率会留下可用来认人的信息。本页不是策略拒绝已经等于共识非法。
