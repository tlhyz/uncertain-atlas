# 反模式：看见一份助记词就当成已经能备齐所有钱包 / 看见扩展根钥就当成已经能倒回助记词 / 看见派生出的熵就当成已经是目标种子

**层次**：应用 / 失败模式。  
**分类**：事实（对象）+ 推断（事故）。  
**来源**：[BIP-85](https://github.com/bitcoin/bips/blob/master/bip-0085.mediawiki)。  
**例**：[一份助记词 ≠ 已经能备齐所有钱包](../../tracks/implementation/worked-example-entropy-vs-seed.md)。

## 塌法

1. 看见一份助记词 / 看见一份种子备份，就当成已经能备齐所有钱包，或当成已经该在多个钱包之间共用。
2. 看见扩展根钥 / 看见派生出的子私钥，就当成已经能倒回助记词，或当成已经是那份熵。
3. 看见派生出的熵 / 看见截过的比特，就当成已经是目标钱包的种子，或当成已经是本钱包里的钥。
4. 看见给另一个应用用了，就当成已经是同一份钱包。
5. 看见本页熵，就当成已经是二进制种子。

## 为什么会出事

官方写：没法只备一份助记词就覆盖各种互不兼容的钱包；也不该共用种子。扩展根钥不能倒回助记词。子私钥还要再变成熵，才是目标标准的输入，不是已经长出那棵树。
