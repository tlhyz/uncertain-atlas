# 反模式：出站代理被写成 P2P 对等节点

> 真值：[SOCKS 代理](../../tracks/failure-museum/cve-2017-18350.md)、[不变式 54](../invariants/README.md)、[CVE-2017-18350](https://bitcoincore.org/en/2019/11/08/CVE-2017-18350/)。

## 一句话

看见节点配了 SOCKS / HTTP 出口，就写成「只是多一条出边」；或把代理握手溢出写成和互联网 P2P 接收分配同一句话。

## 正确写法

「出站代理是另一类信任对象。要打进这条溢出，节点必须先被配成使用该代理；明文网上的任意代理本身就可被截获。」
