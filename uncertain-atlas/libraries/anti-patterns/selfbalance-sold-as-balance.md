# 反模式：把本账户余额指令写成已经是 BALANCE

**标识：** `selfbalance-sold-as-balance`
**等级：** 重要
**相关模式：** [`name-the-selfbalance`](../design-patterns/name-the-selfbalance.md)
**相关课文：** [L5.1](../../courses/level-05-ethereum/L05-M01-evm-and-gas.md)
**相关不变量：** 229、169、101、221

## 错误句

「有了本账户余额指令，按地址查余额就已经一样便宜。」「给自己查余额，已经按本账户价扣。」「树依赖操作码涨价了，所以已经是本笔冷热 / 磁盘已经是常数时间。」「EIP-1884 就是 EIP-2929 / 不变量 169 / 不变量 101 / EIP-150。」

## 为什么错

官方页写：状态长大之后，若干操作码更吃资源，所以给读存储、按地址查余额、读代码哈希涨价。按地址查余额天生方差大：查自己本来便宜，查任意账户往往要碰树。事后看更该拆成两条。本页补一条本账户余额指令：不弹地址，压回当前地址余额。给自己走按地址那条，价仍按地址。官方预期以后还会再涨，除非先清状态。这不是 2929 的本笔冷热，也不是磁盘已经是常数时间，也不是 150 那一次已经永远够。

看见本账户余额指令不是已经是按地址查余额；看见给自己查余额不是已经按本账户价扣；看见树依赖涨价不是已经是本笔冷热，也不是已经是磁盘 O(1)；EIP-1884 不是 EIP-2929 也不是不变量 169，也不是不变量 101。

## 正确替代

[`name-the-selfbalance`](../design-patterns/name-the-selfbalance.md)。需要本笔冷热时用[不变量 169](../invariants/README.md)。需要气≠墙钟时用[不变量 101](../invariants/README.md)。需要代码哈希语义时用[不变量 221](../invariants/README.md)。

## 会在哪炸

把本账户快捷窗口当成按地址查自己已经便宜，会把「翻档案室」听成「看自己口袋」。把一次涨价当成 2929，会把整网统一价听成已经按本笔访问集合计价。把涨价当成磁盘已经是常数时间，会把补丁听成 101 已经修完。
