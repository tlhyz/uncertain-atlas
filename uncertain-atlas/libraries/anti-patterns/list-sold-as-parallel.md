# 反模式：把块级访问名单写成已经并行跑完

**标识：** `list-sold-as-parallel`
**等级：** 重要
**相关模式：** [`name-the-block-list`](../design-patterns/name-the-block-list.md)
**相关课文：** [L5.1](../../courses/level-05-ethereum/L05-M01-evm-and-gas.md)、[L6.4](../../courses/level-06-throughput/L06-M04-three-worldviews.md)
**相关不变量：** 212、168、143、122

## 错误句

「一块带着访问名单，所以交易已经并行跑完。」「名单是强制的，所以已经是 2930。」「看见事后状态差，所以已经可以不跑交易。」「EIP-7928 就是不变量 168 / 143 / 122。」

## 为什么错

官方页写：给一块加一份块级访问名单，记下真正碰到的账户和槽，以及执行后的值。2930 是可选的交易级名单，并不强制。本页把名单做到块这一层并且强制。2930 的项不得自动抄进本页。名单不在块体里。缺项或多出来的项让块非法。官方写本页能用来并行和不做执行就更新状态；看见本页不是这些已经发生。规范没有把看见名单写成已经并行跑完，也没有把强制写成已经是 2930，也没有把事后差写成已经不跑交易。

看见块级访问名单不是已经并行跑完；看见强制名单不是已经是 2930；看见事后状态差不是已经不跑交易；EIP-7928 不是不变量 168 也不是 143 也不是 122。

## 正确替代

[`name-the-block-list`](../design-patterns/name-the-block-list.md)。需要交易级可选名单时用[不变量 168](../invariants/README.md)。需要声明调度时用[不变量 143](../invariants/README.md)。需要乐观并行时用[不变量 122](../invariants/README.md)。

## 会在哪炸

把记录当成已经跑完，会把「列了房间」写成「已经并行开完门」。把强制当成 2930，会把块级和交易级糊成一句。把事后差当成已经不跑，会漏掉官方仍要硬分叉改结构和通道。把本页写成 168 / 143 / 122，会把计划访问、声明调度、STM 混进块级记录。
