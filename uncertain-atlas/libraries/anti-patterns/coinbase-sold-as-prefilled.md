# 反模式：把出块者开跑已热写成已经是 169 那几个预填

## 一句话

把发送者、收款方、预编译开跑已在集合写成出块者也已经在里面，或把出块者开跑已热写成已经访问过、已经付过钱。

## 看起来像什么

- 「开跑已热的那几个，出块者也算上了。」
- 「出块者一开始就热，等于已经读过。」
- 「出块者已热，小费已经到账。」
- 「3651 就是 2929。」

## 为什么错

[EIP-3651](https://eips.ethereum.org/EIPS/eip-3651) 写明：交易一开始，已访问地址还要放入出块者。2929 的预填是发送者、收款方和预编译，没有出块者。开跑已热不是已经访问过，也不是已经付过奖励或小费。规范编号 3651 不是 2929、2930 或 1559，也不是不变量 163。

## 正确分法

1. 先点名 169 那几个预填。
2. 再点名出块者有没有另补进开跑集合。
3. 再问这是冷热，还是已经访问过。
4. 最后才问钱有没有到，以及是不是另一条链的出块奖励。

## 和相邻坑的差别

- 和 [`first-access-sold-as-warm.md`](first-access-sold-as-warm.md) 不同：那一条把本笔第一次碰写成已经热。
- 和 [`listed-sold-as-accessed.md`](listed-sold-as-accessed.md) 不同：那一条把名单写成已经访问过。
- 和 [`basefee-sold-as-tip.md`](basefee-sold-as-tip.md) 不同：那一条把基础费写成已经给了出块者。
- 和 [`coinbase-sold-as-spendable.md`](coinbase-sold-as-spendable.md) 不同：那一条是 Bitcoin 出块奖励还要熟。
