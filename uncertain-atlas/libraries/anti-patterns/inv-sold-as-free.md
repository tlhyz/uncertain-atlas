# 反模式：库存消息被写成免费

> 真值：[三方向精读](../../tracks/network/worked-example-inventory-quotas.md)、[不变式 45](../invariants/README.md#45-库存宣布的三个方向必须各自有配额)。

## 一句话

看见 INV / GETDATA，就写成「只是告诉邻居有什么」，不指出入站宣布、入站索取、出站待宣布是三个队列。

## 正确写法

| 方向 | 能说的句子 |
|------|------------|
| 入站 INV | 「一条宣布触发的回复必须有界；对方拒收会钉发送缓冲」 |
| 入站 GETDATA | 「畸形索取不得让单连接死循环；其它连接仍应前进」 |
| 出站待宣布 | 「集合必须能丢掉过期对象并跟得上排空；只听不讲会放大」 |
