# 反模式：看见机会主义未认证加密就当成已经私人 / 已经认证 / 已经认不出 / 已经没有第 1 版

**层次**：网络 / 失败模式。  
**分类**：事实（对象）+ 推断（事故）。  
**来源**：[BIP-324](https://github.com/bitcoin/bips/blob/master/bip-0324.mediawiki)。  
**例**：[第 2 版传输 ≠ 已经私人](../../tracks/network/worked-example-v2-transport-vs-private.md)。

## 塌法

1. 看见线上在加密，就当成已经私人，或当成已经知道对面是谁。
2. 看见未认证，就当成已经没有隐私改进；或看见导出了会话标识，就当成已经对照过、已经认证。
3. 看见字节看起来随机，就当成防火墙已经认不出；或看见允许垃圾 / 诱饵，就当成已经塑过形。
4. 看见支持第 2 版，就当成第 1 版已经退役；或看见版本包，就当成后量子握手已经换完。
5. 看见传输在加密，就当成应用消息已经不再公开，或当成广播元数据已经藏住。
6. 看见本页，就当成已经写了 v2 失败后的 v1 重连，或当成已经写了发现记录。

## 为什么会出事

官方写：数据本身公开，协议没有密码学身份。未认证加密只逼被动偷听变成主动。流量分析仍可能认出第 2 版。入站第 1 版仍收。认证和后量子握手是以后的路。
