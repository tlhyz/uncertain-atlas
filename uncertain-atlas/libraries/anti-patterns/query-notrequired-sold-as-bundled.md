**层次**：实现 / 文案。  
**分类**：推断（产品）+ 建议（产品）。  
**例**：[实现了 Query not already required ≠ bundled（329）](../../tracks/implementation/worked-example-query-notrequired-vs-bundled.md)。

## 卖法

把实现了 Query / 规范写了 Query / 有 Query 写成已经是正常运转必须有 interchangeable / 已经 required interchangeable / 已经必须有交差 interchangeable / 329 query bundled interchangeable / 33 four gates interchangeable / query-sold-as-replicated interchangeable；把邻居过滤 / 按 ID IP 过滤 / 过滤查询 写成已经是邻居过滤交差 interchangeable / 已经 filter interchangeable；把默克尔证明 / 有 Proof / 证明回了 写成已经是默克尔证明交差 interchangeable / 已经 proof interchangeable，或已经和 329 query bundled / query-sold-as-replicated interchangeable / 745 query-notrequired interchangeable。

## 为什么错

官方把实现了 Query 单句、already required、already filter、already proof 写成三件独立的实现事。把它们卖成 already required interchangeable / already filter interchangeable / already proof interchangeable，会把 not already required、not already filter、not already proof 三条路一起吞掉。
