# 反模式：把 BIP-13 old-reject not already paid / not already 16 / not already settled 正式三事（297 余量） 写成已经 已经付过 / 已经走了 16 / 已经交差

**层次**：应用 / BIP-13 old-reject not already paid / not already 16 / not already settled 正式三事（297 余量）。  
**分类**：建议（产品）。  
**来源**：Bitcoin [BIP-13](https://github.com/bitcoin/bips/blob/master/bip-0013.mediawiki)（Deployed, Applications, Specification）。  
**对应**：[`../tracks/implementation/worked-example-p2sh13-notpaid-vs-bundled.md`](../tracks/implementation/worked-example-p2sh13-notpaid-vs-bundled.md)。

把 BIP-13 old-reject not already paid / not already 16 / not already settled 正式三事（297 余量） 写成已经 已经付过 / 已经走了 16 / 已经交差，就是本页。

**建议（产品，不是事实）**：不确定第一条结算机如果给人看旧软件报无效 正式三事（297 余量），必须分开 not already paid、not already 16、not already settled 三件事，不要和 297 / 174 / 181 / 1208 / 1210 糊成一句。

也不是：

- [p2sh13-not16-sold-as-bundled](p2sh13-not16-sold-as-bundled.md) 是本页这种地址仍未是 16 单句边界（1208 item 1），不是本页旧软件报无效仍未付过边界。
- [p2sh13-notwho-sold-as-bundled](p2sh13-notwho-sold-as-bundled.md) 是只有地址仍未知道付给谁单句边界（1210 item 3），不是本页旧软件报无效仍未付过边界。
