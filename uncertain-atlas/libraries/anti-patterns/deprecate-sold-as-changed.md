# 反模式：把弃用自毁写成已经改了行为

**标识：** `deprecate-sold-as-changed`
**等级：** 重要
**相关模式：** [`name-the-deprecation`](../design-patterns/name-the-deprecation.md)
**相关课文：** [L5.1](../../courses/level-05-ethereum/L05-M01-evm-and-gas.md)、[L2.2](../../courses/level-02-state/L02-M02-account.md)
**相关不变量：** 224、160、223、222

## 错误句

「自毁已弃用，所以共识行为已经改了。」「看见 6049，所以客户端已经改了。」「以后可能有破坏性改动，所以已经变了。」「EIP-6049 就是 EIP-6780 / 不变量 160 / 不变量 223。」

## 为什么错

官方页写：用劝阻使用、并警告以后可能改行为的方式弃用自毁指令。更新文档，警告不要再用。本页更新黄皮书里的非规范文字，对客户端不适用任何改动。怎么改的讨论还在进行；强烈共识是会改点什么。本页不带来安全考虑。规范没有把弃用写成已经改了共识，也没有把本页写成客户端硬分叉，也没有把本页写成 6780 或 3529。

看见弃用警告不是已经改了共识行为；看见本页不是已经改了客户端；看见「以后可能变」不是已经变了；EIP-6049 不是 EIP-6780 也不是不变量 160，也不是不变量 223。

## 正确替代

[`name-the-deprecation`](../design-patterns/name-the-deprecation.md)。需要后来自毁语义时用[不变量 160](../invariants/README.md)。需要自毁退款时用[不变量 223](../invariants/README.md)。

## 会在哪炸

把告示当成门已经拆了，会把「不要再用」写成「现在已经不能这样执行」。把 6049 当成 6780，会把文档警告听成以后只转余额。把元层页当成已经改了客户端，会把说明书听成硬分叉。
