# 模式：把布隆服务位三件事说成三个名字

**层次**：轻客户端 / 命名。  
**分类**：事实（官方拆法）+ 建议（产品）。  
**来源**：[BIP-111](https://github.com/bitcoin/bips/blob/master/bip-0111.mediawiki)。  
**例**：[布隆服务位 ≠ 已经退役](../../tracks/light-clients/worked-example-bloom-bit-vs-retired.md)。

## 三个名字

1. **显式宣布：** 旧协议默认人人都服；本页才让节点自己说。不是已经私人。
2. **能关掉：** 没开这一位就可以拒，过滤器命令应当断开。不是全网已经退役。
3. **旧版本兼容窗：** 版本够了仍可能继续服。不是已经在遵守。

## 为什么要分开叫

官方把「可以关掉布隆」写成一位服务位，同时又写旧节点仍可能继续服。把它们叫成一个「布隆已经退役」，会把客户端侧过滤、费率过滤器和有限历史服务位一起吞掉。

## 产品

**建议（产品，不是事实）**：不确定第一条结算机如果做连接过滤，先数清问的是这个节点宣不宣布、能不能关掉，还是全网已经退役，再决定要不要同一次发布。
