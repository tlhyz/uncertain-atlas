# 模式：把给人快照或给自己装回不是已经必须两头都做 not already both-ends / not already restored / not already and-or-done 正式三事（334 余量）说成三个名字

**层次**：实现 / 命名。  
**分类**：事实（官方拆法）+ 建议（产品）。  
**来源**：[Requirements for the Application](https://github.com/cometbft/cometbft/blob/main/spec/abci/abci++_app_requirements.md) Snapshot Connection。  
**例**：[给人快照或给自己装回 not already both-ends ≠ bundled（334）](../../tracks/implementation/worked-example-snapshotconn-notbothends-vs-bundled.md)。

## 三个名字

1. **用来给人快照 不是 already both-ends：** 看见用来给人快照 / 能给人 / 给人快照，不是已经必须两头都做 interchangeable / 已经必须给自己装交差 interchangeable，不是 334 snapshotconn bundled interchangeable / 33 four gates interchangeable / snapshotconn-sold-as-required interchangeable。

2. **用来给自己装回 不是 already restored：** 看见用来给自己装回 / 能装回 / 装回口，不是已经装完 interchangeable / 已经装回交差 interchangeable，不是 321 snapshotrestore interchangeable / 334 snapshotconn item 1 interchangeable。

3. **写了「和 / 或」 不是 already and-or-done：** 看见写了「和 / 或」 / 和或写法 / 两头写法，不是已经两头都做了 interchangeable / 已经和或交差 interchangeable，不是 321 snapshotrestore interchangeable / 334 snapshotconn item 3 interchangeable。

官方把给人快照或给自己装回单句、already both-ends、already restored、already and-or-done 写成三个名字。把它们叫成一个「看见给人快照或给自己装回就已经必须两头都做 interchangeable / 就已经装完 interchangeable / 就已经两头都做了 interchangeable」，会把 not already both-ends、not already restored、not already and-or-done 三条路一起吞掉。

## 产品

**建议（产品，不是事实）**：不确定第一条结算机如果给人看给人快照或给自己装回不是已经必须两头都做 not already both-ends / not already restored / not already and-or-done 正式三事（334 余量），先数清问的是用来给人快照 是不是 already both-ends / 334 / snapshotconn-sold-as-required，是不是用来给自己装回 是不是 already restored，还是写了「和 / 或」 是不是 already and-or-done，再决定要不要同一次发布。334 snapshotconn vs required bundled unbundling 在本页 item 2 续。
