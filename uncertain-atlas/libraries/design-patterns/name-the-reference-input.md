# 模式：eUTXO 必须先点名是引用还是花费

**问题：** 产品把「交易用到了这枚输出 / 脚本看见了 datum」写成已经解释了花费。用户把看听成花，或把引用听成已经过锁。  
**方案：** 每个 eUTXO 句先点名问的是花费输入、引用输入，还是花费条件。引用必须仍在 UTXO、不参与平衡、不过锁、通过后不删除。同一枚不得既花又引用。  
**适用：** Cardano CIP-31 / 任何「看输出上的数据但不消耗」的结算文案。  
**优点：** 用户能指出隔着玻璃看和借走不是同一盏灯。  
**缺点：** 句子变长；不能再用「用到了这枚 UTXO」交差。  
**项目：** CIP-31 Active；Conway 正式账本 `txins ∩ refInputs ≡ ∅`。  
**常见 bug：** 引用写成已经花费；看见 datum 写成已经过锁；同一枚既花又引用。  
**不确定：** 第一版可以不做 eUTXO / 引用输入。若做，必须写清看不是花。见 [工作实例](../../tracks/state-models/worked-example-refinput-vs-spent.md)。
