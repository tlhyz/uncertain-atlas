# 模式：地址必须先点名是串、校验灯还是链上输出

**问题：** 产品把「看见 Bech32」写成链上已经有这笔输出。用户把校验过听成程序已经上链，或把 173 听成 141 / 350。  
**方案：** 每个地址句先点名问的是给人看的串、串自己的校验，还是 UTXO 集里的输出。自动纠错不是已经改对。本页校验不是后继校验。  
**适用：** Bitcoin 原生见证地址文案 / 任何「收款写法 ≠ 账本对象」的结算产品。  
**优点：** 用户能指出门牌、校对章和登记簿不是同一盏灯。  
**缺点：** 句子变长；不能再用「支持 Bech32」交差。  
**项目：** BIP-173：Bech32 串 + 原生见证地址标准。  
**常见 bug：** 看见地址写成已有 UTXO；校验过写成已上链；173 写成 141 或 350。  
**不确定：** 若提供收款地址，必须写清地址是编码，不是账本对象。见 [工作实例](../../tracks/implementation/worked-example-address-vs-utxo.md)。
