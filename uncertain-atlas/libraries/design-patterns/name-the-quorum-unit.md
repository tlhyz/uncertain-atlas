# 模式：超多数必须点名单位是验证者还是质押

**问题：** 「2/3」下面叠着人数、投票权、质押、抽样委员会。产品却只说「过了三分之二」。  
**方案：** 每个超多数先点名集合，再点名单位。选举加权与当选后计票分开写。出块抽签的权重与最终投票的权重分开写。  
**适用：** NPoS / DPoS / 债券质押；任何把「谁进集合」和「进了以后一票多重」做成两段的结算文案。  
**优点：** 用户能指出自己等的是人数还是质押；不会把大户质押过半当成已经最终。  
**缺点：** 句子变长；不能再用「PoS 所以 ⅔ 质押」交差。  
**项目：** Polkadot NPoS（选举加权 + 共识等权）对照 Cosmos 债券质押（共识按质押）。  
**常见 bug：** 当选写成已经按质押计票；⅔ 质押写成 Polkadot 官方超多数；BABE 按质押抽槽写成 GRANDPA 也按质押；提名写成已经交出治理权。  
**不确定：** 可以参考「单位必须点名」；第一版若抄 CometBFT，单位写投票权，不要发明「所有 PoS 都按人数」。见 [工作实例](../../tracks/consensus/worked-example-npos-equal-weight.md)。
