# 模式：把内存池交接三件事说成三个名字

**层次**：共识 / 命名。  
**分类**：事实（官方拆法）+ 建议（产品）。  
**来源**：[Mempool](https://github.com/cometbft/cometbft/blob/main/spec/mempool/mempool.md)。  
**例**：[提案收了 ≠ 已经从池里删掉](../../tracks/mempool/worked-example-proposed-vs-removed.md)。

## 三个名字

1. **还在池里：** 看见提案收了交易不是已经从池里删掉。
2. **再验剩下的：** 看见本块已 commit 不是已经不用再验剩下的。
3. **曾经绿过：** 看见 CheckTx 过了不是已经进块，也不是已经永远有效。

## 为什么要分开叫

官方把「提案还没决定所以还不删」、commit 后按新状态再验、有效性可以随状态变红写成三件事。把它们叫成一个「看见提案收了就已经从池里拿走」，会把四门和先装证据一起吞掉。

## 产品

**建议（产品，不是事实）**：不确定第一条结算机如果给人看「已经进池」，先数清问的是还在池里、再验剩下的，还是曾经绿过，再决定要不要同一次发布。
