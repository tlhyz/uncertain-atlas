# 先给自愿退出的签名域起名（name-the-exit-domain）

> 类型：design pattern  
> 对读：不变量 213；C217；反模式 [`../anti-patterns/exit-sold-as-forever.md`](../anti-patterns/exit-sold-as-forever.md)；[`../../tracks/consensus/worked-example-exit-domain-vs-fork.md`](../../tracks/consensus/worked-example-exit-domain-vs-fork.md)。

设计或讲解「退出签一次就永远有效」时，先分开四个名字：

1. **签过的自愿退出** — 活动钥签的退出消息，不是已经永远有效，也不是已经退出。
2. **锁死的签名域** — 处理退出时按某一次分叉算域，不是已经改了执行层。
3. **分叉两边能重放** — 本页之后不再靠两代分叉隔开，不是已经丢资金。
4. **7044** — 把退出域锁死，不是 7002，也不是 4895。

四句对照：

- 看见的是签过的纸条，还是已经永远有效？
- 看见的是域锁，还是已经改了执行层？
- 看见的是两边能重放，还是已经丢资金？
- 这是 7044，还是已经是 7002 / 4895 / 7685？

不要和执行层退出请求≠已退出（不变量 193）、提款≠用户交易（不变量 154）、请求承诺≠已处理（不变量 192）糊成「退出已经办完」一句。
