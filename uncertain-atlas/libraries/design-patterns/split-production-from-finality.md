# 模式：出块与最终写成两条服务

**问题：** 纯 Nakamoto 总能出块，但规范链可能事后换掉；纯每高度 BFT 一卡住就什么都不出。产品却想同时说「一直在出」和「已经不可逆」。  
**方案：** 出块装置与最终装置并行、独立。出块必须接在已最终的链上；未最终段用另一把尺子（官方：最多主块，不是最长链）。最终对**链**投票，祖先一次敲定。  
**适用：** 需要在终局前做额外可用性 / 有效性检查；或想把活性与安全拆开运维。  
**优点：** 官方写：卡住终局时仍能出块；检查可以放在出块之后、终局之前。  
**缺点：** 用户看见两盏灯；explorer 绿不是最终；实现是两套服务，一个活着不等于另一个没停；双签谓词也要拆开。  
**项目：** Polkadot 中继 BABE + GRANDPA。Wiki 对照 Tendermint：同路径出一块终一块。BEEFY 是已最终块上的第三套桥 gadget，不要并进本模式。  
**常见 bug：** 出块写成最终；最长链写成 hybrid 尺子；BEEFY 写成已经解释 GRANDPA；与平行链 backed 糊成一句。  
**不确定：** 可以参考「两盏灯必须点名」；第一版保持同路径出块+终局。见 [工作实例](../../tracks/consensus/worked-example-babe-vs-grandpa.md)。
