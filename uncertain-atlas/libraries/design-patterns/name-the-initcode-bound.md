# 模式：创建必须先点名是 initcode、运行时代码还是已经占址

**问题：** 产品把「合约有大小限制」写成 initcode 已经受部署代码那道界管。用户把按字收费听成已经创建，或把 3860 听成 170 / 1014。  
**方案：** 每个创建句先点名问的是构造代码、存上链的运行时代码，还是已经占址。创建交易超界是整笔非法；指令超界是异常中止。分析费在跑之前扣。  
**适用：** EVM 创建文案 / 任何「构造代码 ≠ 运行时代码」的结算产品。  
**优点：** 用户能指出说明书、建成的房子和门牌不是同一盏灯。  
**缺点：** 句子变长；不能再用「合约有上限」交差。  
**项目：** EIP-3860：initcode 有自己的长度界和按字分析费。  
**常见 bug：** initcode 写成已经是 170；分析费写成已创建；3860 写成 1014。  
**不确定：** 若允许链上创建，必须分开 initcode 界和部署代码界。见 [工作实例](../../tracks/implementation/worked-example-initcode-vs-runtime.md)。
