# 模式：费用市场必须先点名是基础费、小费还是弹性上限

**问题：** 产品把「1559」写成已经解释了手续费。用户把基础费听成出块者进账，或把烧掉听成 MEV 已经解决。  
**方案：** 每个费用句先点名问的是协议烧掉的基础费、给打包人的小费，还是短期弹性上限。发送者付基础费+有效小费；出块者只留小费。`GASPRICE` 只报签名者付了多少。  
**适用：** Ethereum 执行气 1559 / 任何「烧掉网络费 + 另付小费」的结算文案。  
**优点：** 用户能指出路税、茶钱、临时加宽不是同一盏灯。  
**缺点：** 句子变长；不能再用「1559」交差。  
**项目：** EIP-1559：基础费烧掉；小费给打包人；弹性只应对瞬时拥堵。  
**常见 bug：** 基础费写成矿工收入；烧掉写成 MEV 已解决。  
**不确定：** 若做费用市场，必须写清两腿和弹性边界。见 [工作实例](../../tracks/mempool/worked-example-basefee-vs-tip.md)。
