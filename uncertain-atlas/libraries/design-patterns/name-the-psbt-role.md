# 模式：多方签名必须先点名是工作包、凑齐、抽出还是广播

**问题：** 产品把「支持 PSBT」写成已经能上链。用户把信封里的几张签听成已经寄出。  
**方案：** 每个签名句先点名问的是工作包、某一输入是否凑齐、抽出的网络序列化，还是已经广播。没齐不得抽出。不同笔不得合并。  
**适用：** Bitcoin 钱包文案 / 任何「传来传去签名再合成」的结算产品。  
**优点：** 用户能指出会签信封、签满的栏和出门的公函不是同一盏灯。  
**缺点：** 句子变长；不能再用「支持 PSBT」交差。  
**项目：** BIP-174：部分签名包是工作格式，不是网上那笔。  
**常见 bug：** 看见包写成已经广播；有签写成已经凑齐；174 写成 173。  
**不确定：** 第一版若做多方签名，必须分开工作包、凑齐、抽出、广播。见 [工作实例](../../tracks/implementation/worked-example-psbt-vs-broadcast.md)。
