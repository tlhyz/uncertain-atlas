# 模式：把 Homestead 四件事说成四个名字

**层次**：实现 / 命名。  
**分类**：事实（官方拆法）+ 建议（产品）。  
**来源**：[EIP-2](https://eips.ethereum.org/EIPS/eip-2)。  
**例**：[Homestead ≠ 已经做完](../../tracks/implementation/worked-example-homestead-vs-already-done.md)。

## 四个名字

1. **交易创建费**：比消息调用高；不是 `CREATE` 操作码费。
2. **交易高 `s`**：交易验证拒；不是预编译拒。
3. **创建失败**：付不起存代码的气就整笔失败；不是代码长度上限。
4. **难度均值**：朝均值收敛；不是已经取消炸弹。

## 为什么要分开叫

官方把四件事写进一次硬分叉，但每一件改的是不同旋钮。把它们叫成一个“Homestead 已经做完”，会把 `CREATE`、`ECRECOVER`、170、3860、161 和后来的炸弹推迟一起吞掉。

## 产品

**建议（产品，不是事实）**：不确定第一条结算机如果做硬分叉，先数清改了几件独立的事，再决定要不要同一次升级。
