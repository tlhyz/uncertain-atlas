# 先给 bn128 预编译降价起名（name-the-bn128-cut）

> 类型：design pattern  
> 对读：不变量 228；C232；反模式 [`../anti-patterns/bn128-cut-sold-as-verify.md`](../anti-patterns/bn128-cut-sold-as-verify.md)；[`../../tracks/implementation/worked-example-bn128-cut-vs-verify.md`](../../tracks/implementation/worked-example-bn128-cut-vs-verify.md)。

设计或讲解「配对终于便宜了」时，先分开四个名字：

1. **bn128 预编译降价** — 给已有的加、乘、配对改价，不是已经换了算法。
2. **更便宜** — 气价跟着当时已经够快的实现下调，不是已经在验签，也不是隐私 / 扩容产品已经齐。
3. **即时补丁** — 先压「密码太贵」，不是已经是通用曲线算术。
4. **1108** — 给 bn128 三条预编译改价，不是 2537，也不是 196/197 原文。

四句对照：

- 看见的是改价，还是算法已经换过？
- 看见的是更便宜，还是已经在验签？
- 看见的是即时补丁，还是通用曲线算术已经落地？
- 这是 1108，还是已经是 2537 / 199 / 196 原文？

不要和预编译算术≠已验 BLS（不变量 199）、子群过了≠在曲线上（不变量 116）、模幂重计价≠已加帽（不变量 227）糊成「配对已经齐了」一句。
