# 先给压零指令起名（name-the-push0）

> 类型：design pattern  
> 对读：不变量 217；C221；反模式 [`../anti-patterns/push0-sold-as-push1.md`](../anti-patterns/push0-sold-as-push1.md)；[`../../tracks/implementation/worked-example-push0-vs-push1.md`](../../tracks/implementation/worked-example-push0-vs-push1.md)。

设计或讲解「有压零所以已经不用带立即数」时，先分开四个名字：

1. **压零指令** — 把常数 0 压进栈，不是已经是带立即数的压 0。
2. **没有立即数** — 指令后面不跟要吃掉的数据字节，不是已经改了跳转目的分析。
3. **已经部署碰巧用了这个字节** — 旧码以前是别的意思，不是分叉后行为已经不变。
4. **3855** — 专用常数零，不是 5656，也不是数前导零。

四句对照：

- 看见的是压零指令，还是已经是带立即数的压 0？
- 看见的是没有立即数，还是已经改了跳转目的分析？
- 看见的是旧字节碰巧用了这个码，还是行为已经不变？
- 这是 3855，还是已经是 5656 / 208？

不要和内存拷≠身份预编译（不变量 216）、数前导零≠已更便宜 ZK（不变量 208）、initcode 超界≠部署代码超界（不变量 176）糊成「新操作码已经齐了」一句。
