**层次**：实现 / EIP-1344 config-chainid not already this-tx-155 / not already default-value / not already 161 正式三事（220 余量）。  
**分类**：建议（产品）。  
**来源**：Ethereum [EIP-1344](https://eips.ethereum.org/EIPS/eip-1344)（Final, Core, CHAINID opcode）。  
**对应**：[`../tracks/implementation/worked-example-chid-nottx-vs-bundled.md`](../tracks/implementation/worked-example-chid-nottx-vs-bundled.md)。

- **指令返回配置链号不是这笔已经带了 155 标识 不是这笔交易已经带了 EIP-155 标识：看见指令返回配置链号不是这笔已经带了 155 标识，不是这笔交易已经带了 EIP-155 标识 interchangeable / 1396 chid-nottx interchangeable。**
- **config chainId is not already this-tx 155 不是已经返回某个默认值：看见config chainId is not already this-tx 155，不是已经返回某个默认值 interchangeable / 1396 chid-nottx interchangeable。**
- **指令返回配置链号不是这笔已经带了 155 标识 不是已经是不变量 161：看见指令返回配置链号不是这笔已经带了 155 标识，不是已经是不变量 161 interchangeable / 1396 chid-nottx interchangeable。**
