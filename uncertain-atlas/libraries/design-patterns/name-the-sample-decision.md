# 模式：抽样决定必须点名是样本置信还是可转发证书

**问题：** 「BFT」下面叠着全员 QC、固定委员会超多数、反复再抽的连续置信。产品却只说「过了三分之二」。  
**方案：** 每个「已决定」先点名问的是全集证书、固定委员会，还是本节点连续 β 轮的样本 α。偏好与接受分开写。出块窗与决定分开写。  
**适用：** Snow 家族、任何「每轮只问一小撮」的结算文案。  
**优点：** 用户能指出别人能不能复验同一张证明；不会把 explorer 绿勾当成 QC。  
**缺点：** 句子变长；不能再用「也是 BFT」交差。  
**项目：** Avalanche Snowball / Snowman；官方对照 PBFT 确定最终 vs Snow 概率可调。  
**常见 bug：** 抽样 α 写成全集 +2/3；连续 β 写成 QC；出块窗写成已经决定；思想层无领袖写成产品没有 ProposerVM。  
**不确定：** 可以参考「决定必须点名对象」；第一版不要同时卖 QC 与抽样固化。见 [工作实例](../../tracks/consensus/worked-example-snow-sample-vs-qc.md)。
