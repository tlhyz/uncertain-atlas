# 模式：失败必须先点名是带回剩余气的回滚还是烧光剩余气

**问题：** 产品把「执行失败」写成已经把剩下的气烧光。用户把回滚听成非法指令，或把不够付回滚自己的费听成已经留下剩余气。  
**方案：** 每个失败句先点名问的是带回剩余气的回滚、烧光剩余气的失败，还是已经部署。创建里回滚是不部署。不够付自己的费按气耗尽。  
**适用：** EVM 失败文案 / 任何「停、撤状态、可带原因」的结算产品。  
**优点：** 用户能指出退工时的回滚、烧光工时的摔机和已经盖好的房子不是同一盏灯。  
**缺点：** 句子变长；不能再用「失败」交差。  
**项目：** EIP-140：回滚可以留下剩余气并带原因。  
**常见 bug：** 失败写成已经烧光；回滚写成非法指令；140 写成空账户 OOG。  
**不确定：** 第一版必须分开带回剩余气的回滚和烧光剩余气的失败。见 [工作实例](../../tracks/implementation/worked-example-revert-vs-invalid.md)。
