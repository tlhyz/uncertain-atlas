# 设计模式：先点名工作包是哪一版

## 一句话

看见部分签名包，先问：这一份是旧版那份固定未签交易，还是创建之后还能加栏的后继版。不要把看见后继包写成已经是旧包，也不要把能加栏写成已经能广播。

## 问题

`PSBT`、`v2`、`未签交易`、`已经能上链` 会被叠成一个词。BIP-370 故意拿掉全局未签交易，正是为了让创建之后还能加输入输出。

## 做法

1. 先写这是工作包，不是网上那笔。
2. 再写包版本是 0 还是后继版。
3. 再写包版本是不是已经被听成交易版本。
4. 最后才问：能不能再加栏、齐了没有、抽出来没有、广播了没有。

## 不要和谁弄混

- 不要和 [`name-the-psbt-role.md`](name-the-psbt-role.md) 弄混：那一页管的是看见包 ≠ 已经能广播；本页管的是后继包 ≠ 旧版固定未签交易。
- 不要和 [`name-the-address-object.md`](name-the-address-object.md) 弄混：那一页管的是收款写法。
- 不要和 [`name-the-replace-signal.md`](name-the-replace-signal.md) 弄混：那一页管的是替换信号。

## 对 Uncertain 的建议

第一版如果做后继工作包，先点名「包版本」和「交易版本」。不要默认看见 v2 就是旧那份，也不要把能加栏写成已经能上链。
