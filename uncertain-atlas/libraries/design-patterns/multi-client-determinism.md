# 模式：多客户端同一状态根

**问题：** 一个实现的 bug 变成全网「合法」错状态。  
**方案：** 至少两条独立实现；规范精确到可差分；同一块必须同根。  
**适用：** 结算主网；后量子编码/验签边界多的协议。  
**优点：** 实现保证可观测；单客户端灭绝风险下降。  
**缺点：** 规范税、升级协调、多样性在部署上可能是假的。  
**项目：** Ethereum 执行/共识多客户端。对照实现案：CVE-2021-39137（Geth 错根，当时其它客户端不受同一洞影响）。  
**常见 bug：** 测试绿了当规范对了；份额集中在一家；为防 malloc DoS 让共识缓冲别名。  
**不确定：** 强烈建议留下第二个实现的位置，即使第一版只写一个。
