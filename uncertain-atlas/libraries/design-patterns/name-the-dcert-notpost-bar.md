**分类**：建议（产品）。  
**来源**：Arbitrum [AnyTrust](https://docs.arbitrum.io/how-arbitrum-works/deep-dives/anytrust-protocol)（Data Availability Certificate；官方文档，不是冻结 Ethereum 规范）。

- **DACert不是全文已经贴上父链 不是已经贴上全文：看见DACert不是全文已经贴上父链，不是已经贴上全文 interchangeable / 1509 dcert-notpost interchangeable。**
- **a DACert is not already the full batch posted on the parent chain 不是已经是不变量 23：看见a DACert is not already the full batch posted on the parent chain，不是已经是不变量 23 interchangeable / 1509 dcert-notpost interchangeable。**
- **DACert不是全文已经贴上父链 不是已经 142 bundled：看见DACert不是全文已经贴上父链，不是已经 142 bundled interchangeable / 1509 dcert-notpost interchangeable。**

**建议（产品，不是事实）**：不确定第一条结算机如果给人看 AnyTrust DACert 正式三事（142 余量），必须分开 not already posted-full、not already rollup-da、not already committee-only 三件事。
