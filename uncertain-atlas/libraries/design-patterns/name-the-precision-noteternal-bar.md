# 模式：把用于 PBTS 不是已经是永恒常数 not already eternal-constant / not already bft-median / not already clock-adjust 正式三事（336 余量）说成三个名字

**层次**：实现 / 命名。  
**分类**：事实（官方拆法）+ 建议（产品）。  
**来源**：[Requirements for the Application](https://github.com/cometbft/cometbft/blob/main/spec/abci/abci++_app_requirements.md) List of Parameters / SynchronyParams.Precision / SynchronyParams.MessageDelay。  
**例**：[用于 PBTS not already eternal-constant ≠ bundled（336）](../../tracks/implementation/worked-example-precision-noteternal-vs-bundled.md)。

## 三个名字

1. **用于 PBTS 不是 already eternal-constant：** 看见用于 PBTS / 两把尺给 PBTS 用 / 写了 PBTS 用，不是已经是永恒常数 interchangeable / 已经抄成产品常数交差 interchangeable，不是 336 precision bundled interchangeable / 40 block-time interchangeable / precision-sold-as-msgdelay interchangeable。

2. **能出合法提案 不是 already bft-median：** 看见能出合法提案 / 仍能出合法提案 / 提案还能过，不是已经是 BFT Time 中位数 interchangeable / 已经是加权中位交差 interchangeable，不是 40 block-time interchangeable / 336 precision item 2 interchangeable。

3. **两把尺 不是 already clock-adjust：** 看见两把尺 / Precision 和 MessageDelay / 同步参数两栏，不是已经是调整钟 interchangeable / 已经调钟交差 interchangeable，不是 40 block-time interchangeable / 336 precision item 1 interchangeable。

官方把用于 PBTS 单句、already eternal-constant、already bft-median、already clock-adjust 写成三个名字。把它们叫成一个「看见用于 PBTS 就已经是永恒常数 interchangeable / 就已经是 BFT Time 中位数 interchangeable / 就已经是调整钟 interchangeable」，会把 not already eternal-constant、not already bft-median、not already clock-adjust 三条路一起吞掉。

## 产品

**建议（产品，不是事实）**：不确定第一条结算机如果给人看用于 PBTS 不是已经是永恒常数 not already eternal-constant / not already bft-median / not already clock-adjust 正式三事（336 余量），先数清问的是用于 PBTS 是不是 already eternal-constant / 336 / precision-sold-as-msgdelay，是不是能出合法提案 是不是 already bft-median，还是两把尺 是不是 already clock-adjust，再决定要不要同一次发布。336 precision vs msgdelay bundled unbundling 在本页 item 3 完成。
