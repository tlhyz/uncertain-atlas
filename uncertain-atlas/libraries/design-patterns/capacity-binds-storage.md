# 模式：容量绑定存储

**问题：** 一次手续费让任意状态永占全节点盘。  
**方案：** 原生额度同时是该对象的字节上限；占用解除才解锁额度。  
**适用：** 允许 `data` 进状态的结算/保管层。  
**优点：** 无自动清场日；占用可逆。  
**缺点：** 资本锁定；最小对象有地板；占用算法必须是共识。  
**项目：** Nervos CKB Cell `capacity`（RFC0002 / RFC0022）。  
**常见 bug：** 占用计算两客户端不一致；把 mempool 灰尘政策当成占用协议。  
**不确定：** 第一版可先禁止任意 data；一旦开放，此模式优先于「以后再收租」。见 L2.6。
