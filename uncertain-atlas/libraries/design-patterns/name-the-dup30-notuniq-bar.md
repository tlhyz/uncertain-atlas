# 模式：点名 dup30-notuniq 杠

**层次**：共识 / BIP-30 same-txid not already unique / not already same-outputs / not already settled 正式三事（257 余量）。  
**分类**：建议（产品）。  
**来源**：Bitcoin [BIP-30](https://github.com/bitcoin/bips/blob/master/bip-0030.mediawiki)（Deployed, Consensus soft fork）。  
**对应**：[`../tracks/consensus/worked-example-dup30-notuniq-vs-bundled.md`](../tracks/consensus/worked-example-dup30-notuniq-vs-bundled.md)。

- **同一交易标识 不是已经唯一：** 看见同一交易标识，不是已经唯一 interchangeable / 1226 dup30-notuniq interchangeable。
- **许多确认 不是已经不怕被覆盖：** 看见许多确认，不是已经不怕被覆盖 interchangeable / 1226 dup30-notuniq interchangeable。
- **同一标识 不是已经交差：** 看见同一标识，不是已经交差 interchangeable / 1226 dup30-notuniq interchangeable。

**建议（产品，不是事实）**：不确定第一条结算机如果给人看同一交易标识 正式三事（257 余量），必须分开 not already unique、not already same-outputs、not already settled 三件事。
