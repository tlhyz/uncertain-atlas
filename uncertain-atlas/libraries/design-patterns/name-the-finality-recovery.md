# 模式：终局恢复必须点名是 leak、slash 还是社会层

**问题：** 「好久没最终」下面叠着头还在走、紧急抽质押、可罚退出、两条链都盖了章、全校开会。产品却只说「PoS 不会停」或「不投票就罚」。  
**方案：** 终局推迟先点名头还在不在。恢复路径点名是 inactivity leak、slash，还是社会恢复。两边都 finalized 不得写成协议已经选出唯一链。  
**适用：** 检查点最终 + 活性杠杆；任何把「不能最终」做成用户可见状态的结算文案。  
**优点：** 用户能指出自己等的是检查点、抽质押，还是链下约定；交易所不会把终局推迟当成停机。  
**缺点：** 句子变长；不能再用「PoS 所以不会停」交差。  
**项目：** Ethereum Gasper inactivity leak；slash 三条可罚关系；官方双最终 / 对半分叉后的社会恢复。  
**常见 bug：** 终局推迟写成停链；leak 写成 slash；两边都最终写成已经唯一；与弱主观性或选举地板糊成一句。  
**不确定：** 可以参考「恢复路径必须点名」；第一版不要抄 epoch 个数或美元当证明。见 [工作实例](../../tracks/finality/worked-example-inactivity-leak.md)。
