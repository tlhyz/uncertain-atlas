# 模式：自毁必须先点名是同笔拆户还是以后只转余额

**问题：** 产品把「SELFDESTRUCT」写成账户已经拆掉。用户把后来转走的余额听成代码已经清，或把同笔创建仍能拆听成以后任意一笔还能拆。  
**方案：** 每个自毁句先点名问的是创建当笔的旧行为，还是以后只转余额、不删数据。自己当收款人时再点名烧不烧。  
**适用：** Ethereum Cancun 之后的 `SELFDESTRUCT` / 任何「账户自杀」结算文案。  
**优点：** 用户能指出搬家当天拆房和几年后只拿走现金不是同一盏灯。  
**缺点：** 句子变长；不能再用「自毁」交差。  
**项目：** EIP-6780：非创建当笔不删账户；同笔创建仍按旧行为。  
**常见 bug：** 后来的 `SELFDESTRUCT` 写成已经删户；自己收款写成已经烧掉。  
**不确定：** 第一版可以不上自毁。若做删除，必须写清是哪一种。见 [工作实例](../../tracks/state-models/worked-example-selfdestruct-vs-delete.md)。
