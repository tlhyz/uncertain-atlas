# 模式：把分叉标识三件事说成三个名字

**层次**：网络 / 命名。  
**分类**：事实（官方拆法）+ 建议（产品）。  
**来源**：[EIP-2124](https://eips.ethereum.org/EIPS/eip-2124)。  
**例**：[分叉标识 ≠ 已经同一条链](../../tracks/network/worked-example-forkid-vs-same-chain.md)。

## 三个名字

1. **创世 + 已应用分叉的摘要：** 用来尽早判断对等节点有没有用；不是已经同一条链。
2. **交叉核对：** 哈希相同还要看通告的下一分叉；子集 / 超集按还在同步来连；不是已经兼容，也不是已经陈旧。
3. **身份方案：** 不改共识，也不解决同一高度三向分叉；不是发现记录格式已经齐，也不是未来分叉清单已经齐。

## 为什么要分开叫

官方把概括、校验、范围写进一次网络身份，但每一件钉的是不同旋钮。把它们叫成一个「握手已经知道同一条链」或「已经改了共识」，会把向前兼容、历史窗、配置 RPC 和握手配额一起吞掉。

## 产品

**建议（产品，不是事实）**：不确定第一条结算机如果做网络身份，先数清问的是创世、已应用分叉、通告的下一次，还是已经改共识，再决定要不要同一次发布。
