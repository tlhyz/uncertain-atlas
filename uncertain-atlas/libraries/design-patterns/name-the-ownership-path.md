# 模式：所有权必须点名走哪条版本路径

**问题：** 「一个人的东西」下面叠着快路径、共识排序的单地址对象、以及谁都能引用的 shared。产品却只说「owned 所以快」。  
**方案：** 每个对象先点名所有权类型，再点名版本路径。引用 shared 必须另写授权。进共识块必须另写接受票。最终证明点名 certified effects 还是 certified checkpoint。  
**适用：** 对象模型、快路径广告、任何「无争用就不排队」的结算文案。  
**优点：** 用户能指出自己的币是快路径、party 还是 shared；不会把伸手黑板当成已授权。  
**缺点：** 句子变长；不能再用「Sui 绕过共识」交差。  
**项目：** Sui 官方所有权表 + Transaction Driver 提交路径。  
**常见 bug：** owned 写成快路径；引用 shared 写成已授权；进块写成已生效；客户端自己收齐验证者签写成现行必经。  
**不确定：** 可以参考「路径必须点名」；第一版不要同时卖三套「到了」。见 [工作实例](../../tracks/parallelism/worked-example-owned-vs-fastpath.md)。
