# 模式：奖励必须先点名能不能当输入

**问题：** 产品把「出块就发奖」写成已经能花。用户把工单听成到账，或把商家确认数听成奖励成熟窗。  
**方案：** 每个奖励句先点名问的是补贴有没有进块，还是已经过成熟窗、能当输入。进块不是已经能花。钱包列表不是已经成熟。  
**适用：** Bitcoin 出块奖励 / 任何「先记工钱、过观察期才能取」的结算文案。  
**优点：** 用户能指出工单和口袋不是同一盏灯。  
**缺点：** 句子变长；不能再用「出块即到账」交差。  
**项目：** Bitcoin 官方文档：coinbase UTXO 至少再过一段块才能当输入。  
**常见 bug：** 进块写成能花；钱包看见写成成熟。  
**不确定：** 若有出块奖励，必须另写成熟窗。见 [工作实例](../../tracks/economic/worked-example-coinbase-vs-mature.md)。
