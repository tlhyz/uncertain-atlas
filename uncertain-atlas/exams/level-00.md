## L00-M01-ledger-problem

### 题

1. 用自己的话解释：双花破坏的是「转账速度」，还是「公共事实」？
2. A 同时对 B 和 C 各转 8，而 A 只有 10。如果 B 和 C 各信各的，世界哪里坏了？
3. 「我钱包显示已发送」是否等于「账本已承认」？差在哪一步？
4. 中心化银行是如何回避本课这个问题的？它付出了什么代价？
5. 如果「不确定」把「广播成功」显示成「结算完成」，攻击者能怎么用？

## L00-M02-replicated-state-machine

### 题

1. 用 `S + T → S'` 讲一笔 10 转 4 的例子。
2. N1 先执行 T1 再执行 T2，N2 顺序相反。两边都觉得自己没算错，世界哪里坏了？
3. 共识和执行，谁负责「顺序」，谁负责「计算」？
4. 举一个会破坏确定性的实现错误（不要抄课文原句，换个例子）。
5. 「不确定」如果允许「节点按自己机器时间决定交易是否过期」，哪个保证会先裂开？

## L00-M03-identity-and-authority

### 题

1. 为什么说链验证的是授权，不是身份？
2. 私钥丢了和「忘记网站密码」差在哪里？
3. 盗贼没有破解哈希，只是偷到了钥匙。账本规则算被打破了吗？坏的是「数学被解了」，还是「钥匙保管」？
4. 为什么签名消息里必须绑上「哪条链、哪笔意图」？
5. 「不确定」如果现在只支持一种签名算法且无法升级，十年后最怕的是什么？

## L00-M04-transaction

### 题

1. 分别用一句话定义：有效、已打包、最终。
2. 为什么「刚才还能花」的交易，下一秒可能变成无效？
3. 账户 nonce 和 UTXO 花费，各自怎样防止重放？
4. 用户说「我交易失败了」，可能是 mempool 策略拒绝，而不是共识非法。为什么这件事情重要？
5. 如果「不确定」的验签比转账逻辑贵 100 倍，攻击者更可能灌验签垃圾，还是去找余额漏洞？为什么？

4. 把每笔交易都单独做一次全球共识，主要会炸什么资源？
5. 「不确定」若用后量子签名投每一个高度，块过大或过频分别会打到哪？

## L00-M06-agreement-problem

### 题

1. 用自己的话区分 safety 和 liveness。举一个保安全但停机的例子。
2. 为什么「过半数」在有说谎者时可能同时选出两个值？
3. Crash 和 Byzantine 差在哪？
4. Bitcoin 和 CometBFT 对「同一高度两个块」的态度，直觉上有什么不同？
5. 「不确定」若承诺「永远不停、也永远不重组」，你现在该产生什么怀疑？
