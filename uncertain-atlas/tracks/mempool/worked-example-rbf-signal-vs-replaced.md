# 工作实例：选择加入替换信号不是已经换掉

> **事实 / 推断 / 建议** 已分开。
> 对照：[L3.2](../../courses/level-03-bitcoin/L03-M02-fees-and-standardness.md)、[策略 ≠ 共识](worked-example-policy-vs-consensus.md)、[CSV ≠ 绝对锁](../state-models/worked-example-csv-vs-cltv.md)、[CLTV ≠ nLockTime 已锁](../state-models/worked-example-cltv-vs-nlocktime.md)。
> 主文献：[BIP-125](https://github.com/bitcoin/bips/blob/master/bip-0125.mediawiki) Opt-in Full Replace-by-Fee Signaling。官方 BIP。应用层，不是共识层。不另写 19 节。
> 本页钉 **选择加入替换信号 ≠ 已经换掉**、**nSequence 用来示意可替换 ≠ 已经是相对锁**、**子孙继承信号 ≠ 自己已经明示加入**、**钱包看见未确认 ≠ 已经当付款**。不抄终值常数 / 替换条数 / 费率例子。不写怎样替换或钉死。

## 1. 核心问题

阿比看见交易带了 RBF 标记，以为池里那笔已经换掉；或看见输入填了较低序列号，以为已经是 BIP-68 相对锁；或看见钱包列出未确认入账，以为已经当付款。

官方句（事实）：

- BIP-125 层是 **Applications**，不是 Consensus。这是选择加入的全额按费替换**示意策略**。
- 花费者可以给交易加一个信号，表示自己以后想能替换。节点**可以**允许带该信号的交易在自己的 mempool 里被替换。收款方**可以**选择在确认之前不当付款，以免花费者用允许的替换骗自己。
- 没有该信号的交易，节点和收款方可以继续按以前的方式对待。
- 两种示意：显式——任一输入的序列号低于官方写明的终值附近；继承——自己没显式示意，但某个未确认祖先示意了，则在本策略下也可替换。
- 官方写：实际替换可能不可靠，直到足够节点升级提供转发路径，并且足够算力升级愿意挖替换。
- 官方写：与共识 locktime、BIP-68、BIP-112 **没有已知的麻烦互动**。同一字段，三种对象。
- 规范**没有**把「带了信号」写成已经换掉，也没有把较低序列号写成已经是相对锁，也没有把未确认入账写成已经当付款。

信号、替换发生、共识锁，是三件事。

---

## 2. 直觉（ELI15）

信封角上盖「可改址」，邮局**可以**收下改址条。  
盖了章，不等于改址条已经生效，也不等于信已经送到新地址。  
改址章也不是门上那把按「货上架几天」才开的锁。

---

## 3. 对象

| 名字 | 是什么 | 不是什么 |
|---|---|---|
| 显式 RBF 信号 | 策略：花费者示意允许替换 | 已经换掉；已经是共识相对锁 |
| 继承信号 | 未确认祖先还在示意 | 子孙自己已经明示加入 |
| 节点可以替换 | 本节点 mempool 策略 | 全网已经换；块里已经非法 |
| 收款方可以等确认 | 应用层谨慎 | 协议已经禁止未确认当付款 |

---

## 4. 最小案例

一条 Bitcoin 要对齐「这一口气替换示意是哪一盏灯」。

1. 交易带了选择加入信号。规范：节点可以允许替换。不是已经换掉。
2. 子孙没写信号，祖先未确认且示意了。规范：本策略下可继承。不是子孙自己已经明示。
3. 输入序列号较低。有人听成 BIP-68（不变量 165）。官方：与相对锁兼容，不是同一对象。
4. 同一序列号终值，有人听成 CLTV 的 final（不变量 164）。本页是应用层示意，不是脚本时间锁。
5. 有人把这听成策略就是共识（不变量 144）。本页是策略里的一种信号，不是块内交易已经非法。
6. 钱包列出未确认入账。官方：收款方可以等确认再当付款。看见不是已经到账。
7. 发出替换之后邻居还没升级。官方：实际替换可能不可靠。发出不是全网已经换。

「带了 RBF 所以已经换掉 / 较低序列号所以已经是相对锁 / 未确认所以已经当付款」是假学习。

## 5. 五层

| 层 | 本页 |
|---|---|
| 密码学 | 无新原语 |
| 协议 | 必须点名问的是示意、本节点替换，还是共识锁 |

| 部署 | 转发路径和算力升级不够，替换可能到不了矿工 |

## 6. 和另外几句不是同一句

1. **策略 ≠ 共识**（不变量 144）：大类。本页是选择加入信号这一盏灯。
2. **CSV ≠ 绝对锁**（不变量 165）：nSequence 的共识年龄。本页是应用层示意。
3. **CLTV ≠ nLockTime 已锁**（不变量 164）：终值关掉绝对锁。本页不是脚本锁。
4. **进 mempool ≠ 已经进块**（不变量 144）：本页再拆：带信号 ≠ 池里已经换。
5. **6 确认 ≠ 协议最终**（L3.1）：商家政策。本页是未确认要不要当付款。

不要抄终值常数 / 替换条数 / 最低中继费率例子。不要写怎样构造替换、怎样钉死、怎样挤掉商家看见的那笔。不编博物馆页。不另写 19 节。full-RBF 默认、package relay、cluster 线性化是另一对象。
