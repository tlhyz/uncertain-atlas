## 1. 核心问题

阿比看见委托调用，以为已经是 CALLCODE；或看见发送者和附带值会传下去，以为已经是普通 CALL；或看见官方写可以把另一地址当可变代码源，以为 7702 已经齐了；或看见能把发送者塞进调用数据，以为本页没有新语义。

官方句（事实）：

- EIP-7：新加一条委托调用，想法上像 CALLCODE，但把**父作用域**的发送者和附带值传到子作用域。看见委托调用，不是已经是 CALLCODE。
- 官方写：子环境里的调用者与附带值，和父环境里的一模一样。看见能读到同一发送者，不是已经是普通 CALL（普通 CALL 换发送者）。
- 官方写：这样合约更容易把另一地址存成可变代码源，并把调用穿过去；子代码几乎在同一环境里跑，只是气更少、调用栈更深。看见能穿过去，不是可变代码源产品已经上线，也不是已经是 7702。
- 官方写：被这样叫到的子函数现在可以自由引用发送者和附带值。看见能引用，不是已经同时能当委托用和直接用。
- 官方写：也可以把发送者塞进调用数据来复刻这件事。那样代码必须专门为委托编译，不能同时在委托语境和直接语境里用。看见能塞进调用数据，不是已经是本页。
- 官方写：不另给基础津贴；给子执行的气就是总数。像 CALLCODE 一样，不会因此创建账户。看见本页，不是已经是普通 CALL 那笔津贴，也不是已经会创建账户。
- 官方写：调用深度上限照旧。看见本页，不是深度上限已经取消。
- 规范**没有**把委托调用写成已经是 CALLCODE，也没有把传到子作用域写成已经是普通 CALL，也没有把可变代码源写成已经是 7702，也没有把能塞进调用数据写成已经是本页。

委托调用、CALLCODE、普通 CALL / 7702、调用数据复刻，是四件事。

## 2. 直觉（ELI15）

柜台把「谁来的、带了多少钱」原封不动交给后厨，不是已经换成后厨自己当来客。  
后厨用的还是前台那本账，不是已经新开一户。  
说明书上写「以后可以换一块后厨牌子」，不是换牌子的产品已经上线。  
把来客名字抄在菜单边上，不是柜台已经替你传了名字。

## 3. 对象

| 名字 | 是什么 | 不是什么 |
|---|---|---|
| 委托调用 | 跑目标代码，发送者与附带值和父作用域相同 | 已经是 CALLCODE |
| CALLCODE | 想法上的近亲，不传父作用域的发送者与附带值 | 已经是委托调用 |
| 可变代码源动机 | 把另一地址当代码、把调用穿过去 | 已经是 7702；升级产品已上线 |
| 7 | Homestead 新加委托调用 | 已经是普通 CALL；已经能靠调用数据复刻 |

## 4. 最小案例

一条 Ethereum 要对齐「这一口气委托调用在管什么」。

1. 看见委托调用。规范：像 CALLCODE，但传父作用域的发送者与附带值。不是已经是 CALLCODE。
2. 看见子环境里的调用者。规范：和父环境一模一样。不是已经是普通 CALL。
3. 看见官方写可变代码源。规范：这是动机。不是 7702 已经齐。
4. 看见能把发送者塞进调用数据。规范：那样不能同时当委托和直接用。不是已经是本页。
5. 看见不另给基础津贴、不会因此创建账户。规范：像 CALLCODE。不是已经是普通 CALL。
6. 有人把这听成不变量 119。那是有状态预编译的信任模型。本页是协议里这条调用。
7. 有人把这听成不变量 190。那是外部账户写委托指示。本页是一帧里的调用。
8. 有人把这听成不变量 178。那是静态帧。本页不管静态旗。
9. 有人把操作码号、操作数表或分叉块号抄进不确定。规范：数字是尺子，不是产品常量。

「7 = 已经是 CALLCODE / 传到子作用域 = 已经是普通 CALL / 可变代码源 = 已经是 7702 / 能塞进调用数据 = 已经是本页」是假学习。

## 5. 五层

| 层 | 本页 |
|---|---|
| 密码学 | 无新原语 |
| 协议 | 必须点名问的是委托调用、CALLCODE、普通 CALL / 7702，还是调用数据复刻 |
| 实现 | 子环境里的调用者与附带值和父环境相同；深度上限照旧 |
| 部署 | Homestead 才有；看见本页不是旧 CALLCODE 已经消失 |
| 经济 | 不另给基础津贴；看见本页不是计量墙已经取消 |

**推断：** 产品句若只写「终于能做库了」，读者会把 CALLCODE 听成已经齐，或把可变代码源听成 7702 已经上线。  
**建议：** 第一版可以不上委托调用。若对照，必须分开委托调用、CALLCODE、普通 CALL / 7702、调用数据复刻。不要发明「看见 7 就已经是 CALLCODE」。不要抄操作码号。不要写怎样做可变代码源或怎样拆代码绕过计量墙。

## 6. 和另外几句不是同一句

1. **正确兑现委托 ≠ 预编译信任已改**（不变量 119）：那是有状态预编译的旧假设。本页是协议里这条调用本身。
2. **授权名单 ≠ 已委托**（不变量 190）：7702 是外部账户写持久指示。本页是一帧里的调用。
3. **静态帧 ≠ view**（不变量 178）：214 管静态旗；CALLCODE 带值官方不算改状态。本页不管静态旗。
4. **返回缓冲 ≠ 已是内存**（不变量 232）：211 管返回数据放哪。本页管发送者传到哪。

不要抄操作码号、操作数表、分叉块号、深度上限数字。不要写怎样做可变代码源、怎样拆代码绕过计量墙、怎样靠调用数据复刻发送者。不编博物馆页。不另写 19 节。不转规范代码。CALLCODE 原文、7702 持久委托、静态帧、有状态预编译信任是另一对象。弃用 CALLCODE 的后来提案标成另一对象。
