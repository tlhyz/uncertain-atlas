## 1. 核心问题

阿比看见多了一条「读本账户余额」的指令，以为按地址查余额已经一样便宜；或看见给自己查余额，以为已经按本账户价扣；或看见树依赖的读操作涨价，以为已经是本笔冷热，或磁盘已经是常数时间；或看见规范编号 1884，以为就是 2929，或已经是 150 那一次涨价永远够了。

官方句（事实）：

- EIP-1884：以太坊状态长大之后，若干操作码此刻比从前更吃资源。本页要给这些操作码涨价，好让气的支出和资源消耗更对齐。看见涨价，不是磁盘已经是常数时间。
- 官方写：价和资源（CPU、内存等）不对齐，有几处坏处：对手可以往块里塞标价过低的操作，拉长处理时间；标价过低也会让块气限看起来齐、实际有的块很快、有的块很慢。看见涨价，不是块气限已经等于稳定墙钟。
- 官方写：操作对齐之后，才更能把块气限抬高，并让处理时间更稳。看见本页，不是块气限已经抬过，也不是处理时间已经稳了。
- 官方写：读存储、按地址查余额、读代码哈希，这几条都涨价。读代码哈希当初按「和按地址查余额一样要查账户」来定价；余额涨了，它也跟着涨。看见本页，不是已经改了代码哈希的语义。
- 官方写：按地址查余额天生方差大：常被用来查「自己」，这件事本来便宜；也可以拿去查任意账户，往往要碰树、碰盘。事后看，更该拆成两条：按地址查、查本账户，两套价。看见本页，不是按地址查自己已经按本账户价扣。
- 官方写：本页扩展操作码集合，加入一条本账户余额指令：不从栈上弹地址，把当前地址的余额压回去。看见本账户余额指令，不是已经是按地址查余额。
- 官方写：它比若干「更快一档」的读数指令稍贵一档，因为执行引擎仍要查（可能已缓存的）树；余额也不像气价或时间戳那样在执行当中不变，所以多一点固有开销。看见本账户余额指令，不是已经是常数上下文。
- 官方写：读存储在更早一次涨价之后，处理时间先掉下去，后来又爬回甚至超过涨价前。官方预期以后还会再涨，除非先做清状态。看见本页，不是 150 那一次已经永远够，也不是以后不用再涨。
- 官方写：这是硬分叉。若干调用会更贵。默认函数若碰存储，有时会超过调用里那笔最小可用气。假定固定气价的合约可能不再能跑。这类操作以前已经涨过，历史上就有「气价可能变」的先例。看见涨价，不是津贴帧已经永远够用。
- 官方写：本账户余额指令若定义成「按地址查余额、只是不从栈上弹地址」，没有特殊边角；按地址查余额本身已经定义清楚。看见本账户余额指令，不是已经改了余额语义。
- 规范**没有**把本账户余额指令写成已经是按地址查余额，也没有把给自己查余额写成已经按本账户价扣，也没有把本页写成 2929 或写成磁盘已经是常数时间，也没有把本页写成 150 已经永远够。

本账户余额指令、按地址查余额、本笔冷热、磁盘已经是常数时间，是四件事。

## 2. 直觉（ELI15）

查自己口袋里有多少钱，和按门牌去档案室翻别人的账，不该同一价。  
本页补了一条「只查自己」的快捷窗口，并把翻档案室的几条操作涨价。  
涨价不是档案室已经变成一伸手就拿到，也不是已经给每个地址发了「本笔来过」的热通行证。

## 4. 最小案例

一条 Ethereum 要对齐「这一口气余额和状态读在管什么」。

1. 看见本账户余额指令。规范：不弹地址，压回当前地址余额。不是已经是按地址查余额。
2. 看见给自己查余额。规范：按地址那条仍按地址价。不是已经按本账户价扣。
3. 看见读存储 / 按地址查余额 / 读代码哈希涨价。规范：状态长大了，这几条更吃资源。不是磁盘已经是常数时间。
4. 看见官方写以后可能再涨。规范：除非先清状态。不是 150 已经永远够。
5. 看见官方写默认函数可能超过那笔最小可用气。规范：气价可能变。不是津贴帧已经永远够用。
6. 有人把这听成不变量 169。那是本笔冷热。本页是整网统一涨价，外加一条本账户快捷窗口。
7. 有人把这听成不变量 101。那是气不是墙钟。本页承认还会再涨，正说明涨价不是已经等于时间。
8. 有人把这听成不变量 221。那是代码哈希不是已经看见代码。本页只让代码哈希跟着余额一起涨价，不改语义。
9. 有人把操作码号、新旧气价或津贴数字抄进不确定。规范：数字是尺子，不是产品常量。

「1884 = 已经是 BALANCE / 查自己 = 已经便宜 / 涨价 = 已经是 2929 / 涨价 = 磁盘已经 O(1) / 1884 = 150」是假学习。

## 6. 和另外几句不是同一句

1. **本笔第一次碰 ≠ 已经热**（不变量 169）：2929 是本笔访问集合。本页是整网统一涨价，外加本账户快捷窗口。
2. **气 ≠ 墙钟**（不变量 101）：状态访问的常数气不是磁盘已是 O(1)。本页的涨价正是那句话的一次历史补丁，不是已经修完。
3. **代码哈希指令 ≠ 已看见代码**（不变量 221）：1052 管返回值。本页只让它跟着余额一起涨价。
4. **bn128 预编译降价 ≠ 已验签**（不变量 228）：1108 是曲线预编译改价。本页是状态读涨价。

不要抄操作码号、新旧气价、津贴数字、接口气上限。不要写怎样绕过涨价、怎样在津贴帧里再读槽、怎样按旧价赌默认函数。不编博物馆页。不另写 19 节。不转规范气价表。150 原文、2929 冷热、1052 语义、清状态提案是另一对象。冷热精读：[`worked-example-cold-vs-warm.md`](worked-example-cold-vs-warm.md)（不变量 169）。气≠墙钟：[`../failure-museum/ethereum-2021-05-state-gas-not-time.md`](../failure-museum/ethereum-2021-05-state-gas-not-time.md)（不变量 101）。
