# 工作实例：本笔第一次碰不是已经热

> **事实 / 推断 / 建议** 已分开。
> 对照：[L5.1](../../courses/level-05-ethereum/L05-M01-evm-and-gas.md)、[列入 ≠ 已访问](worked-example-listed-vs-accessed.md)、[gas ≠ 墙钟](../failure-museum/ethereum-2021-05-state-gas-not-time.md)、[自毁 ≠ 已删](../state-models/worked-example-selfdestruct-vs-delete.md)。
> 主文献：[EIP-2929](https://eips.ethereum.org/EIPS/eip-2929) Gas cost increases for state access opcodes。官方 EIP。不另写 19 节。
> 本页钉 **本笔第一次碰 ≠ 已经是热的**、**本笔再碰 ≠ 又是一次冷访问**、**发送者 / 收款方 / 预编译开跑时已在集合里 ≠ 任意地址已经热**、**子范围回滚 ≠ 外层集合已经忘了**、**CREATE 地址立刻进集合 ≠ 创建已经成功**、**EIP-2929 ≠ EIP-2930 名单 ≠ gas 已经等于墙钟**。不抄气价 / 分叉高度 / 操作码号。不写怎样灌冷访问或怎样预热救人。

## 1. 核心问题

阿比看见发送者已经在集合里，以为任意地址开跑就是热的；或看见本笔读过一次，以为下一笔还热；或看见规范编号 2929，以为就是 2930 名单或已经把 gas 钉成墙钟。

官方句（事实）：

- EIP-2929 提高若干状态访问操作码**在本笔第一次使用**时的费用：`SLOAD`、`*CALL`、`BALANCE`、`EXT*`、`SELFDESTRUCT`。
- 预编译，以及**本笔已经访问过**的地址和存储槽，费用更低。
- 执行时维护两份本笔集合：已访问地址、已访问存储键。集合跟自毁名单、退款计数一样，是交易范围对象。
- **子范围回滚**时，集合回到进入该范围之前。
- 一笔开始：存储键集合空着；地址集合先放入发送者、收款方（或正在创建的地址），以及全部预编译。
- 第一次碰到：按冷收费，并加入集合。已经在集合里：按热收费。
- `CREATE` / `CREATE2`：在检查该地址是否还能占之前，就把将创建的地址放进已访问地址。创建后来失败，这个地址仍留在外层集合；内层范围加进去的项随回滚丢掉。
- `SSTORE`：若该槽还不在存储键集合，先加一笔冷访问费再入集合。
- `SELFDESTRUCT`：若以太收款人还不在地址集合，加一笔冷访问费（转的金额是不是零都一样）。收款人已经热时，本操作**不再**另收一笔热读费，和其它调用族不一样。
- 规范**没有**把发送者已在集合写成任意地址已经热，也没有把本笔再碰写成又是冷的，也没有把本页写成 2930 名单或墙钟上限。

本笔第一次、本笔再碰、下一笔重新开始，是三件事。

## 2. 直觉（ELI15）

同一趟出门，第一家店要走远路，回头再进同一家就近。  
出门前口袋里已经有自家钥匙和预留座位，不等于全城的门都开着。  
这趟结束，下一趟又从远路开始。

## 3. 对象

| 名字 | 是什么 | 不是什么 |
|---|---|---|
| 冷访问 | 本笔第一次碰这个地址或槽 | 已经热；下一笔还算热 |
| 热访问 | 本笔集合里已经有 | 永远便宜；已经读到值 |
| 开跑预填 | 发送者、收款方 / 创建地址、预编译 | 任意地址已经热 |
| 范围回滚 | 集合回到进该范围之前 | 外层已经忘了；内层失败创建地址也没了 |

---

## 4. 最小案例

一条 Ethereum 要对齐「这一口气冷热是哪一盏灯」。

1. 本笔第一次 `SLOAD` 某个槽。规范：冷，入集合。不是已经热。
2. 同一笔再读同一槽。规范：热。不是又是一次冷访问。
3. 下一笔再读。规范：新交易，集合重开。上一笔热过不是这笔已经热。
4. 开跑时发送者已在地址集合。规范：预填这几个。不是任意地址已经热。
5. 子调用读过再回滚，外层再读。规范：内层加的项随回滚丢掉。回滚不是外层已经忘了自己先前加的。
6. `CREATE` 立刻把新地址放进集合，随后 initcode 失败。规范：这个地址仍在外层集合。进集合不是创建已经成功。
7. 有人把 2929 听成 2930（不变量 168）。2930 是可选名单，用来预填这两份集合。本页是集合自己怎么冷热。
8. 有人把 2929 听成 gas 已经等于墙钟（不变量 101）。101 是计量钉不住时间。本页是本笔第一次与再碰。

「发送者已在集合所以全城已热 / 读过一次所以下一笔还热 / 2929 所以已经是 2930」是假学习。

## 6. 和另外几句不是同一句

1. **列入 ≠ 已访问**（不变量 168）：可选名单预填集合。本页是集合自己的冷热。
2. **gas ≠ 墙钟**（不变量 101）：常数 gas 钉不住磁盘时间。本页再拆本笔第一次与再碰。
3. **自毁 ≠ 已删**（不变量 160）：后来只转余额。本页只钉自毁收款人要不要算一次冷访问。
4. **信封 ≠ 内层**（不变量 167）：编码外壳。本页不是类型字节。
5. **initcode ≠ 运行时代码**（不变量 176）：构造代码有多长。本页是地址进没进本笔热集合。
6. **出块者开跑已热 ≠ 169 预填**（不变量 187）：本页预填是发送者、收款方、预编译。出块者是后来另补的一盏灯。

不要抄气价 / 分叉高度 / 操作码号 / 见证字节公式。不要写怎样灌大量冷账户、怎样预热救人、怎样靠回滚躲集合。不编博物馆页。不另写 19 节。EIP-3651 开跑即热的 coinbase 见不变量 187。EIP-2200 净计量细则、1884 无条件涨价表是另一对象。

**边界：** 不抄气价。不另写 19 节。不写怎样灌冷访问。名单见 **C172**。墙钟见 **C105**。自毁见 **C164**。
