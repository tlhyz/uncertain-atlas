## 官方为什么这样拆

- **round 0 not same round ≠ 302 same height round change / 640 finunlock-notcommitlock interchangeable：** 官方把 When 第 11 步 round 0 和同高换轮 / When 第 10 步 unlock not h+1 分开。
- **round 0 not next_block_delay ≠ 589 fndelay / 385 block interval / 617 notslot interchangeable：** 官方把 593 item 2 和 Response 表非确定 / 块间隔参数分开。
- **round 0 not timeout_commit / not finh1 bundled ≠ 480 finmorepre / 643 finh1-notafterunlock interchangeable：** 官方把 593 item 2 和 processing time / timeout_commit / item 1 / item 3 分开；593 finh1 unbundling 续（642 item 2）。
