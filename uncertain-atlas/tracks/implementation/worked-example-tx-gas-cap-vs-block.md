## 1. 核心问题

阿比看见单笔交易的气上限被协议写成硬帽，以为块气限已经改了；或看见入池拒掉超帽的单笔，以为块已经验过；或看见块里有一笔超帽，以为只是策略拒绝、块还可以收；或看见规范编号 7825，以为就是 7934、7623，或已经是 Sepolia 那次通道尺寸。

官方句（事实）：

- EIP-7825：给**任何一笔**交易的气用量加一道协议级上限。
- 这道帽**不论**出块者把块气限设成多少都适用。
- 发送者写下的 `gasLimit` 高于这道帽，该笔交易被拒，并带相应错误码。
- 入池校验：发送者写下的 `gasLimit` 超帽，该笔作废，**不进交易池**。
- 块校验：处理之前，块里只要有一笔 `gasLimit` 超帽，整块非法、拒掉。
- 客户端实现里，交易的气限参数会被这道帽封顶。这道帽**独立于**块气限；官方写块气限比它大。
- 对已经写下超帽气限的交易，本页不向后兼容。官方写：这种交易需要拆成更小的操作。
- 气用量低于这道帽的交易不受影响。验证者仍可处理块气限高于这道帽的块，只要里面每一笔都守帽。
- 动机：单笔吃掉整块气会让负载不均、伤稳定性；高气交易常带来更大状态改动；高气交易会拉长验块时间。
- 安全段：固定帽用来减轻单笔超高气的拒绝服务；单笔有帽，验块更可预期、更齐。
- 规范**没有**把单笔气帽写成已经改了块气限，也没有把入池拒掉写成已经验过块，也没有把块里有一笔超帽写成只是策略拒绝，也没有把本页写成 7934、7623 或不变量 96。

单笔气帽、块气限、编码体积帽、通道尺寸，是四件事。

## 2. 直觉（ELI15）

一辆货车再能装，也不能把整座桥的载重配额一个人用完。  
这不是已经把桥的总限重改了。  
门口不让这辆车排队，不是这座桥已经验过今天的车队。  
量的是载重，不是车身外廓。

## 3. 对象

| 名字 | 是什么 | 不是什么 |
|---|---|---|
| 单笔气帽 | 任何一笔交易的协议级气上限 | 已经改了块气限 |
| 入池拒掉 | 超帽的单笔不进池 | 已经验过这块 |
| 块里有一笔超帽 | 整块非法 | 只是策略拒绝 |
| 7825 | 独立于块气限的单笔气谓词 | 7934 编码帽；7623 地板；96 通道尺寸 |

## 4. 最小案例

一条 Ethereum 要对齐「这一笔气限有没有超过单笔帽」。

1. 看见单笔气帽。规范：任何一笔的气用量有协议级上限。不是已经改了块气限。
2. 入池拒掉。规范：发送者写下的气限超帽，不进池。不是已经验过这块。
3. 块里有一笔超帽。规范：处理之前整块非法。不是只是策略拒绝。
4. 块气限可以比单笔帽大。规范：验证者仍可处理更大的块气限，只要每一笔守帽。不是单笔帽已经等于块气限。
5. 有人把这听成 7934（不变量 202）。那是整块 RLP 编码字节，独立于气。本页量的是单笔气。
6. 有人把这听成 7623（不变量 197）。那是 calldata 地板，还走气的计价。本页是单笔气上限。
7. 有人把这听成 96。那是出块通道沿用各家 HTTP 尺寸。本页是协议自己写死的单笔气帽。
8. 有人把这听成 101。那是气不是墙钟。本页仍是气，只是单笔有帽。
9. 有人把这听成 1559（不变量 158）。那是基础费、小费和弹性块气。本页不改块气市场。

「看见单笔气帽 = 已经改了块气 / 入池拒 = 块已验 / 块里超帽 = 只是策略 / 7825 = 7934」是假学习。

## 6. 和另外几句不是同一句

1. **RLP 编码硬帽 ≠ 已经改了气限**（不变量 202）：整块编码字节。本页是单笔气，独立于块气限。
2. **calldata 地板 ≠ 执行气**（不变量 197）：还走气的计价地板。本页是单笔气上限。
3. **出块通道尺寸 ≠ 拼块已齐**（不变量 96）：各家 HTTP / Engine API 上限。本页是协议自己写死的单笔气帽。
4. **气 ≠ 墙钟**（不变量 101）：计量钉的是气还是时间。本页仍钉气，只是单笔有帽。
5. **基础费 ≠ 小费**（不变量 158）：1559 拆分和弹性块气。本页不改块气市场。

不要抄单笔气帽取值 / 二次幂字面量 / 典型块气区间。不要写怎样把一笔拆到帽下。不编博物馆页。不另写 19 节。EIP-7934 编码帽、EIP-7623 calldata 地板、不变量 96 通道尺寸、不变量 101 气≠墙钟、EIP-1559 弹性块气是另一对象。编码帽精读：[`worked-example-rlp-cap-vs-gas.md`](worked-example-rlp-cap-vs-gas.md)（不变量 202）。地板精读：[`worked-example-calldata-floor-vs-execution.md`](worked-example-calldata-floor-vs-execution.md)（不变量 197）。通道尺寸馆藏：[`../failure-museum/ethereum-2024-03-sepolia-engine-rpc.md`](../failure-museum/ethereum-2024-03-sepolia-engine-rpc.md)（不变量 96）。
