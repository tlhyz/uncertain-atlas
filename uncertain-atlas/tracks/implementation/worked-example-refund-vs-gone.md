## 1. 核心问题

阿比看见规范削减了存储退款，以为已经没有退款；或看见去掉自毁退款，以为自毁已经按 6780 改了语义；或看见还有退款计数，以为执行当中就能拿来继续跑；或看见账面上的块气限，以为已经是本块实际能烧掉的上限；或看见规范编号 3529，以为就是 2200 的退款表本身，或已经是 1559 的费用市场。

官方句（事实）：

- EIP-3529：去掉自毁退款，并把存储清零退款降到**仍然可观、但不再够支撑现行退款利用**的水平。看见本页，不是已经没有退款。
- 官方写：退款只在**交易执行之后**结算，不能改任何一帧执行当中还能用多少气。看见退款计数，不是已经能在执行当中花。
- 官方写：拿掉退款不会让任何代码跑不起来，只会让一部分用法在经济上不再划算。看见本页，不是已经改了执行能不能走完。
- 官方写：本页只动 2200 里「原来非零、写成零」那一档；另外两档（先写后清、写回去）仍在。看见本页，不是已经重写 2200。
- 官方写：更早的全删退款提案会拿掉清零激励；本页仍留一部分清零退款。看见本页，不是已经是那些全删页。
- 官方写：退款会加大块大小方差；账面上的气限不是本块实际能烧掉的上限。看见账面气限，不是已经封死执行量。
- 官方写：退款对交易执行不可见。看见本页，不是已经改了帧里怎么扣气。
- 规范**没有**把削减写成已经没有退款，也没有把去掉自毁退款写成已经改了自毁语义，也没有把本页写成 2200 或 1559。

削减后退款仍在、已经没有退款、自毁语义、执行当中能用的气，是四件事。

## 2. 直觉（ELI15）

以前清掉不用的柜子，店会多退一笔押金。  
本页把这笔押金削薄，不是店已经不退押金。  
自毁那笔押金拿掉了，不是自毁已经改成「以后只转余额」。  
押金要等这单做完才结，不是做到一半就能拿去继续买东西。  
门上写的「本店最多接待多少人」，不是里面实际已经只能容那么多——退款会让后面的人挤进来。

## 4. 最小案例

一条 Ethereum 要对齐「这一口气退款还停在哪一层」。

1. 看见规范削减了清零退款。规范：降到仍然可观、但不再够支撑现行利用。不是已经没有退款。
2. 看见去掉自毁退款。规范：只拿掉自毁那笔退款。不是已经改了自毁以后只转余额。
3. 看见还有退款计数。规范：只在整笔执行之后结算。不是已经能在某一帧里接着花。
4. 看见账面上的块气限。规范：退款会加大方差，账面气限不是实际能烧掉的上限。不是已经封死执行量。
5. 有人把这听成不变量 158。那是 1559 的基础费 / 小费 / 烧掉。本页官方另写：退款造成的尖峰，1559 也压不了那么久。
6. 有人把这听成不变量 160。那是后来自毁不是已经删户。本页管的是自毁还退不退气，不是自毁还删不删户。
7. 有人把这听成不变量 159。那是瞬时存储不走退款计数器。本页动的是持久存储清零退款。
8. 有人把退款比例、气价表或测试向量抄进不确定。规范：数字是尺子，不是产品常量。

「3529 = 已经没有退款 / 去掉自毁退款 = 已经是 6780 / 有退款计数 = 执行当中能花 / 3529 = 2200 / 3529 = 1559」是假学习。

**推断：** 产品句若只写「退款削减所以已经没有退款」，读者会把削薄听成取消，或把去掉自毁退款听成 6780，或把账面气限听成已经封死执行量。

## 6. 和另外几句不是同一句

1. **基础费 ≠ 小费 / 烧掉 ≠ MEV 已解决**（不变量 158）：1559 管费用市场。本页管退款削薄。官方另写：退款尖峰，1559 也压不了那么久。
2. **后来的 SELFDESTRUCT ≠ 账户已经删掉**（不变量 160）：6780 管以后只转余额。本页管自毁还退不退气。
3. **瞬时存储 ≠ 账户持久存储**（不变量 159）：1153 不走退款计数器。本页动的是持久存储清零退款。
4. **本笔第一次碰 ≠ 已经热**（不变量 169）：2929 管冷热访问。本页依赖 2929 的计价名，不是已经是冷热规则本身。

不要抄退款比例、气价表、测试向量、百分比。不要写怎样做气代币、怎样留灰、怎样用退款打满一块。不编博物馆页。不另写 19 节。不转规范代码。2200 退款表、全删退款提案、6780 自毁语义、1559 费用市场是另一对象。费用市场精读：[`../mempool/worked-example-basefee-vs-tip.md`](../mempool/worked-example-basefee-vs-tip.md)（不变量 158）。
