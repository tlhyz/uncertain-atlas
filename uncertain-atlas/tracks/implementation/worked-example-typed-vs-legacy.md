# 工作实例：类型信封不是已经解开内层

> **事实 / 推断 / 建议** 已分开。
> 对照：[L1.4](../../courses/level-01-crypto/L01-M04-canonical-encoding.md)、[L5.1](../../courses/level-05-ethereum/L05-M01-evm-and-gas.md)、[编码](worked-example-encoding.md)、[chainId ≠ 已签](../crypto/worked-example-chainid-vs-signed.md)、[基础费 ≠ 小费](../mempool/worked-example-basefee-vs-tip.md)。

> 本页钉 **类型字节 ≠ 已经解开内层字段**、**旧式 RLP 列表 ≠ 已经是类型信封**、**看见收据 ≠ 收据类型已经对上该笔**、**EIP-2718 ≠ EIP-1559 ≠ EIP-155**、**信封在 ≠ 已经把类型签进哈希**。不抄类型取值范围 / 分叉高度 / 字段表。不写怎样跨类型复用签名。

## 1. 核心问题

阿比看见交易带了类型号，以为内层字段已经解开；或看见旧式字段列表，以为已经装进类型信封；或看见规范编号 2718，以为就是 1559 费用市场。

官方句（事实）：

- EIP-2718 定义一种**类型交易信封**，给以后的交易类型当外壳。
- `TransactionType || TransactionPayload` 是一笔合法交易；`TransactionType || ReceiptPayload` 是一份合法收据。`TransactionType` 标明格式；载荷由**以后的 EIP** 定义。
- 一笔交易要么是「类型字节再接不透明载荷」，要么是旧式 `LegacyTransaction`。
- 载荷是不透明字节；怎么读，取决于类型号。
- 同一下标的收据类型**必须**对上那笔交易的类型。
- 客户端用**第一个字节**分辨：落在类型区间是新信封，落在旧式 RLP 区间是旧交易。
- 以后的类型**应当**把类型字节放进被签数据的第一个字节。规范写的是应当，不是已经必须。
- 类型应对合约保持不透明；`ORIGIN` / `CALLER` 仍是同一地址。
- 规范**没有**把看见类型号写成已经解开内层，也没有把旧式列表写成已经是信封，也没有把本页写成 1559。

信封、内层、旧式列表，是三件事。

---

## 2. 直觉（ELI15）

信封角上盖了「几号袋」，不等于你已经拆开袋里的信。  
旧式明信片还在用，不等于它已经装进新信封。  
门牌 2718 不是门牌 1559，也不是门牌 155。

---

## 3. 对象

| 名字 | 是什么 | 不是什么 |
|---|---|---|
| 类型字节 | 标明后面载荷用哪份以后的 EIP | 已经解开内层字段 |
| 不透明载荷 | 字节；解释取决于类型 | 已经是 1559 / 已经是访问列表 |
| 旧式列表 | 仍合法的旧编码 | 已经是类型信封 |
| 收据类型 | 必须对上同一下标的交易类型 | 看见收据就已经对上 |

---

## 4. 最小案例

一条 Ethereum 要对齐「这一口气编码是哪一盏灯」。

1. 交易第一个字节落在类型区间。规范：这是信封。不是已经读懂袋里。
2. 交易是旧式字段列表。规范：仍是合法旧交易。不是已经装进信封。
3. 有人把 2718 听成 1559（不变量 158）。1559 是以后某一种载荷，不是本页外壳。
4. 有人把 2718 听成 155（不变量 161）。155 是旧字段里塞链号；本页是后来的外壳。
5. 看见一份收据。规范：收据类型必须对上那笔。看见不是已经对上。
6. 产品写「支持类型交易」。规范：以后的类型应当把类型签进去。应当不是已经签了。

「带了类型号所以已经解开 / 旧列表所以已经是信封 / 2718 所以已经是 1559」是假学习。

## 5. 五层

| 层 | 本页 |
|---|---|
| 密码学 | 应当把类型放进被签数据的头一个字节；应当不是已经签了 |
| 协议 | 必须点名问的是类型字节、不透明载荷，还是旧式列表 |
| 实现 | 两家客户端必须用同一把「第一字节」尺子 |
| 部署 | 分叉高度是部署对象，不是已经换完所有钱包 |
| 经济 | 信封本身不改谁收费；1559 是另一页 |

**推断：** 产品句若只写「支持 2718」，读者会把盖袋号听成已经拆信。  
**建议：** 第一版必须把类型字节、载荷、旧式列表三套文案分开。不要发明「带了类型 = 已经是 1559」。不要抄类型取值范围。不要写怎样跨类型复用签名。

---

## 6. 和另外几句不是同一句

1. **chainId ≠ 已签**（不变量 161）：155 在旧字段里塞链号。本页是后来的外壳。
2. **基础费 ≠ 小费**（不变量 158）：1559 是一种载荷。本页是装载荷的信封。
3. **意思一样、字节不一样**（L1.4）：大类。本页再拆类型字节与旧式列表。
4. **处理完一块 ≠ 已经改头**（不变量 149）：执行结果。本页是交易怎么编码。

不要抄类型取值范围 / 分叉高度 / 旧字段表。不要写怎样让一种类型的签名去当另一种。不编博物馆页。不另写 19 节。EIP-2930 访问列表、1559 载荷细则、blob 类型是另一对象。
