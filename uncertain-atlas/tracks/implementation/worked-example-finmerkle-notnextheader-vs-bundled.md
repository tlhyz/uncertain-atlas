## 官方为什么这样拆

- **included in next block not already written ≠ 432 finrespend / 467 finreturn interchangeable：** 官方把会写进下一块头和已经写进下一块头、When 第 4 步 returns 分开。
- **included in next block not this header AppHash ≠ 147 apphash vs this block / 614 notheader interchangeable：** 官方把 475 item 2 和下一块头写入时机 / 本头 AppHash 分开。
- **included in next block not finmerkle bundled ≠ 623 notthisheader / 625 notquery interchangeable：** 官方把 475 item 2 和 item 1 / item 3 分开。
