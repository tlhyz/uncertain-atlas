## 1. 核心问题

阿比看见创建合约，以为 initcode 的长短已经受部署代码那道上限管；或看见按长度收了气，以为已经跑完构造；或看见规范编号 3860，以为就是 170，或已经是 CREATE2 算地址的哈希费。

官方句（事实）：

- EIP-3860：给 **initcode** 补一道最大长度，并按字加一笔气，代表创建前必须做的跳转目标分析。
- 它**扩展** EIP-170。170 管的是创建结束时要存上链的运行时代码。本页管的是还没跑、用来创建的那份代码。
- 创建前，客户端必须对 initcode 做跳转目标分析，工作量随长度线性涨。本页之前：这件事没有计量，协议也没有上限。
- 创建交易：initcode 超界，整笔非法，像不够付固有气。固有气还要加上本页这道按字费。
- `CREATE` / `CREATE2`：initcode 超界，指令异常中止，像耗尽气。这道费在算新地址、跑 initcode **之前**扣；CREATE2 的哈希费同时或更早。
- 超界对指令来说，归早期耗尽气那一组检查，排在深度和余额那些「轻检查」前面。
- 已经部署的合约不应受影响。超界的创建交易仍可能进块，但结果是异常中止。
- 规范**没有**把 initcode 的界写成已经是 170，也没有把按字收费写成已经跑完构造，也没有把本页写成 1014 的哈希费或 2681 的序号上限。

initcode、运行时代码、已经创建，是三件事。

## 3. 对象

| 名字 | 是什么 | 不是什么 |
|---|---|---|
| initcode | 创建时先分析、再跑的那份代码 | 已经存上链的运行时代码 |
| initcode 界 | 这份代码的长度上限 + 按字分析费 | 170 的部署代码界 |
| 创建交易超界 | 整笔非法 | CREATE 指令异常中止 |
| 指令超界 | 像耗尽气那样中止 | 已经算出地址；已经跑完构造 |

---

## 4. 最小案例

一条 Ethereum 要对齐「这一口气创建卡在哪」。

1. 创建交易带着超长 initcode。规范：整笔非法。不是已经进 EVM 再失败。
2. `CREATE` / `CREATE2` 接到超长 initcode。规范：指令异常中止。不是创建交易那种整笔非法。
3. 扣了按字分析费。规范：创建前的跳转目标分析。不是已经跑完 initcode。
4. CREATE2 还要为算地址哈希付钱。规范：另一道费。不是本页这道分析费。
5. 有人把这听成 EIP-170。170 是存上链的运行时代码。本页是还没跑的构造代码。
6. 有人把这听成 2681（不变量 175）。那是序号顶到头。本页是代码有多长。
7. 有人把这听成 2929（不变量 169）。那是地址进没进本笔热集合。本页是 initcode 的界。

「initcode 超了 = 已经是 170 / 收了分析费 = 已经创建 / 3860 = 1014」是假学习。

## 6. 和另外几句不是同一句

1. **返回代码 ≠ initcode**（不变量 185）：创建结束要存上链的返回代码。本页是还没跑的构造代码。规范 EIP-170 不是不变量 170。
2. **上限 ≠ 还能加**（不变量 175）：序号顶。本页是代码有多长。
3. **第一次 ≠ 已热**（不变量 169）：地址进集合。本页不是占址成没成。
4. **自毁 ≠ 已删**（不变量 160）：账户还在不在。本页不写怎样同址再部署。
5. **回滚 ≠ 烧光**（不变量 177）：失败要不要留下剩余气。本页是构造代码有多长。
6. **保留首字节 ≠ 已是对象格式**（不变量 188）：返回代码第一字节。本页是还没跑的构造代码有多长。
7. **calldata 地板 ≠ 已改执行气**（不变量 197）：数据为主的下限气。本页是构造代码有多长；3860 是旧内在路径的输入，不是 7623 地板。

不要抄上限字节 / 每字气价 / 部署代码上限 / 哈希费常数 / 例工厂。不要写怎样造超长 initcode，或怎样用一层 initcode 塞多层合约。不编博物馆页。不另写 19 节。EIP-170 部署代码表、EIP-1014 哈希费、EIP-2681 序号上限是另一对象。保留首字节精读：[`worked-example-reserved-prefix-vs-eof.md`](worked-example-reserved-prefix-vs-eof.md)（不变量 188）。
