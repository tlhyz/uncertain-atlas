## 1. 核心问题

阿比看见模幂预编译的三段长度被加上限，以为计价公式已经改过；或看见超帽，以为还能算出结果；或看见长度有界，以为预编译已经换成普通 EVM 代码；或看见规范编号 7823，以为就是 198 已经重定价，或已经是 7825 那道单笔气帽，或已经是 7951 那种失败不 revert、气和成功一样。

官方句（事实）：

- EIP-7823：给模幂预编译的输入加上限。底数长度、指数长度、模数长度，每一段都必须不超过规范写的那一档。
- 任一段超帽：预编译停住、报错、**把剩余气烧光**。
- 动机：这条预编译出过不少共识洞。许多洞来自故意造的、不切实际的输入长度。测试面不再无限，洞会少一些。
- 计价函数因为输入无界而复杂。官方**现在不建议**借本页重写计价。上限落地之后，以后才可能改。
- 有了上限，才更说得上以后用一套扩展指令把预编译换成 EVM 代码。看见本页，不是已经换成 EVM 代码。
- 现有合理用法（官方点名验签和大数曲线那一类）仍被允许。本页不是已经改了那些算法。
- 这是不向后兼容的改动。官方对照历史调用：按他们分析到的那一段，没有过去的交易会因本页表现不同。
- 安全段：只收窄了接受范围，官方不预期因此多出新的攻击面。
- 规范**没有**把长度帽写成已经改了计价，也没有把超帽写成已经算出结果，也没有把长度有界写成预编译已经换成 EVM，也没有把本页写成 198 已经重定价、7825 或 7951。

输入长度帽、计价公式、预编译还在不在，是三件事。

## 2. 直觉（ELI15）

计算器门口加了一块「题目不能无限长」的牌子。  
这不是已经改了收费表。  
题目太长，机器直接关机并把力气罚光，不是还在给你一张答卷。  
牌子立了，不是这台专用计算器已经拆掉、换成普通纸笔。

## 3. 对象

| 名字 | 是什么 | 不是什么 |
|---|---|---|
| 输入长度帽 | 三段长度各有上限 | 已经改了计价公式 |
| 超帽 | 停住、报错、烧光剩余气 | 已经成功返回 |
| 长度有界 | 测试面不再无限 | 已经用 EVM 换掉预编译 |
| 7823 | 给 198 那条预编译加帽 | 198 已经重定价；7825 单笔气帽；7951 失败不烧光 |

## 4. 最小案例

一条 Ethereum 要对齐「这一口气模幂预编译在管什么」。

1. 看见三段长度有帽。规范：每一段都必须守帽。不是已经改了计价。
2. 任一段超帽。规范：停住、报错、烧光剩余气。不是已经算出结果。
3. 看见长度有界。规范：好让以后才可能换成 EVM 代码。不是已经换掉。
4. 有人把这听成 198 已经重定价。官方明确现在不借本页改计价。
5. 有人把这听成 7825（不变量 203）。那是单笔交易气用量帽。本页是一条预编译的输入长度。
6. 有人把这听成 7951（不变量 204）。那条失败不得 revert，气和成功一样。本页超帽烧光剩余气。
7. 有人把这听成 199（不变量 199）。那是 BLS12 算术。本页是模幂输入帽。

「看见长度帽 = 已经改计价 / 超帽 = 已算出 / 有界 = 已换成 EVM / 7823 = 7825 / 7823 = 7951」是假学习。

## 5. 五层

| 层 | 本页 |
|---|---|
| 密码学 | 模幂仍是那条预编译；本页不管算法对不对 |
| 协议 | 必须点名问的是输入长度、计价，还是预编译还在不在 |
| 实现 | 超帽必须停、必须报错、必须烧光剩余气 |
| 部署 | 不把历史「没人超过」写成永远不会有人超 |
| 经济 | 不把长度帽写成已经让块气限能涨 |

**推断：** 产品句若只写「模幂终于有界了」，读者会把帽听成已经改了价，或把有界听成专用预编译已经拆掉。  
**建议：** 第一版可以不做无界模幂预编译。若做，必须分开输入长度、计价、替换路径。不要发明「看见 7823 就已经改了计价」。不要抄长度上限。不要把 7823 写成 7825。

## 6. 和另外几句不是同一句

1. **回滚 ≠ 烧光**（不变量 177）：EVM 回滚可留气。本页超帽烧光剩余气。
2. **P256 失败不 revert**（不变量 204）：7951 失败气和成功一样。本页超帽烧光。
3. **预编译算术 ≠ 已验 BLS**（不变量 199）：2537 是曲线算术。本页是模幂输入帽。
4. **单笔气帽 ≠ 已改块气**（不变量 203）：7825 是交易气用量。本页是预编译输入长度。

不要抄长度上限比特 / 字节、预编译地址、历史块号、调用次数表。不要写怎样造超长输入。不编博物馆页。不另写 19 节。不转无效调用样本。EIP-198 原文、后来的模幂重定价、单笔气帽、7951 失败模型是另一对象。失败气模型精读：[`../crypto/worked-example-p256-vs-k1.md`](../crypto/worked-example-p256-vs-k1.md)（不变量 204）。
