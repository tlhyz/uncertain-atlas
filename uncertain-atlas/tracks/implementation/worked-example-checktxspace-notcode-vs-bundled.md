## 官方三件事

规范把 Methods 里 CheckTx 回包 codespace 是码的命名空间 和「已经是写了空间就已经是回包码 interchangeable / 已经是有命名空间就已经没进块 interchangeable / 已经是能回就已经交差 interchangeable / 已经是 checktxspace bundled interchangeable」分开写成三件独立的实现事，不是「看见写了空间就已经是回包码 interchangeable / 就已经没进块 interchangeable / 就已经交差 interchangeable」一件事：

1. **看见写了空间 / 看见 CheckTx 回包 codespace 是码的命名空间 / 看见写了 codespace is not already 已经是回包码 interchangeable / 已经 code interchangeable / 已经是回包码交差 interchangeable / 381 checktxspace bundled interchangeable / 373 checktxopt interchangeable / checktxspace-sold-as-code interchangeable，也不是已经 checktxspace bundled（381） interchangeable / 890 checktxspace-notcode interchangeable / 381 checktxspace item 1 interchangeable，也不是已经 CheckTx 回包 codespace 是码的命名空间不是已经是回包码 not already code / not already excluded / not already settled 正式三事 bundled（381 item 1 余量） interchangeable / 381 checktxspace item 1 interchangeable，也不是已经回了事件就已经交差（381 item 2） interchangeable / 填了道就已经不设道（381 item 3） interchangeable / 373 checktxopt interchangeable，也不是已经引擎对回包码不再赋予别的含义就已经被引擎用了 Data（373） interchangeable。**  
   官方写：`codespace` 是这个 `code` 的命名空间。看见写了空间，不是已经是回包码本身。看见写了空间，不是已经 code interchangeable——381 钉 bundled 三事，本页从 item 1 侧钉 not already code 单句。看见 CheckTx 回包 codespace 是码的命名空间，不是已经 checktxspace bundled（381） interchangeable——381 钉 bundled，本页钉 item 1 第一件事。看见写了 codespace，不是已经引擎对回包码不再赋予别的含义就已经被引擎用了 Data（373） interchangeable——373 另钉。381 checktxspace-vs-code bundled unbundling 在本页 item 1 启动。

2. **看见有命名空间 / 看见有 codespace 命名空间 / 看见有空间名 is not already 已经没进块 interchangeable / 已经 excluded interchangeable / 已经没进块交差 interchangeable / 381 checktxspace bundled interchangeable / 373 checktxopt interchangeable，也不是已经 checktxspace bundled（381） interchangeable / 890 checktxspace-notcode interchangeable / 381 checktxspace item 2 回了事件 interchangeable / 381 checktxspace item 3 填了道 interchangeable，也不是已经 CheckTx 回包 codespace 是码的命名空间不是已经是回包码 not already code / not already excluded / not already settled 正式三事 bundled（381 item 1 余量） interchangeable / 381 checktxspace item 1 interchangeable，也不是已经是回包码（本页第一件事） interchangeable。**  
   官方写：看见有命名空间，不是已经没进块。看见有 codespace 命名空间，不是已经 excluded interchangeable——本页钉 not already excluded 单句。看见有空间名，不是已经是回包码（本页第一件事） interchangeable——三件事分开钉。381 checktxspace-vs-code bundled unbundling 在本页 item 1 启动。

3. **看见能回 / 看见能回 codespace / 看见有 codespace 回包 is not already 已经交差 interchangeable / 已经 settled interchangeable / 已经交差交差 interchangeable / 381 checktxspace bundled interchangeable / 316 txresults interchangeable，也不是已经 checktxspace bundled（381） interchangeable / 890 checktxspace-notcode interchangeable / 381 checktxspace item 2 / 381 checktxspace item 3，也不是已经 CheckTx 回包 codespace 是码的命名空间不是已经是回包码 not already code / not already excluded / not already settled 正式三事 bundled（381 item 1 余量） interchangeable / 381 checktxspace item 1 interchangeable，也不是已经是回包码（本页第一件事） interchangeable / 已经没进块（本页第二件事） interchangeable。**  
   官方写：看见能回，不是已经交差。看见能回 codespace，不是已经 settled interchangeable——本页钉 not already settled 单句。看见有 codespace 回包，不是已经没进块（本页第二件事） interchangeable——三件事分开钉。381 checktxspace-vs-code bundled unbundling 在本页 item 1 启动。

怎样写 CheckTx 回包、怎样填码空间、怎样选道是规范里的做法，本页不抄。checktxspace bundled（381）、CheckTx 回包 events 是给索引用的类型键值不是已经交差（381 item 2 余量）、CheckTx 的 lane_id 必须在 Info 回包车道范围内不是已经不设道（381 item 3 余量）、引擎对回包码不再赋予别的含义就已经被引擎用了 Data（373）、结果列表就已经同一顺序（316）、没定义 lane_priorities 就已经排了优先（367）是另外那套，本页不抄。

## 官方为什么这样拆

- **写了空间 not already code ≠ 381 / 373 interchangeable：** 官方把码的命名空间和回包码本身分开。
- **有命名空间 not already excluded ≠ 已经没进块 interchangeable：** 官方把有命名空间和已经没进块分开。
- **能回 not already settled ≠ 已经交差 interchangeable：** 官方把能回和已经交差分开；381 checktxspace-vs-code bundled unbundling 在本页 item 1 启动。
