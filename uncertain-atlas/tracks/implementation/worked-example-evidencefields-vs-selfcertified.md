# 例：看见 DuplicateVoteEvidence 里有 TotalVotingPower 不是这些数已经自证；看见要求是「与本节点自己那份数据相等」不是已经能自己算；看见 Timestamp 是过错那块的凭证时间不是已经由证据自带

**层次**：实现 / 证据字段可信性。  
**分类**：事实（对象边界）+ 推断（产品）+ 建议（产品）。  
**来源**：CometBFT 官方 [Core Data Structures](https://github.com/cometbft/cometbft/blob/main/spec/core/data_structures.md) DuplicateVoteEvidence / LightClientAttackEvidence。

**不要写进**：Ethereum 行、L5.1、M5.4、L5.4、03 共识图谱、Bitcoin 行、L4.5。本页是「DuplicateVoteEvidence 里有 TotalVotingPower 不是这些数已经自证 / 要求与本节点自己那份数据相等不是已经能自己算 / Timestamp 是过错那块的凭证时间不是已经由证据自带」，不是双签证据形状成立就已经罚没，也不是证据身份不得含尚未最终的本地视角字段。不要另写怎样写证据。

## 官方三件事

规范把 `DuplicateVoteEvidence` 的 `VoteA` / `VoteB` 是要各自合规的票、`TotalVotingPower` / `ValidatorPower` / `Timestamp` 三个字段**必须与节点自己那份数据相等**、以及 `LightClientAttackEvidence` 的同类字段同样是「与本节点自己那份数据相等」，写成三件独立的实现事，不是「看见证据里有这些数就已经是证据自带了权威、已经能罚」一件事：

1. **看见 `TotalVotingPower` / `ValidatorPower` 写在证据里 / 看见有数 不是已经自证，也不是已经能自己算。**  
   官方写：这两个字段的校验是**必须与节点自己那份数据相等**（Must be equal to nodes own copy of the data）。看见证据里填了权，不是这些数自带权威。看见有数，不是已经能用这份证据自己算出来。看见填了，不是已经交差。
2. **看见校验写的是「与本节点自己那份数据相等」/ 看见这行 不是已经能独立验证，也不是已经不看本地状态。**  
   官方写：这三个字段（`TotalVotingPower` / `ValidatorPower` / `Timestamp`）都要求与本节点自己那份数据相等。看见要求，不是已经能从证据本身推出。看见证据在，不是已经不需要本地链状态。看见能核，不是已经能不查自己那份。
3. **看见 `Timestamp` 是过错那块的凭证时间 / 看见有时间 不是已经由证据自带，也不是已经能自己定。**  
   官方写：`Timestamp` 是过错发生那块的凭证时间。看见有时间，不是证据自己证明了它。看见能填，不是已经能自己定。看见对上了那块的字段，不是已经交差。

怎样构造证据、怎样算投票权、怎样挑时间戳是规范里的做法，本页不抄。双签证据形状成立就已经罚没是不变量 21，本页不抄。证据身份不得含尚未最终的本地视角字段是不变量 64，本页不抄。

## 官方为什么这样拆

- **证据里有权数字段 ≠ 这些数已经自证：** 官方把「字段存在」和「值可信」分开，并要求对照节点自己那份。
- **要求是「与本节点自己那份数据相等」 ≠ 已经能独立验证：** 官方把这个校验钉在本地状态上，而不是钉在证据内容上。
- **`Timestamp` 是那块的凭证时间 ≠ 已经由证据自带：** 官方把它同样列入「与自己那份相等」的三个字段之一。

## 和相邻页的边界

| 对象 | 本页 | 那一页 |
|---|---|---|
| 证据里有 TotalVotingPower / ValidatorPower | 不是这些数已经自证 | 不是双签证据形状成立就已经罚没（21） |
| 要求「与本节点自己那份数据相等」 | 不是已经能独立验证 | 不是证据身份含本地视角字段就已经有规范身份（64） |
| Timestamp 是过错那块的凭证时间 | 不是已经由证据自带 | 不是证据过期是高度或时间之一（46） |
| 本页不涉及 | — | 不是收下冲突头就必须能形成证据（66） |

## 产品

**建议（产品，不是事实）**：不确定第一条结算机如果给人看「看见证据里有这些数就已经是证据自带权威、已经能罚」，必须分开证据里有 TotalVotingPower / ValidatorPower 是不是这些数已经自证、要求与本节点自己那份数据相等是不是已经能独立验证、Timestamp 是过错那块的凭证时间是不是已经由证据自带。可以跳过「看见证据里有这些数就已经是证据自带权威」。不要另写怎样写证据。

## 本页不抄

- 怎样构造证据、怎样算投票权、怎样挑时间戳。
- 双签证据形状成立就已经罚没。那是不变量 21。
- 证据身份不得含尚未最终的本地视角字段。那是不变量 64。
- 证据过期是高度与时间的合取。那是不变量 46。
