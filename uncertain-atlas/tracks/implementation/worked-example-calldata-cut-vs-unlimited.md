## 1. 核心问题

阿比看见非零 calldata 降价，以为零字节也已经便宜；或看见更便宜，以为块已经可以任意大；或看见二层常把数据贴在 calldata 上，以为数据可用性已经解决，或已经是后来的 blob；或看见规范编号 2028，以为就是 7623 那道地板，或已经是 1559。

官方句（事实）：

- EIP-2028：降低**非零** calldata 字节的气价。零字节的气价**不变**。看见本页，不是已经给零字节也降价。
- 官方写：更高的 calldata 带宽一般能提高可扩展性，因为一块里能多塞数据。看见降价，不是已经没有块大小上限。
- 官方写：二层常把存储和计算挪到链下，但往往改成传数据。可选做法之一是把数据贴在主链的 calldata 上。看见本页，不是已经解决数据可用性，也不是已经是 blob。
- 官方写：降低 calldata 气价会导致潜在更大的块，加大与传输有关的网络延迟。这只是总延迟的一部分。看见降价，不是已经不伤延迟。
- 官方写：加大延迟会降低攻击网络的成本，因为任一时刻更少节点更新到最新状态。看见降价，不是已经不改安全。
- 官方写：延迟可拆成传输延迟和处理延迟；二层常用的认证路径往往传输重、处理轻。看见认证路径，不是已经量过整网延迟。
- 规范**没有**把非零降价写成零字节也降了，也没有把本页写成已经没有块上限，也没有把本页写成 7623 或 4844。

非零降价、零字节价、块上限、后来的地板 / blob，是四件事。

## 2. 直觉（ELI15）

以前寄一封「有字的信」比较贵。  
本页把有字的信降价，空白信的邮费没动。  
邮费便宜了，不是邮局已经不限包裹有多大。  
二层常把收据塞进这些信，不是收据已经另开了短时袋子，也不是以后那道「数据为主更贵」的地板已经铺上。

## 3. 对象

| 名字 | 是什么 | 不是什么 |
|---|---|---|
| 非零 calldata 降价 | 有内容的字节更便宜 | 已经给零字节也降价 |
| 潜在更大块 | 一块里能多塞数据 | 已经没有块大小上限 |
| 延迟与安全 | 更大块可能加大延迟、降低攻击成本 | 已经不改安全 |
| 2028 | 非零降价 | 7623 地板；4844 blob；1559 |

## 4. 最小案例

一条 Ethereum 要对齐「这一口气 calldata 价还停在哪一层」。

1. 看见非零 calldata 降价。规范：只动非零字节。不是已经给零字节也降价。
2. 看见一块能多塞数据。规范：潜在更大的块。不是已经没有上限。
3. 看见二层把数据贴在 calldata。规范：这是可选的数据可用性做法。不是已经解决 DA，也不是已经是 blob。
4. 看见规范谈延迟和安全。规范：更大块可能加大延迟，从而降低攻击成本。不是已经不改安全。
5. 有人把这听成不变量 197。那是 7623 给数据为主的交易加地板。本页是更早的非零降价。
6. 有人把这听成不变量 145。那是 4844 两套气。本页还没有 blob。
7. 有人把这听成不变量 158。那是 1559 基础费 / 小费。本页不改费用市场。
8. 有人把每字节气价或延迟公式抄进不确定。规范：数字和模型是尺子，不是产品常量。

「2028 = 零字节也降了 / 降价 = 已经没有块上限 / 2028 = 7623 / 2028 = 4844 / 贴在 calldata = DA 已经齐」是假学习。

## 5. 五层

| 层 | 本页 |
|---|---|
| 密码学 | 降价不换签算法；看见 STARK / SNARK 不是证明已经便宜到免费 |
| 协议 | 必须点名问的是非零降价、零字节价、块上限，还是后来的地板 / blob |
| 实现 | 官方写延迟可拆成传输和处理；看见拆开不是已经量过整网 |
| 部署 | 官方写要用模型加实测再定价；看见本页不是已经测过不确定的延迟 |
| 经济 | 更便宜不是已经不改攻击成本，也不是二层已经免费 |

**推断：** 产品句若只写「calldata 降价所以已经没有上限」，读者会把便宜听成无限，或把 2028 听成 7623，或把贴在 calldata 听成 DA 已经齐。  
**建议：** 第一版不要把短时 calldata 当默认 DA。若对照，必须分开非零降价、零字节价、块上限、后来的地板 / blob。不要发明「看见 2028 就已经没有上限」。不要抄每字节气价或延迟公式。不要写怎样往 calldata 里塞证明或打满更大块。

## 6. 和另外几句不是同一句

1. **calldata 地板 ≠ 已经改了执行气**（不变量 197）：7623 给数据为主的交易加地板。本页是更早的非零降价。
2. **blob 气 ≠ 执行气**（不变量 145）：4844 另开短时袋子。本页还把数据贴在 calldata。
3. **基础费 ≠ 小费**（不变量 158）：1559 管费用市场。本页不改基础费。
4. **净计量 ≠ 已经是瞬时存储**（不变量 225）：2200 管存储三值。本页管交易数据字节价。

不要抄每字节气价、延迟公式、测试仓库。不要写怎样往 calldata 里塞证明、怎样打满更大块、怎样按延迟模型定价。不编博物馆页。不另写 19 节。不转规范代码。7623 地板、4844 blob、1559 费用市场、零字节旧价是另一对象。地板精读：[`worked-example-calldata-floor-vs-execution.md`](worked-example-calldata-floor-vs-execution.md)（不变量 197）。
