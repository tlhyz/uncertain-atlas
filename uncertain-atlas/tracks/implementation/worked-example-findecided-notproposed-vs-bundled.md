   官方 Request 表写：`decided_last_commit` 是上一份提交信息，从刚决定那块拿到。Process 请求表写：`proposed_last_commit` 是从拟议块里的信息拿到的上一份提交信息。看见从刚决定那块拿到，不是已经 proposed_last_commit 那种从拟议块里的信息拿到 interchangeable——463 bundled 第二件事常被写成「看见 decided_last_commit 就已经是 proposed_last_commit interchangeable」，本页钉 decided_last_commit from decided block not proposed_last_commit 单句。看见 decided_last_commit，不是已经 Finalize 请求栏 decided vs proposed（422 余量） interchangeable——422 钉三栏单栏定义，本页钉 decided block commit vs proposed block commit 边界。看见从刚决定那块拿到，不是已经 Process 请求余栏 bundled（420 余量） interchangeable——420 钉 proposed_last_commit 单栏，本页钉 decided vs proposed commit 单句。

## 官方为什么这样拆

- **decided_last_commit from decided block not proposed_last_commit ≠ FinalizeBlock decided_last_commit + misbehavior 定奖惩 bundled interchangeable：** 官方把 decided block 的 commit 和 proposed block 的 commit 分开。
- **decided_last_commit from decided block not local_last_commit ≠ Prepare local_last_commit interchangeable：** 官方把 decided block 的 commit 和 Prepare 本进程 local commit 分开。
- **decided_last_commit from decided block not can use means slashed ≠ 567 can use not slashed interchangeable：** 官方把 Request 表上 decided block commit 和 Usage 里 can use 定奖惩 分开。
