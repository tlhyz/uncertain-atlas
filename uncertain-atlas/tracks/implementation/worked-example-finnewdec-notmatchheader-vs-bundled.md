## 官方为什么这样拆

- **fields of the newly decided block not match header means objects separated ≠ FinalizeBlock Contains newly decided block fields bundled interchangeable：** 官方把 newly decided 对象边界和 match header 单句分开。
- **fields of the newly decided block not fill all fields means newly decided/proposed interchangeable ≠ 473 fill all fields interchangeable：** 官方把 newly decided 对象和又填一遍 / decided/proposed 语义分开。
- **fields of the newly decided block not decided/proposed commit columns interchangeable ≠ 422 decided vs proposed interchangeable：** 官方把 fields of the newly decided block 和 decided_last_commit / proposed_last_commit 单栏混用分开。
