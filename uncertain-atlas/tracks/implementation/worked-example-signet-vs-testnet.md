# 例：看见 signet 不是已经是 testnet；看见 signet 不是已经是 regtest；看见头上有合法工作量不是已经签过

**层次**：应用 / 规范对象。  
**分类**：事实（对象边界）+ 推断（产品）+ 建议（产品）。  
**来源**：Bitcoin [BIP-325](https://github.com/bitcoin/bips/blob/master/bip-0325.mediawiki)（Complete, Applications）。  
**对应课文**：[L3.6](../../courses/level-03-bitcoin/L03-M06-testing-and-culture.md)。  
**不要写进**：Ethereum 行、L5.1、05b 当执行层测试网、M5.4、L5.4、03 共识。本页是「带挑战脚本的测试网不是已经是 testnet / regtest / 已经签过」，不是主网重复交易标识，也不是跳脚本加速。

## 官方三件事

规范把 signet 写成三件独立的测试网事，不是「看见测试网就已经能当主网预演」一件事：

1. **看见 signet 不是已经是 testnet，也不是已经和 testnet 一样不可靠。**  
   官方写：testnet 适合试新东西、不必拿真钱冒险，但出了名的不可靠。巨大重组、长时间不出块、突然连出一串块，让多家独立方做较长时间的真实测试变得不可行。本页是一种新的测试网：出块除了工作量，还要签名。目标不是完美可靠，而是不可靠的分量可预期。你希望它表现得像主网（不会出现上千块的重组），同时又更容易触发预期中的稀有事件（例如一次六块重组）。看见 signet，不是已经是 testnet。看见它比 testnet 稳，不是已经和主网同一套结算。
2. **看见 signet 不是已经是 regtest，也不是已经谁都能完全控制。**  
   官方写：regtest 不适合多家独立方做较长时间的场景，因为造块没有代价，任何一方都能完全控制测试网。看见 signet，不是已经是本地无代价出块。看见还能协调出块，不是已经谁都能独占。
3. **看见头上有合法工作量 / 只加了网络参数就能连上 不是已经签过，也不是已经全验证通过。**  
   官方写：现有软件只要加上网络参数就能连任何一条 signet，不必再改别的。头上有合法工作量，客户端可以轻易判断这些块「大概」合法。可是任何人都能挖出会被这种客户端收下的块；这些块没有所需签名，全验证节点会立刻拒。客户端要么自己验 coinbase 里的块签名，要么只连受信任的对等节点。创世块对所有 signet 相同，消息起始字节由挑战脚本决定。看见同一份创世，不是已经是同一条 signet。看见工作量过了，不是已经签过。

挑战怎么承诺、虚拟交易怎么拼、最低难度数字是规范里的取值，本页不抄。

## 官方为什么这样拆

- **signet ≠ testnet：** 官方把 testnet 的巨大重组和出块风暴写成不可用，把本页写成可预期的不可靠。
- **signet ≠ regtest：** 官方把「造块没有代价、任何一方都能完全控制」写成 regtest 不适合多方长期测。
- **工作量 ≠ 已经签过：** 官方把「只加参数就能连」和「全验证必须验签名」写成两件独立的事。

## 和相邻页的边界

| 对象 | 本页 | 那一页 |
|---|---|---|
| signet | 工作量 + 块签名 | 不是已经是 testnet |
| regtest | 无代价出块 | 不是已经是本页 |
| 头上工作量 | 「大概」合法 | 不是已经签过 / 已经全验证 |
| 同一创世 | 所有 signet 共用 | 不是已经是同一条网 |
| 同一交易标识 ≠ 已经唯一 | 另一对象 | 不变量 257 |
| 跳脚本 ≠ 已经全验证 | 另一对象 | 不变量 25 |
| 进了块的 coinbase ≠ 已经能花 | 另一对象 | 不变量 163 |

## 产品

**建议（产品，不是事实）**：不确定第一条结算机如果写测试网，必须分开 testnet 式不可靠、regtest 式无代价控制、signet 式可预期不可靠。可以跳过「看见测试网就已经能当主网预演」。若对照，必须分开工作量过了和块签名过了。不要另写怎样拼挑战或造假签块。

## 本页不抄

- 挑战头字节、最低难度、创世哈希、时间戳、例挑战脚本、虚拟交易字段。
- 怎样拼 to_spend / to_sign、怎样磨 nonce 还不重签、怎样让空解当挑战为真。
