# 例：Homestead 硬分叉四件事 ≠ 已经改了 CREATE / 已经拒高 s / 已经限制代码 / 已经没有炸弹

**层次**：实现 / 规范对象。  
**分类**：事实（对象边界）+ 推断（产品）+ 建议（产品）。  
**来源**：Ethereum [EIP-2](https://eips.ethereum.org/EIPS/eip-2)（Final, Core, Homestead）。  
**对应课文**：[L5.1](../../courses/level-05-ethereum/L05-M01-evm-and-gas.md)。  
**不要写进**：`index/03` 共识行、M5.4、L5.4。难度公式是第四个对象，不是另开共识页。

## 官方四件事

规范把 Homestead 写成一次硬分叉的四件独立事，不是“创建贵了”一件事：

1. **交易创建的固定费比消息调用高；`CREATE` 操作码的创建费没改。**  
   官方原文：现在用交易创建合约，比用合约里的 `CREATE` 更有超额激励。看见交易创建变贵，不是已经改了 `CREATE`。
2. **交易签名里 `s` 大于曲线阶的一半，现在无效；`ECRECOVER` 预编译仍接受高 `s`。**  
   官方原文：预编译仍接受，是因为还要恢复旧比特币签名。看见交易拒高 `s`，不是已经让预编译拒高 `s`。
3. **创建付不起最后那段存代码的气，现在整笔失败，不再留下空合约。**  
   官方原文：成功就带上全部代码，失败就不当成创建成功。看见“失败不再留空合约”，不是已经限制返回代码长度（不变量 185）、不是已经限制 initcode（不变量 176）、不是已经区分 empty / dead（不变量 180）。
4. **难度调整改成朝均值收敛。**  
   官方原文：旧式“时间只加一点点、难度几乎不动”会把平均出块时间推向无穷；新公式用更粗的时间粒度，并给难度下降加了下限。看见新公式，不是已经取消指数炸弹，也不是已经写了后来那些推迟炸弹的分叉。

四件事共享一次分叉，不共享一个对象。分叉高度是规范里的常数，本页不抄。

## 官方为什么这样拆

- **交易创建**：官方说，用交易创建比用合约创建更便宜，是超额激励。`CREATE` 操作码的创建费保持原样。看见交易创建变贵，不是已经让合约里的创建一样贵。
- **高 `s`**：官方说，旧规则下把 `s` 翻到另一半、再把恢复标识翻过去，签名仍有效，但发出去的哈希和链上确认的哈希可以对不上。官方把它叫界面上的不方便，不是严重安全漏洞——因为以太坊用地址、不是用交易哈希，当作转账输入。看见交易拒高 `s`，不是已经修了预编译，也不是已经写了比特币的 DER 低 `s`（不变量 172），也不是已经把链标识写进签名（不变量 161）。
- **空合约**：官方说，以前创建可能走出“成功 / 失败 / 留下空合约”三种结果；现在只留成功或失败。失败时剩余的气和附带的值退回，也不会为了失败再造一个账户。看见“失败更好认”，不是已经限制代码有多长。
- **难度**：官方说这是本规范里最明显必须改的一项。旧式微调时间戳会让平均出块时间被推向无穷。新公式仍保留指数炸弹项。看见朝均值收敛，不是已经没有炸弹。

官方还写过：创建再立刻自毁、用退款做便宜转账，arguably 是个 bug。那是退款 / 自毁家族的另一对象，不是本页已经写了不变量 160、223、208。

## 产品

**建议（产品，不是事实）**：不确定第一条结算机可以跳过“看见 Homestead 就已经改了 `CREATE` / 就已经让预编译拒高 `s` / 就已经限制代码 / 就已经没有炸弹”。交易创建的费、交易验签、创建失败语义、出块节奏，是四个旋钮。预编译仍接受高 `s`，是官方留下的旧接口，不是“验签已经统一”。

## 本页不抄

- 主网 / 测试网分叉高度。
- 交易创建费、消息调用费、`CREATE` 操作码费、自毁退款例子里的气。
- 曲线阶一半的十六进制、`s` 怎么翻、恢复标识怎么翻。
- 难度公式、时间粒度、下降下限、炸弹项里的常数。
- 怎么用创建再自毁做便宜转账，怎么调时间戳磨难度。
