## 1. 核心问题

阿比看见 bn128 上的加、乘、配对检查降价，以为算法已经换过；或看见更便宜，以为合约已经在验签，或隐私 / 扩容产品已经上线；或看见规范编号 1108，以为就是后来的 2537，或已经是 196/197 原文那一次「加上预编译」，或已经是通用曲线算术。

官方句（事实）：

- EIP-1108：椭圆曲线算术预编译当时被标价过高。给它们重新标价，会大大帮助以太坊上的一批隐私方案和扩容方案。看见本页，不是这些方案已经上线，也不是已经在验签。
- 官方写：2018 年官方 Go 参考实现换了底层库，bn128 上的加、乘、配对检查快了很多。更快的操作应当反映成更低的气价。看见降价，不是本页已经换了算法。
- 官方写：加、乘的气价是对 EIP-196 那张表的更新；配对检查的气价是对 EIP-197 那张表的更新。看见本页，不是已经重新加入这三条预编译。
- 官方写：新气价按当时更慢的那一家客户端的基准来对齐。看见对齐，不是已经量过不确定的墙钟。
- 官方写：底层算法没有改，因此不必另写测试向量。看见降价，不是得数已经变了。
- 官方写：本页不要求客户端再部署新的密码库；够快的算法当时已经集成进去。看见本页，不是已经换库。
- 官方写：本页是给当时还在推进的「通用椭圆曲线算术」提案当即时补丁，好在更先进的方案写完、定下来、部署之前，先把「密码太贵」这件事压一压。看见本页，不是已经有通用曲线算术。
- 官方写：更便宜的椭圆曲线运算可以用来拿计算换存储。看见本页，不是已经把账户收成一棵树，也不是已经用简短证明代替多份余额。
- 官方写：对当时基于简短证明的协议，本页会显著降低验证费，也可以帮助把多份证明捆在一起。看见本页，不是已经在验简短证明，也不是已经捆好了。
- 规范**没有**把降价写成已经换了算法，也没有把本页写成已经在验签，也没有把本页写成 2537 或写成 196/197 原文，也没有把本页写成通用曲线算术已经落地。

降价、196/197 原文、2537、已经在验签，是四件事。

## 2. 直觉（ELI15）

厨房里的秤、刀、锅还是那一套，只是水电费降了。  
水电费便宜了，不是已经端出一盘验过的签名菜。  
也不是已经换成另一套厨具，更不是已经开了通用厨房、什么曲线都能炒。

## 3. 对象

| 名字 | 是什么 | 不是什么 |
|---|---|---|
| bn128 预编译降价 | 给 196/197 已有的加、乘、配对改价 | 已经换了算法或得数 |
| 更便宜 | 当时客户端已经够快，气价跟着下调 | 已经在验签；隐私 / 扩容产品已经齐 |
| 即时补丁 | 先压「密码太贵」 | 已经是通用曲线算术 |
| 1108 | 给 bn128 三条预编译改价 | 2537；196/197 原文；不变量 199 |

## 4. 最小案例

一条 Ethereum 要对齐「这一口气椭圆曲线预编译在管什么」。

1. 看见 bn128 加 / 乘 / 配对降价。规范：只改气价。不是已经换了算法。
2. 看见更便宜。规范：帮助隐私和扩容方案。不是这些方案已经上线，也不是已经在验签。
3. 看见本页对照 196/197。规范：更新那两张气价表。不是已经重新加入预编译。
4. 看见官方写不要求换库。规范：够快的算法当时已经在。不是本页已经换库。
5. 看见官方写给通用曲线算术当即时补丁。规范：更先进的方案当时还没落地。不是已经有通用曲线算术。
6. 有人把这听成不变量 199。那是后来的 BLS12-381 预编译，不是已经在验 BLS 签。本页是更早的 bn128 改价。
7. 有人把这听成不变量 116。那是实现把点验错。本页不管子群谓词。
8. 有人把这听成不变量 227。那是模幂换公式。本页是椭圆曲线三条预编译改价。
9. 有人把新旧气价、基准微秒或产品气账抄进不确定。规范：数字是尺子，不是产品常量。

「1108 = 已经换算法 / 便宜 = 已经在验签 / 1108 = 2537 / 1108 = 196 原文 / 便宜 = 隐私产品已经齐」是假学习。

## 6. 和另外几句不是同一句

1. **预编译算术 ≠ 已验 BLS**（不变量 199）：2537 是后来的 BLS12-381 算术。本页是更早的 bn128 改价。
2. **子群过了 ≠ 在曲线上**（不变量 116）：那是实现把点验错。本页不管子群谓词。
3. **模幂重计价 ≠ 已加帽**（不变量 227）：2565 换模幂公式。本页换的是椭圆曲线三条预编译的价。
4. **模幂长度帽 ≠ 已改计价**（不变量 206）：7823 给模幂加帽。本页不管模幂。

不要抄预编译地址、新旧气价、基准微秒、产品气账。不要写怎样拼配对、怎样做机密交易、怎样把状态收成一棵树再上证。不编博物馆页。不另写 19 节。不转规范气价表。196/197 原文、2537、不变量 116 那次洞、通用曲线算术提案是另一对象。2537 精读：[`../crypto/worked-example-bls-precompile-vs-verify.md`](../crypto/worked-example-bls-precompile-vs-verify.md)（不变量 199）。
