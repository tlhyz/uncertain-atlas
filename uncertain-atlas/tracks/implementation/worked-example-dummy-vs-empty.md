# 例：看见多余栈元素不是已经随便填；看见隔离见证不是已经没有这条延展；看见转发策略已经要空 dummy 不是已经是共识

**层次**：共识 / 规范对象。  
**分类**：事实（对象边界）+ 推断（产品）+ 建议（产品）。  
**来源**：Bitcoin [BIP-147](https://github.com/bitcoin/bips/blob/master/bip-0147.mediawiki)（Deployed, Consensus soft fork）。  
**对应课文**：[L1.4](../../courses/level-01-crypto/L01-M04-canonical-encoding.md)、[L3.3](../../courses/level-03-bitcoin/L03-M03-conservative-evolution.md)、[L3.7](../../courses/level-03-bitcoin/L03-M07-segwit-soft-fork.md)。  
**不要写进**：Ethereum 行、L5.1、M5.4、L5.4。本页是「CHECKMULTISIG 多吃的那一个 dummy 必须是空字节」，不是签名已经是严格 DER，也不是 txid 已经等于 wtxid。

## 官方三件事

规范把 dummy 栈元素写成三件独立的共识事，不是「多重签已经验过就已经不可延展」一件事：

1. **看见多余栈元素不是已经随便填，也不是已经合法。**  
   官方写：`OP_CHECKMULTISIG` / `OP_CHECKMULTISIGVERIFY` 在验签之后还会再吃一个多余的栈元素（dummy）。以前这个元素完全不看，换成任何值脚本仍过。本页新增一条共识规则：dummy 必须是空字节数组。别的任何值让脚本立刻为假。本页同时管隔离见证之前的脚本，也管 BIP-141 那种付给见证脚本哈希。看见多重签验过，不是已经看过 dummy。看见 dummy 不是空，不是已经合法。
2. **看见隔离见证 / txid 不能被第三方改不是已经没有这条延展。**  
   官方写：没有隔离见证时，签名延展会改 txid，并让未确认的子交易作废。隔离见证之后，txid 不能被第三方改，但本页这条仍会改 wtxid，并可能降低紧凑块中继的效率。看见隔离见证已经开，不是已经没有 dummy 延展。看见 txid 没变，不是 wtxid 已经没变，也不是紧凑块已经一样快。
3. **看见转发策略已经要空 dummy 不是已经是共识。**  
   官方写：参考客户端一开始就会出兼容的签；这条空 dummy 规则从某次发布起就当转发策略在执行。本页才把它写成共识。官方还写：本页是从 BIP-62 提案里抽出来的。看见转发已经拒，不是块里已经拒。看见 BIP-62 菜谱，不是已经是本页这一条。看见非兼容签能改成兼容，不是已经没有功能损失——官方要求设计古怪脚本的人必须额外注意本页。

激活日程、版本位编号是规范里的取值，本页不抄。

## 官方为什么这样拆

- **dummy ≠ 已经随便填：** 官方把「验签之后多吃一个却不看」写成设计缺陷。
- **隔离见证 ≠ 已经没有这条：** 官方把「仍改 wtxid、仍伤紧凑块」写成独立动机。
- **策略 ≠ 已经共识：** 官方把早就当转发策略执行写成兼容事实，不是共识已经要。

## 和相邻页的边界

| 对象 | 本页 | 那一页 |
|---|---|---|
| dummy | 必须是空字节 | 不是已经随便填 / 已经合法 |
| 隔离见证 | txid 不能被第三方改 | 不是 wtxid 已经不能改 |
| 转发策略 | 可以早就只要空 dummy | 不是共识已经要 |
| 验得过 ≠ 已经是严格 DER | 另一对象 | 不变量 172 |
| txid ≠ wtxid | 另一对象 | 不变量 152 |
| 策略 ≠ 共识 | 另一对象 | 不变量 144 |
| 版本位 ≠ 已经激活 | 另一对象 | 不变量 171 |
| 紧凑块宣布 ≠ 已收到 | 另一对象 | 不变量 36 |

## 产品

**建议（产品，不是事实）**：不确定第一条结算机如果写多重签或多吃栈元素，必须分开验签、dummy、txid、wtxid。可以跳过「看见多重签验过就已经不可延展」。若对照，必须分开空 dummy、策略、共识。不要另写怎样改 dummy 撞身份。

## 本页不抄

- 激活时间、版本位编号、部署名、参考客户端版本号。
- 怎样造非空 dummy、怎样把非兼容签改成兼容、怎样靠改 dummy 挡紧凑块。
