# 工作实例：列入访问列表不是已经访问过

> 对照：[L5.1](../../courses/level-05-ethereum/L05-M01-evm-and-gas.md)、[信封 ≠ 内层](worked-example-typed-vs-legacy.md)、[基础费 ≠ 小费](../mempool/worked-example-basefee-vs-tip.md)、[谓词 ≠ 脚本](../parallelism/worked-example-utxo-access-list.md)、[gas ≠ 墙钟](../failure-museum/ethereum-2021-05-state-gas-not-time.md)。

## 1. 核心问题

阿比看见交易带了访问列表，以为那些地址已经访问过；或看见列表外还能碰，以为规范已经禁止；或看见规范编号 2930，以为就是 2718 信封或 1559 费用市场。

官方句（事实）：

- EIP-2930 增加一种**含访问列表**的交易类型。访问列表是交易**计划访问**的地址和存储键。
- 这是一种 EIP-2718 交易类型；载荷格式由本页定义。依赖 2718 与 2929。
- **列表外仍可访问，只是更贵。**
- 列入的地址和存储键会进本笔的已访问集合。收一笔列表费，相对列表外访问有折扣。
- 执行开始时（与起步 gas 同时）把名单装进已访问集合，并按项收费。
- 重复地址或键**不禁止**；会收多次费。除了更贵，执行流和结果与只列一次没有别的差别。
- 列表**不**按交易数据那种按字节收费。
- 签名罩住类型和交易数据，避免被当成另一种类型再解释。
- 规范**没有**把列入写成已经读过，也没有把列表外写成已经禁止，也没有把本页写成信封或 1559。

计划访问、真正读到、列表外仍能碰，是三件事。

---

## 2. 直觉（ELI15）

出门前列了「打算进哪几家店」，不等于已经进过那些店。  
没写在纸条上的店，仍可以进，只是可能更贵。  
列了两遍同一家，不是已经更熟，只是多付了一次列名费。

---

## 3. 对象

| 名字 | 是什么 | 不是什么 |
|---|---|---|
| 访问列表 | 计划访问的地址和存储键 | 已经读过；已经调用过 |
| 列表外访问 | 仍允许，更贵 | 已经禁止 |
| 列表费 | 执行开始时按项预收 | 已经跑完 SLOAD / EXT* |
| 本页交易类型 | 2718 信封里的一种载荷 | 信封本身；1559 费用市场 |

---

## 4. 最小案例

一条 Ethereum 要对齐「这一口气访问列表是哪一盏灯」。

1. 交易带了访问列表。规范：计划访问。不是已经读过。
2. 执行时碰了没列的槽。规范：可以，更贵。不是已经非法。
3. 同一地址列了两次。规范：收两次费。不是已经更热。
4. 有人把 2930 听成 2718（不变量 167）。2718 是外壳。本页是一种载荷。
5. 有人把 2930 听成 1559（不变量 158）。1559 是费用市场。本页是可选名单。
6. 有人把这听成 Fuel 访问集（不变量 143）。那一页管并行读写。本页管本笔计划访问与气价。
7. 有人把预付列表费听成已经跑完读取。规范：开跑时装集合并收费。付了不是已经读到值。

「带了访问列表所以已经访问过 / 没列入所以已经不能碰 / 2930 所以已经是 1559」是假学习。

## 5. 五层

| 层 | 本页 |
|---|---|
| 密码学 | 签名罩住类型和数据；不是已经是另一种类型 |
| 协议 | 必须点名问的是计划访问、列表外，还是已经读过 |
| 实现 | 开跑时装进本笔已访问集合；两家必须同一把尺子 |
| 部署 | 分叉高度是部署对象，不是已经换完所有钱包 |
| 经济 | 列表费鼓励预声明；不列几乎不亏，不是已经强制 |

**推断：** 产品句若只写「支持访问列表」，读者会把购物清单听成已经逛完。  
**建议：** 第一版必须把计划访问、列表外仍能碰、已经读过三套文案分开。不要发明「列入 = 已经访问」。不要抄气价。不要写怎样生成列表。

## 6. 和另外几句不是同一句

1. **信封 ≠ 内层**（不变量 167）：外壳。本页是一种载荷。
2. **基础费 ≠ 小费**（不变量 158）：费用市场。本页是可选名单。
3. **谓词 ≠ 脚本**（不变量 143）：Fuel 读写集与并行。本页不是并行引擎。
4. **gas ≠ 墙钟**（不变量 101）：本笔未访问对象涨价。本页是可选预填那份集合。
5. **出块者开跑已热 ≠ 169 预填**（不变量 187）：开跑必填出块者。本页是可选名单。

不要抄类型号 / 分叉高度 / 气价 / 例地址。不要写怎样生成列表、怎样灌重复项、怎样靠名单绕过冷访问。不编博物馆页。不另写 19 节。EIP-2929 冷热气价表、1559 载荷里的同名名单、blob 类型是另一对象。冷热集合精读：[`worked-example-cold-vs-warm.md`](worked-example-cold-vs-warm.md)（不变量 169）。出块者开跑预填精读：[`worked-example-coinbase-vs-prefill.md`](worked-example-coinbase-vs-prefill.md)（不变量 187）。
