# 例：看见 Part.index 是这片的下标不是已经有整叠；看见写成 ≥ 0 不是已经有序；看见 Part 表的校验栏不是已经是本对象的校验

**层次**：实现 / 片下标。  
**分类**：事实（官方现状）+ 推断（产品）+ 建议（产品）。  
**来源**：CometBFT 官方 [Core Data Structures](https://github.com/cometbft/cometbft/blob/main/spec/core/data_structures.md) Part。  
**对应课文**：[L4.4](../../courses/level-04-bft/L04-M04-abci-and-wal.md)。  
**不要写进**：Ethereum 行、L5.1、M5.4、L5.4、03 共识图谱、Bitcoin 行、L4.5。本页是「Part.index 是这片的下标不是已经有整叠 / 写成 ≥ 0 不是已经有序 / Part 表的校验栏不是已经是本对象的校验」，不是外层下标必须与证明下标同一对象，也不是带内部长度的结构必须先验再传。不要另写怎样切片。

## 官方三件事

规范把 `Part` 是一片（`index` 是 int32、校验写 `Must be >= 0`）、以及这张表的校验栏写的东西**其实是 `PartSetHeader` 的校验**，写成三件独立的事实，不是「看见下标在就已经有整叠、已经有序、已经按本对象验过」一件事：

1. **看见 `Part.index` / 看见有下标 不是已经有整叠，也不是已经齐。**  
   官方写：`Part` 定义块的一片，CometBFT 把块切成 `parts` 用来流言。看见有下标，不是已经拿到全部片。看见是这一片，不是已经有整叠。看见能填，不是已经交差。
2. **看见校验写 `Must be >= 0` / 看见这条下限 不是已经有序，也不是已经在范围内。**  
   官方给 `Part.index` 的校验只有一条：必须大于等于 0。看见 `>= 0`，不是已经小于总片数。看见过了下限，不是已经有序。看见合法，不是已经落在这一叠里。
3. **看见 Part 表的校验栏 / 看见「长度必须是 32」 不是已经是本对象的校验，也不是已经能照抄。**  
   这张表里 `bytes` 与 `proof` 的校验都写 `Must be of length 32`；而 `proof` 的类型是 `[Proof](#proof)`（一个结构，不是 32 字节）。同一栏里 `index` 的说明写成「Total amount of parts for a block」、`bytes` 与 `proof` 的说明都写成「MerkleRoot of a serialized block」——**这两条说明与它们各自的类型不符**，而「总片数」「序列化块的默克尔根」按下文分别是 `PartSetHeader.Total` 与 `PartSetHeader.Hash` 的语义。看见这张表的校验栏，不是已经是 `Part` 的校验。看见 32 字节，不是已经能照抄到本对象。

怎样切片、怎样算片根、怎样流言是规范里的做法，本页不抄。外层下标必须与证明下标同一对象是不变量 59，本页不抄。带内部长度的结构必须先验再传是不变量 60，本页不抄。

## 官方为什么这样拆

- **有下标 ≠ 已经有整叠：** 一片只是整叠里的一片。
- **`>= 0` ≠ 已经有序：** 那是下限，不是范围上界，也不是顺序保证。
- **Part 表的校验栏 ≠ 本对象的校验：** 该表把 `PartSetHeader` 的校验（32 字节）与说明抄到了 `Part` 的 `bytes` / `proof` 行上。

## 和相邻页的边界

| 对象 | 本页 | 那一页 |

| Part.index 是这片的下标 | 不是已经有整叠 | 不是外层下标与证明下标对不上就可以收（59） |

## 产品

**建议（产品，不是事实）**：不确定第一条结算机如果给人看「看见片下标在就已经有整叠」，必须分开 Part.index 是这片的下标是不是已经有整叠、写成 ≥ 0 是不是已经有序、Part 表的校验栏是不是已经是本对象的校验。**实现里不要照抄 `Part` 表的校验栏与说明栏**——那一栏和它自己的类型不符；要以下文 `PartSetHeader` 的定义为准。可以跳过「看见片下标在就已经有整叠」。不要另写怎样切片。

## 本页不抄

- 怎样切片、怎样算片根、怎样流言。
- 外层下标必须与证明下标同一对象。那是不变量 59。
- 带内部长度的结构必须先验再传。那是不变量 60。
- `PartSetHeader` 是整块的根不是已经是头。那是不变量 442。
