## 1. 核心问题

阿比看见执行块的 RLP 编码被协议写成硬帽，以为气限已经改了；或看见共识层流言不传更大的块，以为执行层已经把这种块判非法；或看见给信标块留了一条边，以为执行编码和信标编码已经并成一份；或看见规范编号 7934，以为就是 7623、1559，或已经是 Sepolia 那次通道尺寸。

官方句（事实）：

- EIP-7934：给执行块的 RLP 编码加一道协议级上限，并且这道上限里已经给信标块留了边。
- 现行协议**没有**对编码后的块大小写死严格上限。没有这道帽，超大块会拖慢传播，提高短暂分叉和重组的风险；对手也可以故意造超大块来砸网络。
- 共识层流言本来就不传超过其对齐上限的块。只靠流言丢弃，可能把网络撕开，或变成拒绝服务。
- 出块者必须保证自己造出的块，RLP 编码后不超过执行层这道帽。节点必须把超过这道帽的块当成非法、拒掉。
- 这道帽**独立于气相关的尺子**。
- 对已经大于新上限的块，本页不向后兼容。出块逻辑必须严格守这道帽。
- 安全段：限制最大块大小，用来挡住故意造超大块。
- 规范**没有**把编码硬帽写成已经改了气限，也没有把共识层流言不传写成执行层已经非法，也没有把给信标块留边写成已经并成一份编码，也没有把本页写成 7623、1559 或不变量 96。

编码硬帽、气限、流言丢弃、通道尺寸，是四件事。

## 2. 直觉（ELI15）

货车过桥要量外廓，不是已经改了按载重收的过路费。  
上游收费站不放行，不是下游已经把这辆车写成违法。  
给拖车头留了一截，不是已经把货车和拖车量成同一把尺子。

## 3. 对象

| 名字 | 是什么 | 不是什么 |
|---|---|---|
| RLP 编码硬帽 | 执行块编码后的协议级字节上限 | 已经改了气限 |
| 共识层流言不传 | 更大的块不会被信标流言传开 | 执行层已经判非法 |
| 给信标块留边 | 执行帽里预留信标块的空间 | 已经并成一份编码 |
| 7934 | 独立于气的编码谓词 | 7623 地板；1559 弹性；96 通道尺寸 |

## 4. 最小案例

一条 Ethereum 要对齐「这一块有没有超过编码帽」。

1. 看见 RLP 编码硬帽。规范：超过这道帽的块非法。不是已经改了气限。
2. 共识层流言不传更大的块。规范：那是传播。不是执行层已经判非法。
3. 给信标块留边。规范：执行帽里预留信标空间。不是已经并成一份编码。
4. 出块者必须守帽，节点必须拒。规范：造和验是同一道谓词。不是已经等于各家 Engine API 的 HTTP 上限。
5. 有人把这听成 7623（不变量 197）。那是 calldata 地板，还走气。本页独立于气。
6. 有人把这听成 1559（不变量 158）。那是基础费、小费和弹性气上限。本页是编码字节。
7. 有人把这听成 96。那是出块通道沿用各家 HTTP 尺寸、多数拒少数收。本页是协议自己写死的编码帽。
8. 有人把这听成 101。那是气不是墙钟。本页是字节，不是时间。

「看见编码帽 = 已经改了气 / 流言不传 = 执行层已非法 / 留边 = 已经并编码 / 7934 = 96」是假学习。

## 6. 和另外几句不是同一句

1. **calldata 地板 ≠ 执行气**（不变量 197）：还走气。本页独立于气，量的是整块 RLP。
2. **出块通道尺寸 ≠ 拼块已齐**（不变量 96）：各家 HTTP / Engine API 上限。本页是协议自己写死的编码帽。
3. **气 ≠ 墙钟**（不变量 101）：计量钉的是气还是时间。本页钉的是编码字节。
4. **基础费 ≠ 小费**（不变量 158）：1559 拆分和弹性气上限。本页不是气市场。
5. **blob 气 ≠ 执行气**（不变量 145）：两套气。本页不是 blob 袋的体积，是执行块 RLP。

不要抄编码上限字节 / 信标边字节 / 十进制字面量。不要写怎样刚好塞进帽下。不编博物馆页。不另写 19 节。EIP-7623 calldata 地板、EIP-1559 弹性气上限、不变量 96 通道尺寸、不变量 101 气≠墙钟是另一对象。单笔气帽不是已经改了块气限，也不是已经是本页这道编码帽（不变量 203）。地板精读：[`worked-example-calldata-floor-vs-execution.md`](worked-example-calldata-floor-vs-execution.md)（不变量 197）。通道尺寸馆藏：[`../failure-museum/ethereum-2024-03-sepolia-engine-rpc.md`](../failure-museum/ethereum-2024-03-sepolia-engine-rpc.md)（不变量 96）。
