# 工作实例：看见代码哈希指令不是已经看见代码

> **事实 / 推断 / 建议** 已分开。
> 对照：[L5.1](../../courses/level-05-ethereum/L05-M01-evm-and-gas.md)、[L2.2](../../courses/level-02-state/L02-M02-account.md)、[空 ≠ 已经不存在](../state-models/worked-example-empty-vs-dead.md)、[发送者已有代码 ≠ 已经能当 EOA 发](../state-models/worked-example-code-sender-vs-eoa.md)、[链号指令 ≠ 已签进哈希](worked-example-chainid-opcode-vs-signed.md)。
> 主文献：[EIP-1052](https://eips.ethereum.org/EIPS/eip-1052) EXTCODEHASH opcode。官方 EIP。核心层。最终标准。依赖 EIP-161。不另写 19 节。

## 1. 核心问题

阿比看见多了一条能读代码哈希的指令，以为已经把对方代码拷出来看过了；或看见返回 0，以为这个账户已经是「没代码」；或看见返回空数据哈希，以为这个地址已经不存在；或看见能读哈希，以为已经读了代码尺寸；或看见规范编号 1052，以为就是 161 的空户规则，或已经是 3607 那页的发送者代码哈希。

官方句（事实）：

- EIP-1052：给 EVM 加一条返回某账户代码 keccak256 哈希的指令。
- 官方写：许多合约要检查另一份字节码，但不一定需要字节码本身。现行做法是整份拷出来，在只要哈希时很贵。看见本页，不是已经拷出代码。
- 官方写：账户不存在，或按 161 是空的，栈上推 **0**。看见返回 0，不是已经能断定「有账户、只是没代码」。
- 官方写：账户没有代码时，推的是**空数据**的 keccak256。看见空数据哈希，不是已经能断定这个地址不存在。
- 官方写：本页把「没代码的账户」和「不存在的账户」分开。这和状态树怎么表示账户一致，也让合约能问账户在不在。看见本页，不是已经改了 161 的空 / 死 / 碰到，也不是已经看见代码。
- 规范**没有**把代码哈希指令写成已经是拷代码，也没有把返回 0 写成已经是没代码，也没有把空数据哈希写成已经不存在，也没有把本页写成 161 或 3607。

拷代码、读尺寸、读哈希、返回 0、返回空数据哈希，是五件事。

## 2. 直觉（ELI15）

仓库门口现在多了一台只报货箱指纹的机器。  
有这台机器，不是你已经打开箱子看过货。  
机器报「零」，不是货架上已经放着一只空箱。  
机器报「空箱指纹」，不是这个货位已经拆掉。  
能报指纹，不是已经量过箱子有多高。

## 3. 对象

| 名字 | 是什么 | 不是什么 |
|---|---|---|
| 代码哈希指令 | 把某账户代码的哈希压进栈 | 已经看见代码本身 |
| 返回 0 | 不存在，或按 161 是空 | 已经是「有账户、没代码」 |
| 返回空数据哈希 | 账户在，但没有代码 | 已经是账户不存在 |
| 1052 | 合约内读代码哈希 | 161；3607；读尺寸；拷代码 |

## 4. 最小案例

一条 Ethereum 要对齐「这一口气代码还停在哪一层」。

1. 看见多了一条代码哈希指令。规范：只要哈希、不必整份拷。不是已经看见代码。
2. 看见返回 0。规范：不存在，或按 161 是空。不是已经能写成「没代码的账户」。
3. 看见返回空数据哈希。规范：账户没有代码。不是已经能写成这个地址不存在。
4. 看见动机写可以问账户在不在。规范：这是和状态树表示一致的副作用。不是已经改了 161 的空 / 死 / 碰到。
5. 有人把这听成不变量 180。那是空、不存在、死三盏灯。本页只是读哈希时怎么用那两盏灯。
6. 有人把这听成不变量 162。那是发送者代码哈希是不是空，用来挡已有代码的发起者。本页是任意地址的读数指令。
7. 有人把操作码号、空代码哈希字面量或气价抄进不确定。规范：字面量和计价档是尺子，不是产品常量。

「EXTCODEHASH = 已经看见代码 / 返回 0 = 没代码 / 空数据哈希 = 不存在 / 1052 = 161 / 1052 = 3607」是假学习。

## 5. 五层

| 层 | 本页 |
|---|---|
| 密码学 | 读的是代码的哈希，不是已经换了签算法，也不是已经看见代码 |
| 协议 | 必须点名问的是拷代码、读尺寸、读哈希、返回 0，还是空数据哈希 |
| 实现 | 不存在或 161 空推 0；没代码推空数据哈希；和状态树表示一致 |
| 部署 | 官方写没有向后兼容问题；看见本页不是已经改了 161 |
| 经济 | 只要哈希时不必付整份拷的代价；看见本页不是已经改了费用市场 |

**推断：** 产品句若只写「能读代码哈希所以已经看见代码」，读者会把指纹听成开箱，或把 0 听成「没代码」、把空数据哈希听成「不存在」。  
**建议：** 第一版可以不加这条读数指令。若对照，必须分开拷代码、读尺寸、读哈希、返回 0、空数据哈希。可以跳过「看见代码哈希就已经看见代码」。221 EXTCODEHASH vs copy bundled unbundling 完成（1392 item 1 / 1393 item 2 / 1394 item 3）；精读 [`worked-example-xhash-notsee-vs-bundled.md`](worked-example-xhash-notsee-vs-bundled.md)（不变量 1392 item 1）、[`worked-example-xhash-notzero-vs-bundled.md`](worked-example-xhash-notzero-vs-bundled.md)（不变量 1393 item 2）、[`worked-example-xhash-notmiss-vs-bundled.md`](worked-example-xhash-notmiss-vs-bundled.md)（不变量 1394 item 3）。不要发明「看见 1052 就已经是 161」。不要抄操作码号、气价或空代码哈希字面量。不要写怎样探存在、按哈希白名单实现或整份拷代码。

## 6. 和另外几句不是同一句

1. **空 ≠ 已经不存在**（不变量 180）：161 定义空、死、碰到。本页读哈希时用「不存在或空 → 0」「没代码 → 空数据哈希」。
2. **发送者已有代码 ≠ 已经能当 EOA 发**（不变量 162）：3607 看发送者代码哈希是不是空。本页是任意地址的读数指令。
3. **后来的 SELFDESTRUCT ≠ 账户已经删掉**（不变量 160）：自毁当笔的哈希怎么变，规范另列测试，不是本页已经改了自毁。
4. **链号指令 ≠ 已经是签进哈希的链号**（不变量 220）：另一条读配置的指令。本页读的是代码哈希。

不要抄操作码号、气价、空代码哈希字面量、位宽、测试向量。不要写怎样探账户是否存在、怎样按哈希白名单实现、怎样整份拷代码。不编博物馆页。不另写 19 节。不转规范代码。拷代码、读尺寸、161 空户规则、3607 发送者规则是另一对象。空户精读：[`../state-models/worked-example-empty-vs-dead.md`](../state-models/worked-example-empty-vs-dead.md)（不变量 180）。

看见空数据哈希 ≠ 已经是账户不存在
