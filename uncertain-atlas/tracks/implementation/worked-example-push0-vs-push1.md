## 1. 核心问题

阿比看见多了一条专门压常数零的指令，以为已经是「带立即数再压一个零」；或看见规范写没有立即数，以为跳转目的分析已经改了；或看见已经部署的合约碰巧用了这个字节，以为分叉后行为还一样；或看见有人用程序计数 / 内存尺寸 / 调用数据长度等凑零，以为那些已经是常数零；或看见规范编号 3855，以为就是 5656，或已经是数前导零那条新操作码。

官方句（事实）：

- EIP-3855：给 EVM 加一条把常数 0 压进栈的指令。
- 官方写：许多指令要偏移，不少场合偏移就是零。今天可以用「带立即数再压一个零」做到，运行时更贵，编码也多一个字节。
- 官方写：因为贵，不少人改用别的指令凑同一效果。常见例子包括程序计数、内存尺寸、调用数据长度、返回数据长度、代码长度、调用附带值、自身余额。其中有的更便宜、也只有一个字节，但它们的值可以随上下文变。
- 官方写：动机包括缩小代码、降低把这些指令当优化手段的风险（以后改价或改语义会更险），以及减少为了复制零而去复制栈项。
- 官方举过一个风险例子：以后若改「返回数据长度」在新调用帧开头是不是保证为零，那些靠它凑零的合约会受伤。看见本页，不是已经改了返回数据长度。
- 气价走「把常数值压进栈」那一档，和取地址、取来源等同一档。看见本页，不是已经改了那些指令的计价。
- 操作码位置和其余压栈指令挨着，实现上也许能共用。看见本页，不是已经共用实现。
- 向后：这是以前没有的新指令。已经部署、碰巧用了这个字节的合约，分叉后行为可能变。
- 安全段：作者不知道对安全有冲击。官方写跳转目的分析不受影响，因为本页没有立即数字节。看见没有立即数，不是已经改了跳转目的分析。
- 规范**没有**把本页写成已经是带立即数的压 0，也没有把没有立即数写成已经改了跳转分析，也没有把旧字节写成行为已经不变，也没有把上下文相关凑零写成已经是常数零。

压零指令、带立即数的压 0、没有立即数、跳转目的分析，是四件事。

## 2. 直觉（ELI15）

以前要在练习册上先写「压一个数」，再在旁边写那个数是 0。  
本页给了一张印好 0 的卡片，旁边不用再写数字。  
有卡片，不是旧那两格已经删掉。  
卡片旁边没有空格，不是老师改了「哪些格子是跳转落点」的批改规则。  
有人用「现在写到第几行」来冒充 0。那一行号会变，不是印好的 0。

## 3. 对象

| 名字 | 是什么 | 不是什么 |
|---|---|---|
| 压零指令 | 把常数 0 压进栈，没有立即数 | 已经是带立即数的压 0 |
| 没有立即数 | 指令后面不跟要吃掉的数据字节 | 已经改了跳转目的分析 |
| 已经部署碰巧用了这个字节 | 旧代码里这个码以前是别的意思 | 分叉后行为已经不变 |
| 3855 | 专用常数零 | 5656 的内存拷；数前导零 |

## 4. 最小案例

一条 Ethereum 要对齐「这一口气零还停在哪一层」。

1. 看见多了一条压零指令。规范：把常数 0 压进栈。不是已经是带立即数的压 0。
2. 看见规范写没有立即数。规范：跳转目的分析不受影响。不是分析规则已经改了。
3. 看见官方写已经部署、碰巧用了这个字节。规范：分叉后行为可能变。不是旧合约已经安全。
4. 看见有人用程序计数或返回数据长度凑零。规范：那些值可以随上下文变。不是已经是常数零。
5. 有人把这听成不变量 216。那是内存拷。本页是压常数零。
6. 有人把这听成不变量 208。那是数前导零。本页不数位。
7. 有人把气价或栈深测试向量抄进不确定。规范：计价档和测试是尺子，不是产品常量。

「PUSH0 = 已经是带立即数的压 0 / 没有立即数 = 已经改了跳转分析 / 3855 = 5656 / 3855 = 7939」是假学习。

## 6. 和另外几句不是同一句

1. **内存拷 ≠ 已经是身份预编译**（不变量 216）：另一条新指令，只动内存。本页是压常数。
2. **数前导零 ≠ 已经更便宜的 ZK**（不变量 208）：另一条新操作码。本页不数位。
3. **initcode 超界 ≠ 已经是部署代码超界**（不变量 176）：创建计量。本页不改创建界。
4. **新代码以保留首字节开头 ≠ 已经是对象格式**（不变量 188）：保留首字节。本页是栈上的常数零。

不要抄操作码号、气价、百分比、块号区间、浪费字节统计、栈深测试向量、规范提交哈希。不要写怎样在旧字节上赌分叉后行为。不编博物馆页。不另写 19 节。不转规范代码。带立即数的压 0、跳转目的分析、上下文相关凑零、内存拷、数前导零是另一对象。内存拷精读：[`worked-example-mcopy-vs-identity.md`](worked-example-mcopy-vs-identity.md)（不变量 216）。
