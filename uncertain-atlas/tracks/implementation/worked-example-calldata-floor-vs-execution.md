# 工作实例：calldata 地板不是已经改了执行气

> **事实 / 推断 / 建议** 已分开。
> 对照：[L5.1](../../courses/level-05-ethereum/L05-M01-evm-and-gas.md)、[blob 气 ≠ 执行气](../light-clients/worked-example-blob-fee-vs-gas.md)、[基础费 ≠ 小费](../mempool/worked-example-basefee-vs-tip.md)、[initcode ≠ 运行时代码](worked-example-initcode-vs-runtime.md)。
> 主文献：[EIP-7623](https://eips.ethereum.org/EIPS/eip-7623) Increase calldata cost。官方 EIP。核心层。不另写 19 节。
> 本页钉 **看见 calldata 地板 ≠ 已经改了执行气**、**数据为主更贵 ≠ 已经让普通转账更贵**、**预留地板气限 ≠ 已经烧到地板**、**EIP-7623 ≠ EIP-4844 ≠ EIP-1559 ≠ EIP-2028**。不抄标准 token 成本 / 地板每 token / 旧最大载荷 / 平均块 / 气限除以旧非零字节成本。不写怎样堆零字节载荷、怎样停在 EVM 比例阈值下继续走便宜 calldata、也不写怎样把一笔数据交易和一笔计算交易捆在一起躲开地板。

## 1. 核心问题

阿比看见 calldata 地板，以为普通执行气已经改了；或看见数据为主的交易更贵，以为普通转账也已经更贵；或看见气限必须预留地板，以为已经烧到地板；或看见规范编号 7623，以为就是 4844、1559 或 2028。

官方句（事实）：

- EIP-7623：提高**主要以 calldata 贴数据**的交易的 calldata 成本，用来压最大块大小与方差，同时不伤普通用户。
- 现行 calldata 定价允许很大的执行层载荷，平均块却小得多。气限自 [EIP-1559](https://eips.ethereum.org/EIPS/eip-1559) 以来未再抬；calldata 成本自 [EIP-2028](https://eips.ethereum.org/EIPS/eip-2028) 以来未改。[EIP-4844](https://eips.ethereum.org/EIPS/eip-4844) 让 blob 成为更合适的数据可用性；本页因此重估 calldata 定价。
- 地板成本取决于**花在 EVM 操作上的气与 calldata 的比例**。
- 新的 `tx.gasUsed` 是基础气加上「旧内在+执行路径」与「地板 × calldata token」二者的**较大值**。
- calldata token 把零字节与非零字节按不同权重计数。
- `execution_gas_used` 是 EVM 执行气、**再减去退款**。
- 气限低于「基础气 + 地板 × token」**或**低于内在气（取较大者）的交易**无效**。即便实际 `gasUsed` 可以落在地板之下，气限也**必须预留地板**。
- 不以 calldata 为主做数据可用性的普通用户可以不受影响；有显著 EVM 计算的交易仍走旧的零/非零字节路径。
- 钱包与 `eth_estimateGas` **必须**把地板算进去，否则会低估，交易失败。
- 把两笔相反的交易捆在一起本来就能做（账户抽象可以省掉一笔基础气）；对本页的块大小目标**不是显著担忧**。
- 规范**没有**把地板写成已经改了普通执行气，也没有把数据为主更贵写成已经让普通转账更贵，也没有把预留气限写成已经烧到地板，也没有把本页写成 4844、1559 或 2028。

地板、旧执行路径、气限预留，是三件事。

## 2. 直觉（ELI15）

货车按载重收过路费，不是已经改了小轿车的票价。  
门口先问你预留了多重的保证金，不是已经按最重那档把钱收走。  
旁边另开了一条拖车专用道，不是这道门槛已经把拖车并进了轿车道。

## 3. 对象

| 名字 | 是什么 | 不是什么 |
|---|---|---|
| calldata 地板 | 数据为主的交易走的下限气 | 已经改了普通执行气 |
| 旧零/非零字节路径 | 有显著 EVM 计算时仍走的那条 | 已经让普通转账更贵 |
| 气限必须预留地板 | 门槛写在 gas limit 上 | 已经烧到地板 |
| 7623 | 重估 calldata 定价 | 4844 blob 气；1559 拆分；2028 旧 calldata 价 |

## 4. 最小案例

一条 Ethereum 要对齐「这一口气 calldata 卡在哪」。

1. 看见地板公式。规范：对数据为主的交易取较大值。不是已经改了普通执行气。
2. 一笔普通转账几乎不贴数据。规范：可以仍走旧路径。不是已经让普通转账更贵。
3. 气限必须盖住地板。规范：预留不够则整笔无效。不是已经按地板把气烧完。
4. 实际 `gasUsed` 可以低于地板。规范：气限仍须预留。不是已经烧到地板。
5. 有人把这听成 4844（不变量 145）。那是另一套 blob 气。本页是执行气上的 calldata 地板。
6. 有人把这听成 1559（不变量 158）。那是基础费与小费。本页不改那套拆分。
7. 有人把这听成 3860（不变量 176）。那是 initcode 上界 / 字成本，是旧内在路径的输入，不是本页地板。

「看见地板 = 已经改了执行气 / 数据为主更贵 = 普通转账也更贵 / 预留了 = 已经烧到 / 7623 = 4844」是假学习。

| 层 | 本页 |

| 密码学 | 无新原语 |

**推断：** 产品句若只写「gas 更贵了」，读者会把数据为主的上限听成已经改了普通执行气，或把预留听成已经烧到。  
**建议：** 第一版若做 DA 定价，必须分开 calldata 地板、blob 气、1559 拆分、3860 字成本。不要发明「看见地板就已经改了执行气」。不要抄参数。不要把 7623 写成 4844。

## 6. 和另外几句不是同一句

1. **blob 气 ≠ 执行气**（不变量 145）：另一套气、另一套目标。本页重估的是 calldata 地板。抬高 blob 日程不是已经改了两套气，也不是已经 PeerDAS（不变量 200）。blob 底价不是已经并账，也不是已经是本页这道地板（不变量 201）。编码硬帽不是已经改了气限，也不是已经是本页这道地板（不变量 202）。单笔气帽不是已经改了块气限，也不是已经是本页这道地板（不变量 203）。
2. **基础费 ≠ 小费**（不变量 158）：1559 拆分。本页不改 tip / basefee；气限自 1559 以来未再抬是动机，不是已经改了 basefee。
3. **initcode ≠ 运行时代码**（不变量 176）：3860 是旧内在路径的输入，不是本页地板。
4. **气 ≠ 墙钟**（不变量 101）：本页改的是 calldata 会计，不是把气写成秒。
5. **请求承诺 ≠ 已处理**（不变量 192）：7685 是执行层往共识层递条子。本页是执行气会计。

不要抄标准 token 成本 / 地板每 token / 旧最大载荷 / 平均块 / 气限除以旧非零字节成本。不要写怎样堆零字节载荷、怎样停在 EVM 比例阈值下、或怎样把数据交易和计算交易捆在一起躲开地板。不编博物馆页。不另写 19 节。EIP-4844 blob 气、EIP-1559 拆分、EIP-2028 旧 calldata 价、EIP-3860 initcode 界是另一对象。blob 气精读：[`../light-clients/worked-example-blob-fee-vs-gas.md`](../light-clients/worked-example-blob-fee-vs-gas.md)（不变量 145）。基础费精读：[`../mempool/worked-example-basefee-vs-tip.md`](../mempool/worked-example-basefee-vs-tip.md)（不变量 158）。
