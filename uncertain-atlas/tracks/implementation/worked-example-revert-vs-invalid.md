## 1. 核心问题

阿比看见合约失败，以为失败就是把剩下的气烧光；或看见规范写了回滚，以为已经和非法指令同一盏灯；或看见返回了一句原因，以为创建已经部署；或看见编号 140，以为就是空账户 OOG 那次分叉，或已经是另一条链的 `REVERTED` 档。

官方句（事实）：

- EIP-140：增加一道指令，用来停执行、撤回到此为止的状态改动，并且能指回一段内存当原因。这样做时，**不把剩下的气烧光**。
- 本页之前，合约里实际能回滚的两条路是：气耗尽，或执行一条非法指令。这两条都会把剩下的气烧光。另外，回滚会丢掉日志，也没有办法把失败原因带出去。
- 这道指令对内存和内存费的语义，与正常返回相同。回滚本身不把气烧光；合约只付内存那笔。
- 剩下的气不够付这道指令自己的费，或栈不够：效果等于普通气耗尽，会把气烧光。这不是已经按「带回剩余气」那盏灯走。
- 和别的失败一样，被调方走了这道回滚，调用方栈上得到 0。
- 创建上下文里走这道回滚：不部署代码，栈上推 0，原因仍在返回缓冲里。
- 那段内存里写什么，本页**没有**定义。
- 规范**没有**把「失败」写成已经烧光剩余气，也没有把不够付自己的费写成已经留下剩余气，也没有把本页写成空账户 OOG 回滚或另一条链的执行档。

带回剩余气的回滚、烧光剩余气的失败、已经部署，是三件事。

## 2. 直觉（ELI15）

柜台发现填错，把本子改回去，并把剩下的工时退你，还可以在回单上写一句「哪里错了」。  
以前只能把工时耗尽，或故意摔坏机器停工——两种都会把剩下的工时烧光，条子上也写不出原因。  
如果连写回单的工时都不够，那就还是按「工时耗尽」算，不是已经享受退工时。

## 3. 对象

| 名字 | 是什么 | 不是什么 |
|---|---|---|
| 带回剩余气的回滚 | 停、撤状态、可带原因、剩下的气留下 | 已经把剩余气烧光 |
| 烧光剩余气的失败 | 气耗尽或非法指令 | 已经是本页这道回滚 |
| 不够付自己的费 | 效果等于普通气耗尽 | 已经按回滚语义留下剩余气 |
| 创建里回滚 | 不部署；原因仍可看 | 已经占址；已经是另一条链的执行档 |

## 4. 最小案例

一条 Ethereum 要对齐「这一口气失败卡在哪」。

1. 合约走本页这道回滚。规范：状态撤回，原因可看，剩下的气留下。不是已经烧光。
2. 合约走非法指令或气耗尽。规范：也会停、也会撤，但剩下的气烧光。不是已经是本页。
3. 剩下的气不够付这道回滚自己的费。规范：等于普通气耗尽。不是已经留下剩余气。
4. 创建里走这道回滚。规范：不部署。不是已经占址。
5. 有人把这听成不变量 103。那是气耗尽时空账户删除有没有撤干净。本页是失败要不要烧光剩余气。
6. 有人把这听成另一条链的 `REVERTED` 档（不变量 138）。那是租户执行轴。本页是 EVM 这一口气怎么停。
7. 有人把这听成 3860（不变量 176）。那是构造代码有多长。本页是失败怎么停。

「失败 = 已经烧光 / 回滚 = 非法指令 / 140 = 103」是假学习。

## 6. 和另外几句不是同一句

1. **OOG ≠ 空户已回滚**（不变量 103）：气耗尽时某一种删除撤没撤干净。本页是失败要不要烧光剩余气。
2. **瞬时 ≠ 持久**（不变量 159）：帧回滚撤瞬时店。本页不是那份店还在不在。
3. **initcode ≠ 运行时代码**（不变量 176）：构造代码有多长。本页是失败怎么停。
4. **两层 accepted**（不变量 138）：租户执行档可以叫 `REVERTED`。本页是 EVM 指令。
5. **静态 ≠ view**（不变量 178）：这面旗开不开。本页是失败要不要留下剩余气。

不要抄操作码号 / 分叉高度 / 例气数 / 例返回字节。不要写怎样挑回滚或非法指令去留气或烧气。不编博物馆页。不另写 19 节。空账户 OOG 分叉、Starknet `REVERTED`、回滚原因编码是另一对象。
