# 例：看见 Testnet 4 不是已经是 Testnet 3；看见 20 分钟例外不是已经没有块风暴；看见会 Testnet 3 不是已经能安全跟 Testnet 4

**层次**：应用 / 规范对象。  
**分类**：事实（对象边界）+ 推断（产品）+ 建议（产品）。  
**来源**：Bitcoin [BIP-94](https://github.com/bitcoin/bips/blob/master/bip-0094.mediawiki)（Deployed, Applications, Specification）。  
**对应课文**：[L3.6](../../courses/level-03-bitcoin/L03-M06-testing-and-culture.md)。  
**不要写进**：Ethereum 行、L5.1、03 共识、M5.4、L5.4。本页是「Testnet 4 不是已经是 Testnet 3 / 20 分钟例外不是已经没有块风暴」，不是 signet 已经是 testnet，也不是头上工作量已经签过。不要另写怎样挖最低难度或怎样造块风暴。

## 官方三件事

规范把 Testnet 4 写成三件独立的测试网事，不是「看见又一条测试网就已经换完、就已经和主网同一套」一件事：

1. **看见 Testnet 4 / 看见测试币 不是已经是 Testnet 3，也不是已经是主网，也不是已经没价值。**  
   官方写：本页是一条新的测试网，目标是替换 Testnet 3。共识规则有几处小而要紧的改动，好让只靠 CPU 挖矿去打这条网变得不实际。官方另引：Testnet 3 跑了很多年，出块奖励已经薄到发测试币不再好用；难度会定期被打回最低，再掀块风暴。测试币被拿去空投、被买卖，有人说「测试币不该有价值」这条底已经被破。看见 Testnet 4，不是已经是 Testnet 3。看见测试币，不是已经没人当钱。看见规则更近主网，不是已经是主网结算。
2. **看见 20 分钟例外 / 看见最低难度 不是已经没有块风暴，也不是已经拿掉了例外。**  
   官方写：Testnet 3 那条 20 分钟例外本页还留着。难度周期里除了第一块，若时间戳比上一块晚过规定窗，这块必须用最低难度；每一周期的第一块必须用当时网上的真实难度。块风暴的修法是：跨周期调难度时，基数必须取上一周期的**第一块**，不得再取上一周期的最后一块。拿掉 20 分钟例外有人提过，评审认为它还让 CPU 能往前推链，所以没拿。看见还能出最低难度块，不是风暴已经没了。看见留着例外，不是已经改成主网那套难度。
3. **看见和主网同一套共识 / 看见会 Testnet 3 不是已经是同一条网，也不是已经能安全跟 Testnet 4。**  
   官方写：Testnet 4 跟主网同一套共识，只加这三条例外；当时主网上已经激活的软分叉，从创世起就强制。会 Testnet 3 的软件，理论上只要补网络参数就能跟 Testnet 4。可是只实现 Testnet 3 规则的节点，会收下违反 Testnet 4 的链，因而会被分叉甩开。官方建议按 Testnet 4 的新规则验块，不合就拒。第三条例外是防时间扭曲：每一难度周期的第一块，时间还要过一道比上一块不得早太多的门，并且仍要遵守已有的中位时间限制。看见补了参数，不是已经在验新规则。看见创世不同，不是已经不必再验。看见和主网同一套软分叉，不是已经是同一条网。

创世哈希、消息起始字节、端口、难度常数、时间窗数字是规范里的取值，本页不抄。

## 官方为什么这样拆

- **Testnet 4 ≠ 已经是 Testnet 3：** 官方把替换、测试币被买卖、块风暴写成换网的理由，不是改个名字。
- **20 分钟例外 ≠ 已经没有风暴：** 官方把例外留下和改取上一周期第一块写成两件独立的事。
- **会 Testnet 3 ≠ 已经能跟：** 官方把「补参数就能连」和「只验旧规则会被甩开」写成两道门。

## 和相邻页的边界

| 对象 | 本页 | 那一页 |
|---|---|---|
| Testnet 4 | 不是已经是 Testnet 3 | 不是已经是 signet（265） |

## 产品

**建议（产品，不是事实）**：不确定第一条结算机如果写测试网，必须分开 Testnet 3 式风暴、本页留下的例外、只验旧规则会被甩开。可以跳过「看见又一条测试网就已经换完」。若对照，必须分开换网、例外还在、参数不是已经验新规则。不要另写怎样挖最低难度或怎样造块风暴。

## 本页不抄

- 创世哈希、消息起始字节、端口、难度常数、时间窗数字、创世十六进制。
- 怎样挖最低难度、怎样按例外出块、怎样造块风暴、怎样做时间扭曲。
