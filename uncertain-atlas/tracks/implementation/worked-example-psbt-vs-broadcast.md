# 工作实例：看见部分签名包不是已经是网上能广播的交易

## 1. 核心问题

阿比看见钱包导出一份「部分签名交易」，以为已经是网上能广播的那笔；或看见里面有几张签，以为这一输入已经凑齐；或看见两份包能合并，以为已经抽出网络序列化；或看见规范编号 174，以为就是地址那一页，或已经是替换信号。

官方句（事实）：

- BIP-174：一种二进制交易格式。里面有签名人要出签所需的信息，也在某一输入**还没凑齐**签名集时，先把已有的签放进去。签名人可以离线：该知道的都在这份格式里。
- 目的是让不同钱包能把同一笔未完成交易传来传去签名、再合并。也让离线签名人不必直接碰 UTXO 集。
- 角色分开。创建者放进一笔未签名交易，输入输出栏先空着。更新者补信息。签名人出签。合并者把同一笔的多份包合成一份；**不得**把两笔不同的包合成一份。输入收尾者：某一输入数据够了，才写出收尾脚本。交易抽出者：所有输入都齐了，才编出网上那种完整序列化；没齐就**不得**改这份包。
- 全局那笔未签名交易：各输入的 scriptSig 和见证必须空着，而且必须用旧序列化（不含见证）。
- 合并者不必会解释脚本，也能合并。抽出者也不必会解释脚本才能抽出；它可以顺便验，但那不是已经广播。
- 规范**没有**把「看见这份包」写成已经是网上那笔，也没有把「有几张签」写成输入已经凑齐，也没有把本页写成地址编码或替换信号。

部分签名包、凑齐的输入、网上能广播的完整交易，是三件事。

---

## 2. 直觉（ELI15）

一叠会签文件在信封里传来传去，还不算出门的公函。  
信封里已经有两个人签了，不等于这一栏已经签满。  
把两叠同一份文件的签字合到一封，不等于已经盖章寄出。

---

## 3. 对象

| 名字 | 是什么 | 不是什么 |
|---|---|---|
| 部分签名包 | 传来传去的签名工作格式 | 已经是网上能广播的完整交易 |
| 输入还没凑齐 | 这一输入的签名集不完整 | 已经能收尾；已经能抽出 |
| 合并 | 同一笔的多份包合成一份 | 已经抽出；已经把两笔不同的合成一份 |
| 抽出 | 所有输入齐了才编网上那种序列化 | 已经广播；已经进块 |

---

## 4. 最小案例

一条 Bitcoin 要对齐「这一口气签名卡在哪」。

1. 创建者放进未签名交易。规范：scriptSig 和见证空着。不是已经签完。
2. 签名人加了几张签。规范：这一输入可以仍没凑齐。不是已经能抽出。
3. 合并者把同一笔的两份包合成一份。规范：可以合并。不是已经抽出，也不是可以把两笔不同的合成一份。
4. 输入还没齐。规范：抽出者不得改这份包。不是已经是网上那笔。
5. 抽出者编出网络序列化。规范：这是完整交易字节。不是已经广播，不是已经进块。
6. 有人把这听成 173 地址（不变量 174）。那是收款写法。本页是签名工作格式。
7. 有人把这听成替换信号（不变量 166）。那是愿不愿意被换。本页是签到哪一步。

「看见 PSBT = 已经能广播 / 有签 = 已经凑齐 / 174 = 173」是假学习。

## 5. 五层

| 层 | 本页 |
|---|---|
| 密码学 | 无新原语；签名算法仍是原来的 |
| 协议 | 必须点名问的是工作包、某一输入是否凑齐，还是网上那笔 |
| 实现 | 两家必须同一套角色：没齐不得抽出，不同笔不得合并 |
| 部署 | 应用层；不是共识软分叉 |
| 经济 | 离线签名人有 UTXO 信息不是已经花掉 |

**推断：** 产品句若只写「支持 PSBT」，读者会把信封里的会签听成已经寄出。  
**建议：** 第一版若做多方签名，必须分开工作包、凑齐、抽出、广播。不要发明「导出了 = 已经能上链」。不要抄类型号。不要把 174 写成 173。

---

## 6. 和另外几句不是同一句

1. **地址 ≠ 已有输出**（不变量 174）：收款写法。本页是签名工作格式。
2. **信号 ≠ 已换**（不变量 166）：愿不愿意被换。本页是签到哪一步。
3. **txid ≠ wtxid**（不变量 152）：身份哈希。本页未签名交易必须用旧序列化、见证为空。
4. **策略 ≠ 共识**（不变量 144）：池子收不收。本页抽出之后才谈广播。

不要抄魔法头 / 类型号 / 例工作流。不要写怎样拼未签包去冒充已签，或怎样做多方拼凑付款。不编博物馆页。不另写 19 节。BIP-173 地址、BIP-125 替换、后续 PSBT 版本字段是另一对象。

## 精密检查

**禁止假学习：** 「看见 PSBT = 已经能广播。」「有签 = 已经凑齐。」「合并了 = 已经抽出。」「抽出 = 已经上链。」「174 = 173。」  
**边界：** 不抄类型号。不另写 19 节。不写怎样拼包。地址见 **C178**。替换见 **C170**。
