- **Set to 0 not decided / finality ≠ 362 finwhen / 610 notdecides / 479 fintrigger interchangeable：** 官方把 set to 0 语义和已经决定 / When 触发分开。
- **Set to 0 not block interval / slot ≠ 385 block interval / 613 notaftercommit / 593 finh1 interchangeable：** 官方把 589 item 3 和块间隔 / after committing not slot 分开。
- **Set to 0 not fndelay bundled ≠ 617 notslot / 618 notwallclock / 480 finmorepre interchangeable：** 官方把 589 item 3 和 item 1 / item 2 / 480 finmorepre 分开；589 fndelay unbundling 完成。
