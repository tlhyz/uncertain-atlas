## 官方为什么这样拆

- **after committing before next height not slot ≠ 385 block interval / 593 finh1 interchangeable：** 官方把 Commit 后再开下一高的等待和块间隔 / 槽位参数分开。
- **after committing / set to 0 not final ≠ 589 set to 0 / 362 finwhen interchangeable：** 官方把 480 item 3 和 set to 0 when all precommits processed、已经决定分开。
- **after committing before next height not finmorepre bundled ≠ 611 notproctime / 612 notmorepre / 1s constant interchangeable：** 官方把 480 item 3 和 item 1 / item 2 / 规范示例秒数分开。
