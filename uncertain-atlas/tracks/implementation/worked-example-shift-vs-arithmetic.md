## 1. 核心问题

阿比看见三条原生移位，以为 EVM 从前用乘除拼出来的移位已经算齐了；或看见算术右移，以为已经和有符号除同一条舍入；或看见更便宜、主机更省，以为位域打包产品已经上线；或看见规范编号 145，以为旧字节码行为已经变了。

官方句（事实）：

- EIP-145：引入原生按位移位指令。官方写：主机上更省处理，合约用起来也更便宜。看见更便宜，不是已经有一套位域打包产品。
- 官方写：EVM 当时缺移位算子，但已经有其它逻辑和算术算子。看见已有加减乘除，不是已经有移位。
- 官方写：移位可以用算术拼出来，但更贵，也更吃主机时间。看见能拼，不是已经是同一条指令。
- 官方写：左移把值按无符号左移；逻辑右移按无符号右移并补零；算术右移把值当有符号、移位量当无符号，并做符号扩展。看见三条指令，不是已经只有一条「移位」。
- 官方写：移位量达到或超过字宽时，左移和逻辑右移得 0；算术右移在非负时得 0、在负时填满符号位。看见超字宽，不是已经未定义。
- 官方写：算术右移和用有符号除拼出来的右移不是同一条，舍入不同。看见能用有符号除拼，不是已经是算术右移。
- 官方写：操作数顺序按「栈上已有的值再移」来排，和多数算术指令相反。看见能移位，不是已经和加减同一套操作数顺序。
- 官方写：新指令不影响过去已经生成的字节码。看见本页，不是旧合约行为已经变了。
- 规范**没有**把原生移位写成已经用算术拼过，也没有把算术右移写成已经是有符号除，也没有把更便宜写成位域产品已经齐，也没有把本页写成已经改了旧字节码。

原生移位、算术拼移位、算术右移、已经是位域产品，是四件事。

## 2. 直觉（ELI15）

厨房里本来能用勺子一下一下拨米，现在多了一把铲子。  
铲子不是勺子已经算铲子；往右拨带符号的那一下，也不是用除法勺出来的那一勺。  
铲子更省力，不是米已经装进袋子。旧菜谱上的字，也不会因为新铲子自己改掉。

## 3. 对象

| 名字 | 是什么 | 不是什么 |
|---|---|---|
| 原生移位 | 左移、逻辑右移、算术右移三条指令 | 已经用乘除拼过移位 |
| 算术右移 | 有符号值、无符号移位量、符号扩展 | 已经是有符号除 |
| 更便宜 / 更省主机 | 原生指令的动机 | 已经是位域打包产品 |
| 145 | 新加三条移位 | 已经改了旧字节码 |

---

## 4. 最小案例

一条 Ethereum 要对齐「这一口气移位在管什么」。

1. 看见原生移位。规范：当时缺移位算子。不是已经有移位。
2. 看见能用算术拼。规范：能拼，但更贵、更吃主机。不是已经是同一条指令。
3. 看见算术右移。规范：和有符号除舍入不同。不是已经是有符号除。
4. 看见更便宜、主机更省。规范：这是动机。不是位域打包已经上线。
5. 看见新指令。规范：不影响过去已经生成的字节码。不是旧合约已经变了。
6. 有人把这听成不变量 208。那是数前导零。本页是移位。
7. 有人把这听成不变量 217。那是压零。本页不压立即数。
8. 有人把这听成不变量 230。那是哈希压缩积木。本页是按位移动。
9. 有人把操作码号、气价档、测试向量或拼指令序列抄进不确定。规范：数字是尺子，不是产品常量。

「145 = 已经用算术拼过 / 算术右移 = 已经是有符号除 / 更便宜 = 位域已经齐 / 145 = 旧字节码已经变」是假学习。

## 5. 五层

| 层 | 本页 |
|---|---|
| 密码学 | 移位不是哈希，也不是数前导零 |
| 协议 | 必须点名问的是原生移位、算术拼移位、算术右移，还是已经是位域产品 |
| 实现 | 超字宽有规定结果；算术右移和有符号除舍入不同 |
| 部署 | 新指令不影响旧字节码；看见本页不是旧合约已经变了 |
| 经济 | 更便宜不是位域打包已经免费 |

**推断：** 产品句若只写「以太坊终于能移位了」，读者会把算术拼听成已经齐，或把算术右移听成已经是有符号除。  
**建议：** 第一版可以不加这三条移位。若对照，必须分开原生移位、算术拼移位、算术右移、已经是位域产品。可以跳过「看见 145 就已经和乘除同一条」。231 SHIFT vs arithmetic bundled unbundling 完成（1404 item 1 / 1405 item 2 / 1406 item 3）；精读 [`worked-example-shft-notarith-vs-bundled.md`](worked-example-shft-notarith-vs-bundled.md)（不变量 1404 item 1）、[`worked-example-shft-notsdiv-vs-bundled.md`](worked-example-shft-notsdiv-vs-bundled.md)（不变量 1405 item 2）、[`worked-example-shft-notpack-vs-bundled.md`](worked-example-shft-notpack-vs-bundled.md)（不变量 1406 item 3）。不要发明「看见 145 就已经和乘除同一条」。不要抄操作码号或测试向量。不要写怎样做位域打包或用移位代替哈希。

## 6. 和另外几句不是同一句

1. **数前导零 ≠ 已便宜 ZK**（不变量 208）：7939 是数零。本页是移位。
2. **压零 ≠ 已是带立即数的压 0**（不变量 217）：3855 是压常数零。本页不压立即数。
3. **内存拷 ≠ 已是身份预编译**（不变量 216）：5656 是拷字节。本页是移比特。
4. **BLAKE2 压缩函数 ≠ 已是哈希**（不变量 230）：152 是哈希压缩积木。本页是按位移动。

不要抄操作码号、气价档、测试向量、拼指令序列。不要写怎样做位域打包、怎样抽字段、怎样用移位代替哈希。不编博物馆页。不另写 19 节。不转规范代码。算术拼移位、有符号除、位域打包库、数前导零是另一对象。
