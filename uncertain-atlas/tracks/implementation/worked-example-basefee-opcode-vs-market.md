## 1. 核心问题

阿比看见多了一条能读本块基础费的指令，以为费用市场已经改完；或看见合约能读这个数，以为已经给了出块者；或看见规范写跑 EVM 前就已经有这个数，以为头怎么算已经改了；或看见动机写悬赏、气期货、挑战期，以为这些产品已经在链上；或看见规范编号 3198，以为就是 1559，或已经是压零那条新指令。

官方句（事实）：

- EIP-3198：给 EVM 加一条读本块基础费的指令。
- 官方写：意图是让合约拿到本块基础费。
- 官方举过几类用法：合约给人「戳一下」的悬赏可以按基础费加减或按比例加，好在市况变化时仍够付；也可以据此做气期货，比旧的气代币更准；欺诈证明一类方案可以把基础费当输入，看见基础费高就自动加长挑战期。看见本页，不是这些产品已经上线。
- 官方写：处理交易本来就要用到基础费，所以跑 EVM 之前这个数已经在。本页不额外加读写复杂度，因此走「把常数值压进栈」那一档气。看见本页，不是已经改了头怎么算。
- 向后：官方写没有已知的向后兼容问题。看见本页，不是已经改了碰巧用了这个字节的旧合约行为。这和压零、内存拷那两页「旧字节可能变」不是同一句。
- 安全段：基础费不敏感，头上本来就公开。官方写这条指令没有已知安全冲击。看见本页，不是已经改了头上哪些字段算秘密。
- 规范**没有**把本页写成已经改了 1559 市场，也没有把能读基础费写成已经给了出块者，也没有把「跑之前就有这个数」写成已经改头，也没有把动机里的用法写成已经上线。

基础费指令、费用市场、能读到的数、头上怎么算，是四件事。

## 2. 直觉（ELI15）

教室门口挂着一块「今天入场费」的牌子。  
本页给每人发一张能看这块牌子的纸条。  
有纸条，不是入场费规则已经改写。  
能读到今天的数，不是这块牌子上的钱已经进了老师口袋。  
纸条上写「进教室前牌子就挂好了」，不是门口又换了一套算费公式。

## 4. 最小案例

一条 Ethereum 要对齐「这一口气基础费还停在哪一层」。

1. 看见多了一条基础费指令。规范：读本块基础费。不是已经改了 1559。
2. 看见合约能读这个数。规范：头上本来就公开。不是已经给了出块者。
3. 看见规范写跑 EVM 前就已经有这个数。规范：处理交易本来就要用。不是头怎么算已经改了。
4. 看见动机写悬赏、气期货、挑战期。规范：这是意图。不是这些产品已经上线。
5. 有人把这听成不变量 158。那是烧掉 / 小费 / 弹性。本页只是读那个已经烧掉的数。
6. 有人把这听成不变量 145 / 201。那是 blob 气和 blob 底价。本页读的是执行层基础费。
7. 有人把气价档或测试向量抄进不确定。规范：计价档和例子是尺子，不是产品常量。

「BASEFEE = 已经是 1559 / 能读到 = 已经给了出块者 / 3198 = 3855 / 3198 = 7516」是假学习。

## 5. 五层

| 层 | 本页 |
|---|---|
| 密码学 | 不换签算法；读基础费不是已经换了域 |
| 协议 | 必须点名问的是读数指令、费用市场、给谁，还是头怎么算 |
| 实现 | 跑之前就有这个数；不额外加读写 |
| 部署 | 官方写没有已知向后兼容问题；不是压零那种旧字节可能变 |
| 经济 | 能读基础费不是已经改了烧掉规则，也不是已经有气期货 |

**推断：** 产品句若只写「能读基础费所以市场已经齐」，读者会把读数听成 1559，或把能读到听成已经给了出块者。  
**建议：** 第一版可以不加这条读数指令。若对照，必须分开读数、市场、给谁、头怎么算。不要发明「看见 3198 就已经改了费用市场」。不要抄气价档或测试向量。不要写怎样设悬赏或做气期货。

## 6. 和另外几句不是同一句

1. **基础费 ≠ 小费**（不变量 158）：1559 定谁付钱、谁烧掉。本页只让合约读那个已经定下来的数。
2. **blob gas ≠ 普通执行 gas**（不变量 145）：另一套气。本页读执行层基础费。
3. **blob 底价 ≠ 已经并成一套气**（不变量 201）：blob 价。本页不是 blob 底价指令。
4. **压零 ≠ 带立即数的压 0**（不变量 217）：另一条新指令，而且官方写旧字节可能变。本页官方写没有已知向后兼容问题。

不要抄操作码号、气价档、测试向量、悬赏公式、规范提交哈希。不要写怎样设悬赏、做气期货或加长挑战期。不编博物馆页。不另写 19 节。不转规范代码。费用市场、给谁、头怎么算、blob 底价指令、压零是另一对象。基础费市场精读：[`../mempool/worked-example-basefee-vs-tip.md`](../mempool/worked-example-basefee-vs-tip.md)（不变量 158）。不另写 7516。
