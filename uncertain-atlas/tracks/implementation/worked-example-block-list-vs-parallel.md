## 1. 核心问题

阿比看见一块带着访问名单，以为交易已经并行跑完；或看见名单是强制的，以为已经是 2930；或看见事后状态差，以为已经可以不跑交易；或看见规范编号 7928，以为就是计划访问、Fuel 声明调度，或已经是 STM。

官方句（事实）：

- EIP-7928：给一块加一份块级访问名单。记下本块执行碰到的账户和存储位置，以及执行后的值。
- 动机：不知道事先会碰哪些地址和槽，交易就不能并行。2930 给的是可选的交易级名单，**并不强制**。本页把名单做到块这一层，并且强制。
- 官方写本页能用来并行读盘、并行验交易、并行算状态根，以及不做执行就更新状态。看见本页，不是这些已经发生。
- 头上多一个字段，承诺这份名单的哈希。名单**不在**块体里。执行层另存，经 Engine API 的执行载荷带过去。
- 2930 名单里的项**不得**自动抄进本页。只记执行里真正碰到或改过的地址和槽。没改状态的地址也必须在，改动列表可以为空。
- 名单必须完整、对得上。缺项或多出来的项让块非法。
- 向后：改块结构和 Engine API，不兼容，要硬分叉。
- 安全段：只读槽没有绑到某一笔，完整核对要等全部交易跑完。官方写：提议者可以申报从未碰过的只读槽，逼客户端多预取；条数有界。看见名单，不是已经挡住多余预取。
- 规范**没有**把看见名单写成已经并行跑完，也没有把强制名单写成已经是 2930，也没有把事后状态差写成已经不跑交易，也没有把本页写成不变量 168、143 或 122。

块级强制名单、交易级可选名单、声明调度、乐观并行，是四件事。

## 2. 直觉（ELI15）

出发前列一张「这一车会开门的房间」。  
列了房间，不是已经并行开完门。  
这张表是这一车强制的，不是乘客自己可选的那张旧表。  
表上写了开门后屋里什么样，不是已经不用走进去。

## 3. 对象

| 名字 | 是什么 | 不是什么 |
|---|---|---|
| 块级访问名单 | 本块真正碰到的账户和槽，加事后值 | 已经并行跑完 |
| 强制名单 | 缺项或多出来的项让块非法 | 已经是 2930 可选名单 |
| 事后状态差 | 执行后的值 | 已经不跑交易 |
| 7928 | 块级强制名单 | 计划访问；Fuel 声明调度；STM |

---

## 4. 最小案例

一条 Ethereum 要对齐「名单在哪一层」。

1. 看见一块带着访问名单。规范：记下真正碰到的。不是已经并行跑完。
2. 看见名单是强制的。规范：2930 不强制。不是已经是 2930。
3. 看见事后状态差。规范：官方写可用来不做执行就更新。看见本页不是已经不跑。
4. 看见 2930 名单。规范：不得自动抄进本页。
5. 有人把这听成不变量 168。那是交易计划访问、列表外仍能碰。本页是块级强制、只记真正碰到的。
6. 有人把这听成不变量 143。那是 Fuel 先声明再调度。本页是执行之后的块级记录。
7. 有人把这听成不变量 122。那是乐观并行再汇合。本页不发明 STM。

「看见块级名单 = 已经并行 / 强制 = 已经是 2930 / 事后差 = 已经不跑 / 7928 = 168」是假学习。

## 5. 五层

| 层 | 本页 |
|---|---|
| 密码学 | 头承诺名单哈希；哈希对上不是已经验完执行 |
| 协议 | 必须点名问的是块级强制名单、交易级可选名单，还是已经并行 |
| 实现 | 名单不在块体；另存、经出块通道带；通道尺寸是另一对象 |
| 部署 | 官方要硬分叉；不把示例名单抄进不确定 |
| 经济 | 不把「能并行」写成已经更安全 |

**推断：** 产品句若只写「有了访问名单所以已经并行」，读者会把记录听成已经跑完，或把强制听成 2930。  
**建议：** 第一版可以不抄块级强制名单。若对照，必须分开块级强制、交易级可选、声明调度、乐观并行。可以跳过「看见 7928 就已经并行」。212 block-list vs parallel bundled unbundling 完成（1476 item 1 / 1477 item 2 / 1478 item 3）；精读 [`worked-example-blal-notpar-vs-bundled.md`](worked-example-blal-notpar-vs-bundled.md)（不变量 1476 item 1）、[`worked-example-blal-not2930-vs-bundled.md`](worked-example-blal-not2930-vs-bundled.md)（不变量 1477 item 2）、[`worked-example-blal-notrun-vs-bundled.md`](worked-example-blal-notrun-vs-bundled.md)（不变量 1478 item 3）。不要发明「看见 7928 就已经并行」。不要抄条数或地址。不要写怎样造名单。

## 6. 和另外几句不是同一句

1. **列出地址或槽 ≠ 已经访问过**（不变量 168）：2930 可选、列表外仍能碰。本页强制、只记真正碰到的。
2. **谓词过了 ≠ 脚本已跑**（不变量 143）：Fuel 先声明再调度。本页是执行之后的块级记录。
3. **STM 跑完 ≠ 最终**（不变量 122）：乐观并行再汇合。本页不发明 STM。
4. **通道尺寸 ≠ 拼块已齐**（不变量 96）：名单走 Engine API，不是已经改了通道尺寸。

不要抄条数上限、气价、地址、示例名单、体积估算。不要写怎样造名单，或怎样申报从未碰过的只读槽。不编博物馆页。不另写 19 节。不另写 7981。交易级可选名单、Fuel 声明调度、STM、通道尺寸是另一对象。2930 精读：[`worked-example-listed-vs-accessed.md`](worked-example-listed-vs-accessed.md)（不变量 168）。
