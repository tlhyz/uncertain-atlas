## 1. 核心问题

阿比看见一笔 Taproot 走了脚本路径，以为已经按本页那种脚本语义在跑；或看见脚本里有成功操作码，以为已经执行到栈顶为真、已经安全升级；或看见旧多重签操作码，以为还能用，或已经被改成成功操作码；或把 P2WSH 里只当策略的 MINIMALIF 听成已经是共识；或看见规范编号 342，以为已经是 341 的结构页、141 的见证页或 16 的赎回页。

官方句（事实）：

- BIP-342：写的是 BIP-341 **底下那一套初始脚本语义**。341 改的是脚本结构；本页才写脚本路径里怎样验。
- 本页规则只在同时满足时适用：隔离见证花费、341 那种 taproot 花费、341 那种脚本路径花费，并且叶子版本标成 **tapscript 花费**。缺一档，不是已经本页。
- 解码时只要遇见成功操作码，验证**直接成功**，后面的规则都不跑。后面的字节就算解不开，也算过。脚本里**存在**一处成功操作码，就保证过。
- 成功操作码是升级钩子。软分叉还没给它定义之前就用，官方写成不安全、会丢钱。
- 旧多重签两条操作码在本页**禁用**：执行到就立刻失败停住；没执行到的分支里当没看见。官方故意不改成成功操作码，好让误用的人马上看见问题。
- P2WSH 里 MINIMALIF 只是策略；本页把它写成共识。
- 验签操作码改成 Schnorr（340）和 341 那套公共摘要；另加一条可批量验的累加验签，补上旧多重签拿掉之后的空位。
- 钥长度既不是空也不是 32 字节，算**未知钥类型**：执行时不当真验签，当成功。这是软分叉钩子，不是已经换了算法。
- 旧的脚本字节上限和非推操作码个数上限在本页不再适用，不是已经没有资源界。栈元素个数、单元素大小、以及按本输入见证算的验签预算仍在。本页验签不计入块级旧配额。
- 规范**没有**把走脚本路径写成已经是本页语义，也没有把遇见成功操作码写成已经执行完或已经安全升级，也没有把旧多重签写成还能用或已经变成成功操作码，也没有把 342 写成 341 / 141 / 16。

脚本路径、tapscript 叶子、成功操作码无条件过，是三件事。

## 2. 直觉（ELI15）

门后规章已经摊开，不等于你手里那本就是新版语法。  
封面上印了「以后再写」的空章，不是已经把整本念完、也不是已经升级完。  
旧的多人签字栏被划掉，不是已经盖成空章。

---

## 3. 对象

| 名字 | 是什么 | 不是什么 |
|---|---|---|
| 脚本路径 | 341：见证里揭开一支脚本 | 已经按本页语义跑 |
| tapscript 叶子 | 叶子版本标成这一档，才走本页 | 任意脚本路径 |
| 成功操作码 | 解码遇见就整段无条件过 | 已经执行完；已经安全升级 |
| 旧多重签禁用 | 执行到立刻失败 | 已经变成成功操作码；还能用 |

---

## 4. 最小案例

一条 Bitcoin 要对齐「这一口气脚本路径卡在哪」。

1. 走了脚本路径。规范：341 那一档。不是已经本页。还要隔离见证、taproot 花费、叶子版本标成 tapscript。
2. 叶子版本不是这一档。规范：本页规则不适用。不是已经按新语义验。
3. 脚本里有一处成功操作码。规范：整段直接过，后面解不开也过。不是已经跑到栈顶为真。软分叉还没定义就用，官方写成会丢钱。
4. 执行到旧多重签操作码。规范：立刻失败停住。不是已经变成成功操作码，也不是还能用。
5. 条件分支的输入不是空或恰好一。规范：本页当共识失败。不是还只是 P2WSH 那种策略拒。
6. 有人把这听成 341（不变量 153）。那是钥路径和脚本路径揭开什么。本页是脚本路径里怎样跑。
7. 有人把这听成 141。那是隔离见证结构。本页是 tapscript 语义。
8. 有人把这听成 16（不变量 170）。那是付给哈希再揭开。本页不是赎回脚本再跑旧语义。

「走了脚本路径 = 已经是 342 / 成功操作码 = 已经执行完 / 342 = 341」是假学习。

## 5. 五层

| 层 | 本页 |
|---|---|
| 密码学 | 验签改成 Schnorr；未知钥类型是钩子，不是已经换算法 |
| 协议 | 必须点名问的是脚本路径、tapscript 叶子，还是成功操作码无条件过 |
| 实现 | 两家必须先认叶子版本，再跑本页；遇见成功操作码不得再往下验 |
| 部署 | 共识软分叉；与 341 同一部署；已部署 |
| 经济 | 旧脚本字节上限不再适用，不是见证预算已经消失 |

**推断：** 产品句若只写「支持 Taproot / 脚本路径」，读者会把 341 的结构听成已经是本页语义，或把成功操作码听成已经执行完。  
**建议：** 第一版若做脚本路径，必须分开 341 结构和本页语义。可以跳过「看见成功操作码就已经执行完」。189 tapscript vs scriptpath bundled unbundling 完成（1557 item 1 / 1558 item 2 / 1559 item 3）；精读 [`worked-example-tpsm-notsem-vs-bundled.md`](worked-example-tpsm-notsem-vs-bundled.md)（不变量 1557 item 1）、[`worked-example-tpsm-notdone-vs-bundled.md`](worked-example-tpsm-notdone-vs-bundled.md)（不变量 1558 item 2）、[`worked-example-tpsm-notmin-vs-bundled.md`](worked-example-tpsm-notmin-vs-bundled.md)（不变量 1559 item 3）。不要发明「走了脚本路径就是新脚本」。不要抄操作码号。不要把 342 写成 341 或 141。

## 6. 和另外几句不是同一句

1. **钥匙路径 ≠ 揭树**（不变量 153）：341 结构。本页是脚本路径里怎样跑。
2. **txid ≠ wtxid**（不变量 152）：两套哈希。本页不是见证树。
3. **哈希 ≠ 已揭开**（不变量 170）：付给脚本哈希。本页不是赎回再跑旧语义。
4. **验得过 ≠ DER**（不变量 172）：旧 ECDSA 编码。本页验签是 Schnorr。
5. **CLTV / CSV**（不变量 164 / 165）：时间锁仍可用。本页不把它们改成另一对象。
6. **Miniscript ≠ 已是链上脚本**（不变量 191）：分析语言。本页是叶子怎么验。

不要抄操作码号 / 叶子版本 / 资源常数 / 例脚本。不要写怎样拼成功操作码、旧多重签改写、未知钥类型跳过验签。不编博物馆页。不另写 19 节。BIP-341 结构、BIP-141 见证、BIP-16 赎回是另一对象。BIP-379 Miniscript 见不变量 191。

## 精密检查

**禁止假学习：** 「走了脚本路径 = 已经是 342。」「成功操作码 = 已经执行完。」「成功操作码 = 已经安全升级。」「旧多重签 = 还能用。」「旧多重签 = 已经是成功操作码。」「MINIMALIF = 已经只是策略。」「342 = 341。」「342 = 141。」「342 = 16。」  
**边界：** 不抄操作码号。不另写 19 节。不写怎样拼成功操作码。结构见 **C157**。见证哈希见 **C156**。赎回见 **C174**。
