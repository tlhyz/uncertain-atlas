## 1. 核心问题

阿比看见多了一条内存拷贝指令，以为已经是身份预编译；或看见规范写「像用了中间缓冲」，以为实现必须真分配一块；或看见能重叠拷，以为已经是 calldata / 返回数据那几条拷；或看见规范编号 5656，以为就是 2929，或已经是数前导零那条新操作码。

官方句（事实）：

- EIP-5656：给 EVM 加一条专门拷内存区间的指令。
- 官方写：内存拷贝是基本操作，但在 EVM 上自己拼有开销。更早用身份预编译，靠 CALL 的输入输出内存偏移来拷。CALL 变贵之后，这条预编译不好用了；后来 2929 让它稍便宜一点，官方仍写：对 CALL 的开销还是让预编译不能当合理替代。
- 官方写：专用拷贝指令让静态分析和优化更好做。CALL 的效果一般必须当篱笆；本页这条只动内存。就算给预编译开特例，以后硬分叉仍可能改 CALL 的效果，用身份预编译的分析只对某一段块有效。看见本页，不是已经改了 CALL。
- 栈顺序和 calldata / 返回数据那几条拷一样：先目的、再来源、再长度。本页拷的是内存到内存。
- 语义：从内存来源偏移拷长度字节到目的偏移。拷的时候**像**用了中间缓冲，所以目的和来源可以重叠。
- 长度大于零、且来源或目的加上长度超出当前内存，就按内存扩张计价扩出去。
- 气价跟其他拷贝组操作码同一套黄皮书公式。看见本页，不是已经改了那套公式。
- 向后：这是以前没有的新指令。已经部署、碰巧用了这个字节的合约，分叉后行为可能变。
- 安全段：官方写实现**不要**真用中间缓冲，那是拒绝服务面。多数语言自带的搬字节函数本来就不是先整块再写。除此之外，拒绝服务和内存耗尽跟其他碰内存的操作码同一套扩张计价。
- 规范**没有**把本页写成已经是身份预编译，也没有把「像用了中间缓冲」写成必须真分配，也没有把本页写成 calldata / 返回数据拷，也没有把本页写成 2929 或数前导零。

内存拷贝指令、身份预编译、「像缓冲」、真缓冲，是四件事。

## 3. 对象

| 名字 | 是什么 | 不是什么 |
|---|---|---|
| 内存拷贝指令 | 内存到内存、只动内存 | 已经是身份预编译 |
| 「像用了中间缓冲」 | 允许重叠的语义 | 已经必须真分配缓冲 |
| 能重叠拷 | 目的和来源可以相交 | 已经是 calldata / 返回数据拷 |
| 5656 | 专用内存拷 | 2929 的冷热；数前导零 |

## 4. 最小案例

一条 Ethereum 要对齐「这一口气内存还停在哪一层」。

1. 看见多了一条内存拷贝指令。规范：专门拷内存区间。不是已经是身份预编译。
2. 看见规范写「像用了中间缓冲」。规范：这是重叠语义。不是实现必须真分配一块。
3. 看见官方写实现不要真用中间缓冲。规范：真缓冲是拒绝服务面。不是语义已经要求真缓冲。
4. 看见栈顺序和 calldata / 返回数据拷一样。规范：本页拷的是内存到内存。不是已经是那几条。
5. 有人把这听成不变量 169。那是冷热访问。本页拿 2929 当身份预编译变便宜的背景，不是已经是那一页。
6. 有人把这听成不变量 208。那是数前导零。本页是拷内存。
7. 有人把气价或测试向量抄进不确定。规范：黄皮书公式是计价尺子，不是产品常量。

「MCOPY = 已经是身份预编译 / 像缓冲 = 必须真缓冲 / 5656 = 2929 / 5656 = 7939」是假学习。

## 5. 五层

| 层 | 本页 |
|---|---|
| 密码学 | 不换签算法；拷内存不是已经换了域 |
| 协议 | 必须点名问的是内存拷、身份预编译、重叠语义，还是 CALL 效果 |
| 实现 | 「像缓冲」是语义；真缓冲是拒绝服务面 |
| 部署 | 新指令；旧字节碰上这个码，分叉后行为可能变 |
| 经济 | 专用拷不是已经改了 CALL 计价，也不是已经更便宜的 calldata |

**推断：** 产品句若只写「有拷贝指令所以已经不用预编译」，读者会把专用指令听成身份预编译，或把「像缓冲」听成必须真分配。  
**建议：** 第一版可以不加这条拷贝指令。若对照，必须分开内存拷、身份预编译、「像缓冲」、真缓冲。不要发明「看见 5656 就已经是身份预编译」。不要抄气价或测试向量。不要写怎样造真缓冲。

## 6. 和另外几句不是同一句

1. **本笔第一次碰 ≠ 已经热**（不变量 169）：2929 让身份预编译稍便宜。本页仍写预编译不能当合理替代。
2. **数前导零 ≠ 已经更便宜的 ZK**（不变量 208）：另一条新操作码。本页是拷内存。
3. **initcode 超界 ≠ 已经是部署代码超界**（不变量 176）：创建计量。本页不改创建界。
4. **calldata 地板 ≠ 已经改了执行气**（不变量 197）：数据地板。本页是内存到内存。
