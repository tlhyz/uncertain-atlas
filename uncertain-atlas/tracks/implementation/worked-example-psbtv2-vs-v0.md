## 1. 核心问题

阿比看见一份「后继版本 PSBT」，以为已经是旧版那份焊死的未签交易；或看见还能往里加输入输出，以为已经凑齐、已经能广播；或看见包上写了版本号，以为已经是交易版本；或看见旧解析器还能拆开，以为两套已经兼容；或看见规范编号 370，以为已经覆盖不变量 179。

官方句（事实）：

- BIP-370：给 BIP-174 的部分签名包补第二版，好让**创建之后**还能加输入和输出。
- 旧版（版本 0）不能改那份全局未签交易，所以加不进去。后继版把输入输出各自定位到自己的栏，不再从全局未签交易再拆一份。
- 后继版**必须排除**全局未签交易字段，**必须带**包版本字段，且版本写成 2。版本 1 故意跳过：旧版在口头上常被叫成版本 1。
- 包版本号不是交易版本号。交易版本另有一栏。
- 创建者先交出 0 输入、0 输出的包。构造者只在后继版出现：先看能不能改，才能加输入输出。能加不是已经凑齐，更不是已经能广播（那仍是不变量 179）。
- 抽出者仍只在输入都齐时才编网上那种完整序列化。
- 旧解析器只要认新字段，就能把后继包拆开。但两套**故意不兼容**，正是为了拿掉全局未签交易。能拆开不是已经当旧包用。
- 规范**没有**把看见后继包写成已经是旧版那份固定未签交易，也没有把能加输入写成已经能广播，也没有把本页写成 174 / 173 / 125。

后继工作包、旧版固定未签交易、网上能广播的完整交易，是三件事。

---

## 2. 直觉（ELI15）

旧信封里已经焊死一封公函，不能再塞附件。  
新信封允许先空着、再往里加栏，不是已经盖章寄出。  
信封角上的「第二版」不是公函自己的年份。

---

## 3. 对象

| 名字 | 是什么 | 不是什么 |
|---|---|---|
| 后继版本工作包 | 创建之后还能加栏的签名工作格式 | 已经是旧版那份固定未签交易 |
| 能再加输入输出 | 构造者还被允许改 | 已经凑齐；已经能广播 |
| 包版本号 | 这份工作格式是哪一版 | 已经是交易版本号 |
| 旧解析器能拆开 | 通用外壳还认得 | 两套已经兼容；已经能当旧包用 |

---

## 4. 最小案例

一条 Bitcoin 要对齐「这一口气签名卡在哪」。

1. 看见后继版本工作包。规范：创建之后还能加输入输出。不是已经是旧版那份焊死的未签交易。
2. 创建者先交出空输入空输出。规范：还没构造。不是已经能抽出。
3. 构造者加了一栏。规范：先看能不能改。不是已经凑齐，更不是已经能广播（不变量 179）。
4. 包上写了版本 2。规范：这是工作格式版本。不是已经是交易版本。
5. 旧解析器拆开了。规范：外壳同族。不是已经兼容，也不是已经能当旧包用。
6. 有人把这听成 174（不变量 179）。那是看见包 ≠ 已经广播。本页再拆「后继包 ≠ 旧版固定未签交易」。
7. 有人把这听成 173 / 125。那是地址和替换信号。本页是工作格式版本。

「看见 v2 = 已经是旧包 / 能加栏 = 已经能广播 / 370 = 174」是假学习。

**推断：** 产品句若只写「支持 PSBT v2」，读者会把还能改的信封听成已经是旧那份，或听成已经能上链。  
**建议：** 第一版若做后继工作包，必须分开包版本、交易版本、旧版固定未签交易、抽出、广播。不要发明「v2 = 已经能改完」。不要抄字段号。不要把 370 写成 174。

## 6. 和另外几句不是同一句

1. **工作包 ≠ 已广播**（不变量 179）：看见包不是已经上链。本页是后继包还不是旧版那份固定未签交易。
2. **地址 ≠ 已有输出**（不变量 174）：收款写法。本页是签名工作格式的版本。
3. **信号 ≠ 已换**（不变量 166）：愿不愿意被换。本页是包还能不能加栏。
4. **txid ≠ wtxid**（不变量 152）：身份哈希。本页不写怎样从后继栏拼回未签交易去算身份。

不要抄字段号 / 位旗 / 锁时间阈值 / 例串。不要写怎样把后继包改回旧包，怎样加减输入，或怎样用签名旗去关改栏。不编博物馆页。不另写 19 节。BIP-174 旧包、BIP-173 地址、BIP-125 替换是另一对象。

## 精密检查

**禁止假学习：** 「看见 v2 = 已经是旧包。」「能加栏 = 已经能广播。」「包版本 = 交易版本。」「能拆开 = 已经兼容。」「370 = 174。」  
**边界：** 不抄字段号。不另写 19 节。不写怎样改回旧包。旧包见 **C183**。看见地址见 **C178**。替换信号见 **C170**。
