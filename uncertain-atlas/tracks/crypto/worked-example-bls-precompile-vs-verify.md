## 1. 核心问题

阿比看见一组 BLS12-381 预编译，以为合约已经在验 BLS 签；或看见加法不查子群，以为 MSM 和配对也不查；或看见全零字节，以为 `(0,0)` 已经在曲线上；或看见规范编号 2537，以为就是 196/197，或已经是不变量 116 那次 Besu 洞。

官方句（事实）：

- EIP-2537：加入 BLS12-381 曲线上的运算预编译，用来**高效做** BLS 验签这类事。连同曲线算术，还包括多标量乘，用来在验签时高效聚合公钥或各签名者的签。
- 动机是给配对友好曲线补一套比现有 BN254 预编译更高安全位数的原语。现有 BN254 预编译只提供更低一档的安全位数。
- 七个分开的预编译：G1 加、G1 多标量乘、G2 加、G2 多标量乘、配对检查、域元素映到 G1、扩域元素映到 G2。
- 映射函数**不**把字节串映成域元素（这件事可以有很多写法，也能在 EVM 里高效做）；它只做域算术，把**已经是域元素**的输入映到曲线点。验签方案需要后面这一步。
- 对 BLS12 曲线，坐标 `(0,0)` **不在曲线上**。一段全零字节按约定编码 G1/G2 的无穷远点，而不是已经把 `(0,0)` 当成曲线点。
- 乘法用的标量**不要求**小于等于主子群阶。
- 变长输入（MSM、配对）在算术上对空输入有定义，但本页不鼓励这种用法；空输入**必须报错**。
- G1/G2 **加法不查子群**。G1/G2 MSM 和配对检查：**必须**查子群；在曲线上但不在正确子群，是错误。
- 配对检查算的是一组对的配对乘积是否为 1。输出是一段定长字节，末字节为假或真。看见末字节为真，不是已经验过一份 BLS 签。
- 预编译出错则本次 `CALL` / `STATICCALL` 带来的气**全部烧掉**，跟当时其它预编译一样。
- 本页**不要求**全部运算用恒定时间算法。
- 规范**没有**把这七个预编译写成已经是「验 BLS 签」一条指令，也没有把加法不查子群写成 MSM/配对也不查，也没有把全零字节写成已经在曲线上，也没有把本页写成 196/197 或写成 116 那次洞。

预编译算术、子群谓词、验签方案，是三件事。

## 2. 直觉（ELI15）

厨房里多了秤、刀和锅，不是已经端出一盘验过的签名菜。  
切菜不用查身份证，不是炒菜和上桌也不查。  
菜单上印的「空盘」是约定，不是已经有一盘坐标为零的菜在桌上。

## 3. 对象

| 名字 | 是什么 | 不是什么 |
|---|---|---|
| BLS12-381 预编译套件 | 加、多标量乘、配对检查、域到点 | 已经在验 BLS 签 |
| 加法 | 两点相加；不查子群 | 已经和 MSM/配对同一套谓词 |
| MSM / 配对 | 必须查子群 | 已经是验签 |
| 全零字节 | 约定的无穷远编码 | 已经在曲线上的 `(0,0)` |
| 2537 | BLS12-381 | 196/197 的 BN254；116 那次 Besu 洞 |

## 4. 最小案例

一条 Ethereum 要对齐「这一口气配对卡在哪」。

1. 看见七个预编译。规范：曲线算术和聚合用的多标量乘。不是已经在验 BLS 签。
2. 调用加法。规范：不查子群。不是 MSM/配对也可以不查。
3. 调用 MSM 或配对，点在曲线上但不在正确子群。规范：必须报错。不是加法那条「不查」已经覆盖这里。
4. 输入一段全零字节。规范：按约定是无穷远。不是 `(0,0)` 已经在曲线上。
5. 映射预编译吃到域元素。规范：只把域元素映到点。不是已经把任意字节映成域元素。
6. 有人把这听成 196/197 / 不变量 116。那是 BN254，以及 Besu 把子群检查当成曲线检查。本页是另一条曲线、另一套预编译。
7. 有人把这听成 4844 的 KZG（不变量 23）。那是 blob 承诺。本页是执行层预编译算术。

「有了 2537 = 已经在验 BLS / 加法不查 = MSM 也不查 / 全零 = 已经在曲线上 / 2537 = 196」是假学习。

## 5. 五层

| 层 | 本页 |
|---|---|
| 密码学 | 必须点名问的是曲线算术、子群、还是验签方案；不要求恒定时间 |
| 协议 | 加法与 MSM/配对的子群谓词不同；空变长输入必须报错 |
| 实现 | 编码必须先验「在域里」；出错烧光本次带来的气 |
| 部署 | 网络升级；两家必须同一套错误 |
| 经济 | 不抄气价或折扣表 |

**推断：** 产品句若只写「有 BLS 预编译」，读者会把算术听成已经验签，或把加法不查子群听成 MSM 也不查。  
**建议：** 第一版可以不做配对预编译。若做，必须分开曲线算术、子群谓词、验签方案。不要发明「看见 2537 就已经在验 BLS」。不要抄地址或气价。不要把 2537 写成 196。

## 6. 和另外几句不是同一句

1. **子群过了 ≠ 已经在曲线上**（不变量 116）：BN254 上 Besu 把子群检查当成曲线检查。本页是 BLS12-381；加法官方就不查子群，MSM/配对必须查。
2. **KZG ≠ DAS**（不变量 23）：blob 承诺与抽样。本页是执行层预编译算术。
3. **验得过 ≠ 严格 DER**（不变量 172）：ECDSA 编码。本页是配对曲线点编码。
4. **气 ≠ 墙钟**（不变量 101）：本页出错烧光本次带来的气，不是已经把气写成秒。
5. **回滚 ≠ 烧光**（不变量 177）：EVM 回滚可留气。本页预编译出错跟当时其它预编译一样烧光本次带来的气。

不要抄预编译地址 / 气价 / 域模数 / 子群阶 / 生成元 / 折扣表 / 编码宽度。不要写怎样造点、怎样跳过子群检查、怎样编码假无穷远，或怎样拼 BLS 验签。不编博物馆页。不另写 19 节。不转测试向量。EIP-196/197 BN254、不变量 116 那次洞、EIP-4844 KZG 是另一对象。子群洞精读：[`../failure-museum/cve-2025-30147.md`](../failure-museum/cve-2025-30147.md)（不变量 116）。
