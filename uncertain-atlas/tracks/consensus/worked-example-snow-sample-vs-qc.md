## 1. 核心问题

阿比听见「Avalanche 也是 BFT」，或看见某轮抽样已经 α 多数，以为手里已经有一张能转给别人验的 +2/3 证书，或以为指定出块窗里的人已经替全网做了决定。

官方句（事实）：

- 官方对照表把传统 PBFT 写成全员通信、**确定**最终；把 Snow* 写成随机抽样、**概率（可调）**最终。这不是同一把尺子。
- Snow 家族靠**反复子抽样投票**。节点问一小撮验证者现在更喜欢谁。抽到的人里若有足够多数（官方叫 α）同一偏好，询问者改跟这个偏好。再抽，直到连续足够多轮（官方叫 β）都是同一答案，才决定。
- 因此「这一轮样本里过了 α」不是「全集已经过了超多数」，也不是「别人拿着同一张证书就能复验」。下一轮会再抽一撮人。连续 β 轮是**本节点的置信计数**，不是 CometBFT 那种可转发 QC。
- 两份官方页把 α 的默认数字写成了不同值。本页**两数都不抄**。参数是网络对象，官方写单节点改掉会让共识失败。
- Snowman 把 Snowball 伸成**一条线性块序列**。主网 P / C / X 都走 Snowman。官方写 DAG 引擎在主网已经不用；X-Chain 线性化之后也走 Snowman。DAG 旧故事不是现行主网对象。
- 引擎接口把 `Preference` 和 `LastAccepted` 分开。偏好是此刻更喜欢哪块；接受是已经决定。偏好不是已经接受。
- 概念页写思想层**没有领袖**，任何节点都可提案。架构页另写 **Snowman++ / ProposerVM**：在 Snowman 上面加软出块窗，按质押抽样排出出块者，窗内只有指定的人能出合法块。出块窗是节奏，不是 Snowball 已经决定。窗里没人出，官方写可能停产，那也不是已经接受。
- 抽样不是均匀随机，按质押加权。官方写没有 slash：表现不好质押仍整份退回，只是没奖励。没 slash 不是已经等于 Casper 可罚关系。
- 一票给某块，也算给它的祖先（传递投票）。这是吞吐优化，不是已经变成全集证书。
- 无效交易不进共识。官方写接受/拒绝被说成不可逆，同时又写安全是概率的、可用参数调到任意低。不要把「不可逆」听成已经有一张 PBFT QC。

样本 α、连续 β、偏好、接受、出块窗、可转发 QC，是不同对象。

## 2. 直觉（ELI15）

全班举手盖章，章可以拿去教务处复验：PBFT 的 QC。  
每次只问附近几个人吃披萨还是烧烤，问到多数就改口，连续好多轮都一样才下单：Snow。  
你笔记本上的「连续成功次数」不能复印给邻桌当已盖章。  
班主任排今天谁写黑板：出块窗。谁执笔不是全班已经点了菜。

小朋友看见「也是 BFT」或「这轮已经多数」，以为手里有一张能转交的证书。

## 3. 对象

| 名字 | 是什么 | 不是什么 |
|---|---|---|
| 子抽样投票 | 每轮问一小撮验证者的偏好 | 全员两轮；Altair 固定委员会 QC |
| α 多数 | 这一撮样本里够数的同一答案 | 全集 +2/3；可转发证书 |
| β 连续成功 | 本节点连续多轮抽到同一 α 多数后决定 | 一张 QC；别人已经能复验 |
| Preference | 此刻更喜欢哪块 | 已经接受 |
| LastAccepted | 已经决定的块 | 还在处理的偏好 |
| Snowman | 用 Snowball 决定线性块序 | 现行主网仍在用的 DAG 引擎 |
| Snowman++ 出块窗 | 按质押排的软出块节奏 | Snowball 已经决定；思想层已经有领袖 |
| 无 slash | 表现不好质押整份退回、没奖励 | 已经等于 Casper slash |
| 传递投票 | 投一块也算投祖先 | 已经变成全集证书 |

## 4. 最小案例

用户在 C-Chain 转一笔。

1. 交易进某个块提案。Snowman++ 可能让指定窗里的人出这块。出了块不是已经接受。
2. 验证者对块做抽样查询。某一轮样本里 α 多数喜欢这块。这是偏好可能被改，不是全集已经盖章。
3. 同一节点连续 β 轮都抽到同一答案，才 Accept。邻节点各自数自己的连续次数。
4. 有人把「Avalanche 也是 BFT」写成和 CometBFT 同一张 QC：官方对照表把最终性写成概率可调，通信写成抽样。
5. 有人把「没有领袖」写成产品里谁都能抢同一高度：架构页另有出块窗。两句都留着，不要互相吞掉。

「抽样过了所以已经 commit」是假学习。

## 5. 五层

| 层 | 本页 |
|---|---|
| 密码学 | 每张抽样回答仍是验证者签；没有新的「雪崩哈希」 |
| 协议 | 必须点名问的是样本 α 还是全集证书；偏好 ≠ 接受；出块窗 ≠ 决定 |
| 实现 | 各节点自己数 β；改本地参数官方写会让共识失败 |
| 部署 | explorer「已确认」若只跟 Preference，不是 LastAccepted |
| 经济 | 没 slash 不是已经没有过错代价；质押加权抽样不是一人一票 |

**推断：** 产品句若只写「BFT 所以秒最终」，读者会把连续置信听成可转发 QC。  
**建议：** 不确定第一版不要同时卖 QC 流水线、检查点最终和抽样固化。若以后对照 Snow，用户可见的「到了」必须点名是偏好还是接受，并写清没有可转发证书。不要抄样本个数或亚秒。

## 6. 和另外几句不是同一句

1. **抽样委员会 2/3 ≠ 全集 2/3**（不变量 22）：Altair 是固定委员会上的超多数签。本页是反复再抽、数连续轮，没有那张委员会 QC。
2. **每高度 commit**（L4.6 / CometBFT）：全员量级投票 + 可转发证书。本页官方对照把它写成另一列。
3. **head ≠ justified ≠ finalized**（不变量 127）：Gasper 三等。本页没有 justified 那一档。
4. **NPoS 等权**（不变量 129）：当选后计票单位。本页是抽样权重按质押，不是 GRANDPA 等权。
5. **正确兑现委托 ≠ 预编译信任**（不变量 119）：C-Chain EVM 事故。本页是 Snow 引擎，不是预编译。
6. **VRF 抽签**（不变量 134）：出示证明、另走 propose / soft vote / certify。本页抽的是每轮被问的人，没有「我被抽中」那张证明。精读：[`worked-example-vrf-sortition-vs-certified.md`](worked-example-vrf-sortition-vs-certified.md)。

不要把官方对照表里的节点上限、亚秒、样本个数、α / β 默认值、窗秒数、安全概率式子、测试吞吐抄进不确定常量。两份官方页的 α 数字不一致，正好说明不要抄。不要写怎样日蚀抽样集或灌投票。不编博物馆页。

## 7. 「不确定」测试句（建议）

```text
抽样 α 多数 ≠ 全集 +2/3 证书
连续 β 轮 ≠ 一张可转发的 QC
Preference ≠ LastAccepted
出块窗里指定的人出块 ≠ Snowball 已经决定
思想层无领袖 ≠ 产品没有 ProposerVM
主网走 Snowman ≠ DAG 引擎还在主网跑
没 slash ≠ 已经等于 Casper 可罚
按质押加权抽样 ≠ 均匀随机一人一票
传递投票 ≠ 已经变成全集证书
「也是 BFT」≠ 已经和 CometBFT 同一把尺子
```

## 精密检查

**禁止假学习：** 「Avalanche 也是 BFT 所以有 QC。」「这轮抽样过了就是已经最终。」「连续成功次数可以转给别人验。」「指定出块者已经替全网决定。」「没有领袖所以谁都能抢同一高度。」「主网还在跑 DAG。」  
**边界：** 不证论文安全式、不填 k / α / β、不抄窗秒数 / 亚秒 / 吞吐。不写怎样偏抽样。C-Chain 预编译事故仍指博物馆委托页。思想层无领袖与产品出块窗两句都留着，不互相改写。
