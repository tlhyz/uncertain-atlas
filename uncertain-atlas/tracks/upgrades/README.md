# 横向地图：升级

详见 L9.4、L3.3、L3.7、L4.5。  
精读：[`worked-example.md`](worked-example.md)（升级钥把 1 改成 2）。

| 系统 | 典型机制 | 旧验证者 | 隐藏中心点 |
|---|---|---|---|
| Bitcoin | 软分叉为主 | 仍跟历史，验证变薄 | 矿工/经济节点是否执行新规则 |
| Ethereum | 协调硬分叉 | 不升级则分裂 | 客户端团队 + 社会层 |
| Cosmos 家族 | 链上 runtime | 取决于治理 | 议会/升级钥 |
| 乐观 rollup | 代理合约 | 用户在桥的规则里 | 升级钥/时锁 |
| Algorand | 协议版本（以规范为准） | 须读现行治理 | 勿用品类名代替 |
| Nervos | 脚本/库可换（VM 不焊死密码） | 旧 lock 不会自动变 PQ | 「crypto-agnostic」当已迁移 |
| Zcash | 网络升级换证明系统 | 旧池规则变 | 验 π 绿了当供给证明 |

「不确定」建议：算法标识可加；供给公式不可静默改。决策列空。
