# 失败案：改冻结门槛不是选举地板已经配对；出块还在不是纪元已经转

层：**协议 + 治理 + 经济**（许可制 `chill_other` 打开后，候选集变差；静态 `MinimumScore` 未随同调整；所有解被 `ScoreTooLow` 拒；验证者集合 / 纪元 / 解绑冻结；出块与最终性继续）

官方披露：

- Polkadot 论坛官方复盘：[2026-06-30 Staking Election Stall PostMortem](https://forum.polkadot.network/t/2026-06-30-staking-election-stall-postmortem/18077)。本页只采用该文已写出的句子。无 CVE。

**事实（官方原文能对上的句子）：**

- Asset Hub 上的多块选举停住。签名与未签名解全部因 `ScoreTooLow` 被拒，提交押金被罚。没有解能进队，验证者集合、纪元、奖励结算、解绑都停在上一成功选出的纪元。
- 触发：一条公投降低了 `ChillThreshold`，打开对低于最低自质押者的许可制 `chill_other`。此前另一条公投已把最低自质押抬高。冷冻潮去掉一批自质押低、但提名很多的验证者。当时能达到的最好选举分，落到**未随同调整**的静态 `MinimumScore` 之下。
- 官方：地板是故意静态的治理后盾，本职是挡住明显变差的集合。这次它按设计暂停轮转，而不是锁进变弱集合。出错的是**过程**：改了会移动可达分的参数，没有在同一公投里配对改地板。
- 官方：链本身未受险。出块、最终性、非质押功能继续。用户资金未丢。解绑是推迟，不是没收。诚实矿工因地板不可达被罚押金，后来单独公投退还。
- 修法：另一条公投只降低地板的主导轴，选举解开。后续要把「改可达分必须带 `SetMinUntrustedScore`」写成检查清单，并让矿工客户端在分低于链上地板时不要提交。

本页不写怎样冷冻、不抄金额 / 公投号 / 验证者人数 / 地址进不确定常量。改冻结门槛，不是选举地板已经配对。

## 1. 发生了什么

门口的质量线没动。  
能进门的人名单变了。  
最好的那一班，仍然够不着那条线。  
每一份答卷都不及格，押金被扣。  
纪元转不动，解绑等纪元。  
隔壁出块的 bell 还在响。  
bell 还在响，不是质押已经结算。

## 2. 根因

选举质量地板与「谁还能当候选人」是两个旋钮。  
打开许可冷冻，会拿走自质押低但提名重的人，从而压低可达的最差当选质押。  
地板静态、不自动跟。同一公投没带配对下调。  
三个单独看起来合理的参数叠在一起：最低自质押、许可冷冻、固定地板。官方：组合从未按真实选举快照测过。

这不是：

| 案 | 对象 |
|----|------|
| 不变量 8 | 计票只认唯一 `V(h)`；本页是选举解过不了质量地板 |
| 不变量 35 | 集合更新延迟；本页是新集合根本选不出来 |
| 不变量 58 | 治理参数吃不了会 panic；本页是参数合法，组合把选举卡死 |
| 不变量 71 | EndBlocker 出错停链；本页出块与最终性继续 |
| 不变量 99 / 100 | 争议禁用；本页是质押选举 |
| 本页 | **改冻结门槛 ≠ 选举地板已经配对；出块还在 ≠ 纪元已经转；诚实解被 ScoreTooLow 罚 ≠ 提交者作恶** |

## 3. 被破坏的 invariant

- 会移动可达选举分的治理变更，必须在同一对象里配对调整质量地板（不变量 110）
- 出块 / 最终性继续不得写成质押纪元、奖励、解绑已经前进
- 诚实解低于不可达地板被罚，不得写成矿工已经作恶

## 4. 为什么测试没发现

幸福路径：候选集差不多，可达分远高于地板。  
绿测试只覆盖「单独改一个旋钮」。  
边角要：冷冻潮之后的真实快照；签名解与未签名回退是否都低于地板；纪元是否还在转。

## 5. 修复

官方：公投下调地板主导轴，选举恢复。  
过程：改选举相关参数必须先对当前快照仿真，并断言可达分仍高于地板；配对 `SetMinUntrustedScore` 写进同一公投。  
矿工客户端：分低于链上地板则不提交，避免诚实者被罚。  
官方考虑过地板自动衰减，因对手可故意停选举把地板打下来而否决。

## 6. 「不确定」若同类

1. 第一版可以不做链上选举 / 许可冷冻 / 质量地板三件套。
2. 若做选举质量地板：改候选集或门槛的治理对象，必须同时带地板。单独看起来安全的旋钮必须测组合。
3. 产品句若写「链还在出块」，必须点名纪元 / 奖励 / 解绑是否冻结。
4. 诚实提交被地板拒，按治理事故审，不得写成提交者作恶。
5. 这和集合更新延迟（35）、治理 panic（58）、EndBlocker 停链（71）、争议禁用（99/100）不是同一句。
6. 不要写怎样冷冻。不要抄金额 / 公投号 / 人数。

## 7. 回归测试

形状（不是利用包）：文案把改冻结门槛写成选举地板已经配对必须红。把出块还在写成纪元已经转 / 解绑还在走必须红。把诚实解被 ScoreTooLow 罚写成提交者作恶必须红。与 35 / 58 / 71 糊成「治理停链」一句必须红。
