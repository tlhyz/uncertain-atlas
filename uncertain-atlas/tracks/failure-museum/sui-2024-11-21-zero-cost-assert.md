# 失败案：估出来的执行代价为 0 不是已经便宜所以安全；拥塞控制里的 assert 不是局部跳过

层：**实现 + 协议**（共享对象拥塞控制估错代价会让全验证者崩溃循环；不是 owned 路径已经绕过共识）

官方披露：

- Sui 官方复盘：[Sui Mainnet Outage Resolution](https://www.sui.io/blog/sui-mainnet-outage-resolution)（2024-11-21）。无 CVE。本页只采用该页已写出的句子。

**事实（官方原文能对上的句子）：**

- 2024-11-21 约 **1:15–3:45 am PT**，Mainnet **完全停住**。所有验证者卡在**崩溃循环**，交易处理停止。
- 拥塞控制代码里的 `assert!` 在**估计执行代价为 0** 时错误地让验证者崩溃。边角要同时满足：拥塞控制处于 `TotalGasBudgetWithCap` 模式；网上出现一笔带**可变共享对象输入**且 **0 条 `MoveCall`** 的交易。
- `TotalGasBudgetWithCap` 曾在协议版本 **63** 短暂打开后撤回，再随 accumulating scheduler 在版本 **68** 打开。
- 一收到这种形状的交易，**所有验证者崩溃**。
- 拥塞控制的本意：限制写**同一共享对象**的速率，避免检查点执行太久。对象架构可并行许多不同交易；写同一共享对象必须串行。新模式想更准地估复杂度，却带了这个洞。
- 修法：PR **#20365**。主网 **v1.37.4**，测试网 **v1.38.1**。官方写补丁发布后约 **15 分钟** 网络恢复。停机时间里相当一部分花在等发布构建。

本页不写怎样拼「可变共享对象 + 0 条 MoveCall」，不抄协议版本号或 15 分钟进不确定常量。估出来的代价为 0 不是已经安全。

## 1. 发生了什么

共享柜子一次只能一个人写。  
门口有人估「这单有多沉」。  
有一单看起来沉为 0。  
门卫用断言把自己砸晕。  
全屋门卫同一条断言。  
屋子转不成。  
估出来的执行代价为 0，不是已经便宜所以安全。

## 2. 根因

拥塞控制是共享对象写速率的上限，不是「估值为 0 就 assert 退出」。  
估值为 0 可以是合法边角（0 条 MoveCall + 可变共享对象），不是已经非法。  
assert 在验证者进程里，全员同一实现，就变成全网崩溃循环。  
owned 快路径帮不上：这单碰的是共享对象。

这不是：

| 案 | 对象 |
|----|------|
| L6.2 | owned 可旁路全局序；shared 不能。本页是 shared 路径上的拥塞控制崩溃 |
| 不变量 37 | 对等路径用断言当过滤器；本页是拥塞控制估值 |
| 不变量 71 | 可选模块 EndBlocker 出错会停 |
| 不变量 88 / 2024-02-06 | 回放无限再编译；本页是 assert 崩溃循环 |
| 不变量 89 / 2022-04-30 | 票不够、分叉不回收、OOM |
| 不变量 91 / 2026-01-14 | 共识提交分叉、隔离区拒证；本页是全员崩溃 |
| 本页 | **估计执行代价为 0 ≠ 已安全；拥塞控制里的 assert ≠ 局部跳过；可变共享对象 + 0 条 MoveCall ≠ 已经便宜；TotalGasBudgetWithCap ≠ 复杂度已估对** |

## 3. 被破坏的 invariant

- 拥塞控制估值失败必须拒交易或走定义好的降级，不得 assert 崩进程（不变量 90）
- 估值为 0 不是已经非法，也不是已经免费可执行
- 全验证者同一实现上的崩溃循环是停链，不是共享对象拥塞已经被管住
- 打开更准的估值模式，不是边角交易已经测过

## 4. 为什么测试没发现

幸福路径：带 MoveCall、估值大于 0 的共享对象交易走拥塞控制。  
只测「热点共享对象被限速」会绿。  
边角要：估值模式打开 + 可变共享对象 + 0 条 MoveCall → 估值为 0 → assert。  
官方事后写要扩大对抗交易生成——说明当时没有这种形状。

## 5. 修复

官方：改代码（PR #20365），打进 v1.37.4。验证者升级后恢复。  
删掉这条 assert 或改成拒交易，不是拥塞控制已经「估准」。  
协议版本 63 曾打开又撤回，不是 68 再开时边角已覆盖。

## 6. 「不确定」若同类

1. 第一版可以不做共享对象拥塞控制。若做：估值失败必须拒或排队，禁止 assert / panic。
2. 估值为 0 必须当合法边角测，不得当成「不会发生」。
3. 共享对象路径与 owned 快路径必须分开测。快路径绿了不是共享路径已安全。
4. 换估值公式 / 调度器是新谓词，旧撤回过的模式再打开必须重测边角。
5. 不要抄 15 分钟、协议 63/68、PR 号当产品证明。不要写怎样拼 0 条 MoveCall。
6. 这和 owned/shared 分类（L6.2）、断言当过滤器（37）、旧加载器死循环（88）、检查点隔离（91）不是同一句。

## 7. 回归测试

形状（不是利用包）：文案把估计执行代价为 0 写成已安全必须红。把拥塞控制 assert 写成局部跳过必须红。把「有共享对象限速」写成 0 条 MoveCall 不会崩必须红。把 owned 快路径绿写成共享路径已安全必须红。与 2026-01-14 检查点隔离糊成一句必须红。
