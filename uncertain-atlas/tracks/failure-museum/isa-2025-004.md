# 失败案：预编译中途出错不是 SDK 侧已写入已经撤回；领奖转出不是可领余额已经清零

层：**协议 + 实现**（EVM 调预编译时 gas 不够或中途失败，部分 SDK 状态已写下、不回滚；分配预编译可先转钱、不把可领清零；其它失败点可造成非确定执行、验证者停）

官方披露：

- Cosmos EVM 官方咨询：[ISA-2025-004 / GHSA-mjfq-3qr2-6g84](https://github.com/cosmos/evm/security/advisories/GHSA-mjfq-3qr2-6g84)（2025-05-13，Critical）。无 CVE。本页不转补丁代码。

**事实（官方原文能对上的句子）：**

- 把 EVM 调用 gas 调低，可让预编译执行到一半再失败，**已写下的部分状态不撤回**。
- 用在分配预编译领奖时：钱可以转到用户，可领余额却不回到 0。也可在其它失败点造成非确定执行，让验证者停。
- 官方：任何使用预编译的 evmOS / Cosmos EVM 链都中。
- 修法：每个预编译包进原子函数，出错则撤回部分已提交状态。有预编译的链没有配置-only 缓解，必须协调升级。
- 测试：分配预编译加了「gas 更低时不再留下部分写入」的用例。

本页不写怎样调 gas、怎样对准领奖中点、不抄补丁函数进不确定常量。预编译失败，不是 SDK 账已经撤回。

## 1. 发生了什么

EVM 说：这次只许走一半。  
预编译已经把 SDK 的本子改了一笔。  
气费不够，EVM 报错。  
那一笔还在本子上。  
领奖的人看见钱到了，可领的数没清。  
报错，不是两本账已经一起退回。  
气费更低，不是已经更安全。

## 2. 根因

预编译跨过两台机器：EVM 气费与 SDK 多店。  
EVM 失败路径若只回 EVM 日志，不回 SDK 快照，就是半笔。  
领奖必须「转出」与「清零」同一原子。先转后清，中间可停。  
气费是对手旋钮，不是已经覆盖所有失败点。

这不是：

| 案 | 对象 |
|----|------|
| 不变量 103 | Geth OOG 没撤回空账户删除；本页是预编译写下的 SDK 状态 |
| 不变量 5 | 崩溃半块；本页是一笔内预编译半写入 |
| 不变量 115 | 可花视图减锁定；本页是失败不回滚 |
| 不变量 118 | 嵌套调用外层看不见内层；本页是出错留下半笔 |
| 本页 | **预编译中途出错 ≠ SDK 已写入已经撤回；领奖转出 ≠ 可领已经清零** |

## 3. 被破坏的 invariant

- 跨模块预编译必须对 EVM 失败与 SDK 写入同一原子；部分写下必须随错误撤回（不变量 117）
- 领奖转出与可领清零不得拆开
- 调低 gas 必须当对抗边角，不得只测气费充足

## 4. 为什么测试没发现

幸福路径：气费够，预编译跑完，转出与清零一起提交。  
绿测试只覆盖成功领奖。  
边角要：气费卡在转出之后、清零之前；失败后 SDK 多店是否回到快照。

## 5. 修复

官方：预编译执行包进原子撤回。协调升级。  
无配置缓解。新测试锁「更低 gas 不再留半笔」。

## 6. 「不确定」若同类

1. 第一版可以不做 EVM 预编译、分配模块、跨 VM 调 SDK。
2. 若一层引擎调另一层有状态模块：失败必须撤回两边。转出与清零同一对象。
3. 气费 / 配额是对手，必须测「走到一半」。
4. 这和 OOG 删户（103）、崩溃半块（5）、可花≠锁定（115）、嵌套外层看不见（118）不是同一句。
5. 不要写怎样调 gas。不要抄补丁代码。

## 7. 回归测试

形状（不是利用包）：文案把预编译中途出错写成 SDK 已写入已经撤回必须红。把领奖转出写成可领已经清零必须红。把更低 gas 写成已经更安全必须红。与 103 / 115 糊成「失败没回滚」一句必须红。
