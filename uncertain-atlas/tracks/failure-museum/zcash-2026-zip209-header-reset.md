# 失败案：重复块头静默复位不是闸门还在转；跟踪字段空了不是 ZIP 209 已执行

层：**协议 + 实现**（链价值池跟踪在重复头上被静默复位；ZIP 209 闸门名义上仍在；实现把跟踪字段当闸门本身）

官方披露：

- Zcash 规范级 ZIP：[ZIP 256](https://zips.z.cash/zip-0256)（NU6.1 与 NU6.2 之间的共识与拒绝服务修补；Orchard 临时缓解与 NU6.2 另见 ZIP 257）。本页只采用 ZIP 已写出的句子。无独立 CVE 号写入本条。

**事实（官方原文能对上的句子）：**

- 重复块头可以**静默复位**链价值池跟踪字段，从而**实际上关掉** ZIP 209 闸门执行。ZIP 写：该洞在 zcashd 某一发布线触发，后续发布才 defer 初始化。
- 变体可以把**已损坏的每块池增量**写盘。
- 修法：池值初始化放到**重复数据检查之后**；在 NU6.1 激活高度加覆盖所有池的供给检查点；启动时从块数据**重算**检查点之后的屏蔽池增量。
- 同批另把 ZIP 209 非负规则扩到透明池、延迟开发基金池，并要求总供给（无溢出加法）不得超过规范上限。本页主句是跟踪复位，不是那条加严。
- 官方写：闸门加严只在「再出现一次本意安全性质被破坏」时才会碰到共识。Zebra 此前已用可检查算术，把每个池写成非负且不超过规范上限。

本页不写怎样送重复头、不抄发布线版本 / 激活高度 / 规范金额上限进不确定常量。跟踪字段被复位，不是闸门还在转。

## 1. 发生了什么

闸门口上挂着计数器。  
计数器归零，门还在那儿。  
门还在那儿，不是闸已经拦住负池。  
重复的一块头，可以把计数器悄悄清掉。  
清掉之后，规范里的「池不得变负」还写着，实现却不再跟。  
跟踪字段空了，不是 ZIP 209 已执行。

## 2. 根因

闸门谓词吃的是**持久跟踪状态**，不是每块当场从规范对象复算出来的池余额。  
重复头被当成「已经见过」，初始化却先于去重；跟踪字段被写成默认空。  
空跟踪 + 仍宣称执行 ZIP 209 = 闸门名义在、算术关。  
损坏增量若已落盘，重启会把错账当历史。

这不是：

| 案 | 对象 |
|----|------|
| 不变量 2 | 供给守恒口号；本页是跟踪被关，不是已证明通胀 |
| 不变量 13 / CVE-2019-7167 | 验证明 ≠ 供给；本页是实现跟踪 ≠ 闸门 |
| 不变量 74 | 奖励池溢出停链；本页是闸门关掉，不是入金溢出 |
| 不变量 5 | 崩溃半块；本页是重复头复位跟踪 |
| 不变量 102 / ZIP 257 | 电路 ≠ 陈述；本页是池跟踪 ≠ 闸门 |
| 不变量 105 | 反序列化归一化 ≠ 编码必须为零；本页是头去重与跟踪初始化顺序 |
| 本页 | **重复头复位跟踪 ≠ 闸门还在转；检查点 / 启动重算 ≠ 旧跟踪已经可信；ZIP 209 写在规范里 ≠ 实现字段还活着** |

## 3. 被破坏的 invariant

- 池闸门必须吃可复算或已交叉核对的跟踪，不得被重复头静默清零（不变量 104）
- 名义上执行 ZIP 209 不得充当跟踪字段仍有效
- 启动必须能从块数据重算检查点之后的增量，不得只信盘上已写的池差

## 4. 为什么测试没发现

幸福路径：每块头只来一次，跟踪从创世连续加。  
绿测试只覆盖「新头、字段还在」。  
边角要：同一头再进一次，初始化是否先于去重；盘上增量是否被改坏后仍当历史。

## 5. 修复

官方：初始化挪到去重之后；NU6.1 供给检查点覆盖所有池；启动从块数据重算屏蔽增量。  
另把非负扩到透明 / 延迟池，并加总供给上限——那是加严，不是本条「复位」已经消失。  
Zebra 的可检查算术不是 zcashd 跟踪字段已经活着。

## 6. 「不确定」若同类

1. 第一版可以不做屏蔽池 / 多池闸门。透明短规则下，供给必须能从规范对象当场复算。
2. 若做池跟踪：初始化必须在「已见过这块」判定之后。去重不是跟踪已安全。
3. 落盘的每块增量必须能从块体重算核对。盘上数字不是历史已可信。
4. 规范段落写着「池不得变负」，不是实现字段还在转。
5. 这和供给口号（2）、验证明≠供给（13）、奖励池溢出停链（74）、电路≠陈述（102）、归一化≠编码（105）不是同一句。
6. 不要写怎样送重复头。不要抄版本 / 高度 / 规范金额上限。

## 7. 回归测试

形状（不是利用包）：文案把重复头复位跟踪写成闸门还在转必须红。把 ZIP 209 写在规范里写成实现字段仍有效必须红。把启动重算写成旧盘上增量已经可信必须红。把本条加严总供给写成复位已消失必须红。与 13 / 74 / 102 / 105 糊成「供给坏了」一句必须红。

**事实来源：** [ZIP 256](https://zips.z.cash/zip-0256)；ZIP 209 闸门原文由 ZIP 256 引用。
