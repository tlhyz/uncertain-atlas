# 失败案：CSA-2026-001 Tachyon —— 验 commit 的路径必须与推导块时间的路径用同一份集合

层：**协议 + 实现**（BFT Time；任何依赖块时间戳的模块都在冲击面里）

官方披露：[CSA-2026-001 / GHSA-c32p-wcqj-j677](https://github.com/cometbft/cometbft/security/advisories/GHSA-c32p-wcqj-j677)。咨询标 **Critical**（ACMv1.2：Catastrophic Impact, Possible Likelihood）。受影响：咨询写 **所有版本**的 CometBFT。本页不另编 CVE——咨询未给 CVE ID。

**事实（官方原文能对上的句子）：**

- 漏洞在 BFT Time 实现里：验 commit 签名的方式，和推导块时间的方式**不一致**。
- 这打破 BFT Time 的一条核心保证，咨询原文：*A faulty process cannot arbitrarily increase the Time value.*
- 下游：任何依赖块时间戳的模块、智能合约或系统都受影响。
- 无有效绕过，必须升级。修复：v0.38.21、v0.37.18（以及当时的 `main`）。

规范对照（[bft-time.md](https://github.com/cometbft/cometbft/blob/main/spec/consensus/bft-time.md)，事实）：块 `H` 的 `Time` 是 `LastCommit` 里 Precommit 时间戳的加权中位数，必须可复算；属性 **Byzantine Fault Tolerance** 写：给定形成 `LastCommit` 的那份 `Commit`，合法 `Time` 的范围只由正确验证者的 Precommit 定义，故障验证者不能任意抬高或压低。咨询打破的是「不能任意抬高」这半句。本页不发明两条路径具体差在哪一字段。

## 1. 发生了什么

节点以为：commit 签名都验过了，中位数就一定落在诚实者给的时间里。  
官方说：验签走一条路，算 `Time` 走另一条路，两条路对不上时，故障进程可以把时间任意抬高。依赖块时间的应用会跟着错。

「能复算中位数」不够。复算用的那一袋时间戳，必须就是验过签的那一袋票。

## 2. 根因

同一份 `LastCommit` 被拆成两个实现对象：一个用来 Verify，一个用来 `MedianTime`。  
规范保证建立在「就是这一份 Commit」。实现若让两份分叉，BFT Time 的拜占庭界限只写在纸上。

这不是：

| 案 | 对象 |
|----|------|
| 不变量 40 / PBTS 精读 | 必须点名 PBTS 还是 BFT Time；中位数可复算 |
| CVE-2024-52912 | 网络调整钟绕过太新上限 |
| 不变量 41 | Bitcoin MTP 三把尺 |
| 本页 | **验 commit σ 的集合 ≠ 推导 Time 的集合** |

## 3. 被破坏的 invariant

- 推导块时间用的时间戳集合，必须与已验收的 commit 签名集合是同一对象（不变量 61）
- 能复算中位数 ≠ 故障者不能抬高 Time
- 无绕过 ≠ 可以靠「应用别读块时间」当协议已安全

## 4. 为什么测试没发现

幸福路径：两路径读同一份结构，诚实者时间靠近。  
只测「中位数复算对得上提案里的 Time」会绿。  
不测「验签接受的票」和「进中位数的戳」是不是同一集合。

## 5. 修复

- v0.38.21 / v0.37.18：官方只写「已修」。本页不把补丁行发明成新规范。
- 无绕过。

升级补的是实现一致性。规范那句保证不会因为「我们复算过」自动成立。

## 6. 「不确定」若同类

1. 若抄 BFT Time：必须写出「Verify(Commit) 用的票」和「MedianTime 用的戳」是同一规范化对象。缺这句不得宣称故障者不能改时间。
2. 第一版更该点名 PBTS（规范已鼓励新链用），不要把「BFT Time 四个字」当已选算法，也不要把 Tachyon 写成「所以 PBTS 没有时间问题」——PBTS 是另一把尺。
3. 任何按块时间解锁、过期、发奖的应用，必须写清它读的是哪一种算法产出的字段。
4. 不要抄规范示例里的投票权或 1 ms 增量。
5. 不要写怎样抬高 Time。

## 7. 回归测试

形状（不是利用包）：验签接受的 Precommit 集合与 `MedianTime` 输入集合不一致 → 必须拒块。文案把「中位数复算通过」写成「故障者不能抬高 Time」必须红。只测幸福路径复算不得标 PASS。
