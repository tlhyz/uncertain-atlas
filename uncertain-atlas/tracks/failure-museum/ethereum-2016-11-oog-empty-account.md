# 失败案：交易以 out-of-gas 结束不是空账户删除已经回滚

层：**实现 + 协议**（Geth 日志/journaling 在 OOG 时没把空账户删除撤回去；与多数其它客户端分叉；Parity 在预编译 OOG 的更窄边角也有同类）

官方披露：

- Ethereum Foundation：[Security alert 11/24/2016](https://blog.ethereum.org/2016/11/25/security-alert-11242016-consensus-bug-geth-v1-4-19-v1-5-2)（Vitalik Buterin，2016-11-25）。无 CVE。本页只采用该页已写出的句子。

**事实（官方原文能对上的句子）：**

- Geth 的 **journaling** 有问题，在块高度官方点名的那一高度造成**网络分叉**。Geth 1.5.3 修 journaling 并修分叉。
- 根因：导致**空账户被删**的交易若以 **out-of-gas** 结束，Geth **没有把这些删除回滚**。
- Parity 另有更窄边角：对预编译的 out-of-gas 调用，也错误地没回滚空账户删除。新 Geth 行为与当时 Parity 对齐。官方：约一周后状态清理结束，空账户将不再是一般担忧。
- 旧 Geth 从分叉点拉出的链，Parity 与新 Geth 都当非法；大约一百多个块之后被放弃。交易在网上广播，多数交易两边都有；旧链上的挖矿奖励与手续费作废。**双方现在都接受的那条链上的交易与块不会被回滚**。
- 已同步过叉点的节点，新版会从叉点重拉。不升级则停在不受支持的非法链。
- 官方继续建议：交易所与高价值用户跑**多家客户端**，若互相偏离超过官方写明的块数，自动停业务或进安全模式。

本页不写怎样造 OOG 删空户，不抄块号 / 弃链长度 / 安全模式块数进不确定常量。交易以 out-of-gas 结束，不是空账户删除已经回滚。

## 1. 发生了什么

一笔交易想擦掉空户口，气不够，中途倒下。  
规范说：倒下的那些擦除，要当没发生。  
一家客户端的日记本忘了把这笔擦除划掉。  
多数人看见户口还在，少数人看见户口没了。  
链从这里分成两本。  
气不够倒下，不是擦除已经撤销。

## 2. 根因

失败路径必须把本笔尝试过的状态改动全部撤回。空账户删除是状态改动。  
journaling 若只记「成功提交」，OOG 就会留下半笔删除。  
两家对「预编译 OOG 要不要撤」还可以再窄一档，但本页主句是：OOG ≠ 删除已回滚。  
弃掉少数链、重拉叉点，是部署止血，不是 journaling 已在规范里。

这不是：

| 案 | 对象 |
|----|------|
| 不变量 3 / CVE-2021-39137 | RETURNDATA 别名错根；本页是 OOG 回滚 |
| 不变量 5 | 崩溃半块；本页是交易内 OOG |
| 不变量 83 / Barberry | 空地址被写成类型；本页是空账户删除没撤 |
| 不变量 101 | gas 上限 ≠ 墙钟；本页是 OOG 的状态语义 |
| 本页 | **OOG 结束 ≠ 空账户删除已回滚；journaling 漏撤 ≠ 两客户端已同根；弃少数链 ≠ 旧奖励还在** |

## 3. 被破坏的 invariant

- 交易以 OOG / 失败结束时，本笔引起的空账户删除必须撤回（不变量 103）
- journaling 必须覆盖失败路径，不得只记成功提交
- 一家客户端与其余对不上，按分叉审，不得写成「多数已在正确链」就不用修
- 官方建议的多客户端偏离停业务，是部署句，不是本条已齐

## 4. 为什么测试没发现

幸福路径：OOG 发生在没删空户的交易，或删除已提交成功。  
只测「气不够则 revert 存储槽」会绿，漏「删除空账户」这条日记。  
边角要：本笔删了空户 + 以 OOG 结束 + 两家客户端对结果。

## 5. 修复

官方：Geth 1.5.3 修 journaling，并从叉点重放。新行为对齐当时 Parity 的更窄语义。  
状态清理被写成「空账户将不再一般令人担心」——那是当时运维句，不是空账户原语已从协议消失。

## 6. 「不确定」若同类

1. 第一版可以不做可 OOG 的通用 VM，也尽量不自动删「空」账户。
2. 若做失败回滚：必须列出本笔可能留下的每一种状态改动，失败路径逐项测。日记本只记成功则按半写状态审。
3. 多客户端对不上超过命名窗，产品应停结算，不得只跟多数实现。
4. 这和执行别名错根（3 / 39137）、崩溃半块（5）、空地址类型（83）、gas≠墙钟（101）不是同一句。
5. 不要写怎样踩 OOG 删户。不要抄块号 / 弃链长度 / 安全模式块数。

## 7. 回归测试

形状（不是利用包）：文案把 OOG 结束写成空账户删除已回滚必须红。把 journaling 漏撤写成两客户端已同根必须红。把弃少数链写成旧链奖励仍结算必须红。与 39137 / Barberry / gas≠墙钟糊成一句必须红。
