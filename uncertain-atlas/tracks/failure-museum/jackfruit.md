# 失败案：Jackfruit ValidateBasic 读本地钟不是已经确定

层：**协议 + 实现**（状态机里的「现在」必须是块时间；不是漏掉 ValidateBasic，也不是 PBTS 提议者本地钟）

官方披露：

- GitHub：[GHSA-2p6r-37p9-89p2](https://github.com/cosmos/cosmos-sdk/security/advisories/GHSA-2p6r-37p9-89p2)。咨询标 **High**。CVE：**CVE-2021-41135**。影响：咨询正文写 0.43.x 与 0.44.{0,1}；页眉 Affected 写 0.44.x。补丁：正文写 **0.44.2**；页眉 Patched versions 写 **None**——两处都记，以复盘与正文的 0.44.2 为准，不把页眉 None 写成「没有补丁」。
- 复盘：[Security Advisory Jackfruit](https://forum.cosmos.network/t/cosmos-sdk-vulnerability-retrospective-security-advisory-jackfruit-october-12-2021/5349)（2021-10-19）。官方定性 **high-severity**，共识停机。

**事实（官方原文能对上的句子）：**

- `x/authz` 的某个 `ValidateBasic` **行为不确定**，可导致**共识停机**。
- `MsgGrant` 的 `Grant` 带用户给的过期时间。`Grant.ValidateBasic()` 把这个时间与**节点本地钟**比较。
- 本地钟是主观的，因而**不确定**。攻击者可以造许多过期时间接近的 Grant，并在临近过期时行使授权；有的节点会当成已过期，有的不会，从而停链。
- 状态机里要用的「现在」，正确对象是**块头时间戳**（共识达成的 BFT 钟），不是节点本地时间。
- 这次检查只是额外防守，keeper 里已有完整、正确的授权参数校验。因此 v0.44.2 的修法是**整段删掉**这次检查。复盘说以后可以加回来，但必须改用块时间。
- 咨询：**资金与余额安全**。
- 复盘：任何开了 `authz`、跑受影响版本的链，**任何能发交易的人**都可能让它停。恢复要打补丁，并**回滚最新一块**。
- 当时只有少数链在跑受影响版本。**Cosmos Hub 不受影响**。不要把「Hub 没事」写成模块已安全。

本页不写过期时间如何间隔、不写怎样临近行使、不抄示例秒数、不把删掉防守检查写成「ValidateBasic 可以乱读钟」。第一版可以不装授权代发。

## 1. 发生了什么

授权写了一张「过期时间」。  
基本校验拿出自己手表来比。  
两台诚实机器的手表差几秒。  
一张交易，一边说过期，一边说没过期。  
状态对不上，高度停。  
钱还在。链不转了。  
ValidateBasic 读本地钟，不是已经确定。

## 2. 根因

把「现在」写成了节点墙上的钟。  
基本校验跑在状态机入口，入口一旦读主观钟，诚实节点会走出两个世界。  
keeper 里其实已经用对了时间；入口多出来的那一刀，反而把确定性砍断。

这不是：

| 案 | 对象 |
|----|------|
| 不变量 3 / L1.6 | 一般确定性：Apply 不得读本地钟或 OS 随机数 |
| 不变量 40 / PBTS | 提议者本地钟是块时间算法，timely 不通过只 prevote nil，不是 Grant 过期 |
| 不变量 29 / CVE-2024-52912 | 对等调整钟绕过上限，拒收规范新块 |
| 不变量 77 / ISA-2025-001 | 跨链 ack JSON 反序列化必须确定 |
| 不变量 81 / Elderflower | 代发管道漏掉 ValidateBasic ≠ 内层已认证 |
| 本页 | **ValidateBasic 读节点本地钟 ≠ 已确定；过期比较必须用块时间，或不要放在这条不确定的入口** |

## 3. 被破坏的 invariant

- 状态机入口的「现在」必须是块时间，不得是节点本地钟（不变量 82）
- `ValidateBasic` 绿了不是已经确定——若它读了主观钟
- 能发交易的用户集合就是能引入停链状态的集合（开了该模块时）

## 4. 为什么测试没发现

幸福路径：过期时间离「现在」很远，所有节点的手表都判同一边。  
只测「授权能发出去」会绿，看不见临近过期时两边各执一词。  
单节点测试永远只有一只表。

## 5. 修复

官方：v0.44.2 删掉这次本地钟比较。资金安全，不必迁余额。  
恢复当时还要回滚最新一块——补丁本身不是已经回到分叉前。  
以后若加回防守，必须改用块时间。删掉 ≠ 允许别的入口继续读 `time.Now()`。

## 6. 「不确定」若同类

1. 第一版可以不装授权代发。
2. 若状态机要判断过期 / 太早 / 太晚：只读块头时间（或规范写明的 BFT 钟），不要读节点本地钟。
3. `ValidateBasic` / 入池预检若跑进共识，禁止读墙钟、禁止读 OS 随机数。额外防守可以删，但不能用主观钟去「加强」。
4. 能启用该模块并发交易的人，是活性对手。
5. 这和一般确定性（3）、PBTS（40）、调整钟（29）、ack JSON（77）、漏掉 ValidateBasic（81）不是同一句。
6. 不要抄 authz。不要把「Hub 当时没中」写成模块可忽略。不要抄回滚高度当产品常量。

## 7. 回归测试

形状（不是利用包）：文案把 `ValidateBasic` 读 `time.Now()` 写成已确定必须红。过期比较用节点本地钟、两节点各执一词仍标 PASS 必须红。把「资金安全」写成链不会停必须红。把 Elderflower（漏检查）与本页（检查读钟）糊成一句必须红。
