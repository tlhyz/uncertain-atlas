# 失败案：ASA-2024-005 再委托不是待执行罚没的洗白

层：**经济 + 协议**（待执行 slash 必须跟着质押走；不是证据上链，也不是证据窗）

官方披露：Cosmos SDK [ASA-2024-005 / GHSA-86h5-xcpx-cfqc](https://github.com/cosmos/cosmos-sdk/security/advisories/GHSA-86h5-xcpx-cfqc)。咨询标 **Low**，影响写成 Slashing Evasion。受影响：`<= 0.50.4`、`<= 0.47.9`。补丁：`0.50.5`、`0.47.10`。本页不另编 CVE——咨询未给 CVE ID。

**事实（官方原文能对上的句子）：**

- 罚没机制里存在一个问题，可能让人在罚没事件中**躲开罚没惩罚**。
- 若一笔委托**参与了**验证者的拜占庭行为，且该验证者**尚未被罚没**，则该委托有可能通过**再委托行为**躲开**待执行的**罚没惩罚。
- 修法：增加额外校验，限制这种行为。

本页不写怎样再委托、不写时间窗数字、不把 Low 写成「不确定可以忽略」、不抄版本号当常量。

## 1. 发生了什么

验证者做了该罚的事。罚还没落下来。  
委托人本该一起挨。  
他把质押再委托到别处。待执行的罚没没跟上。  
证据可以已经在路上。钱已经走了。

## 2. 根因

罚没对象被当成「此刻还挂在这个验证者名下的委托」，而不是「当时参与了该过错的那份质押」。  
再委托改的是现在的挂钩，不是过去的责任。

这不是：

| 案 | 对象 |
|----|------|
| 不变量 21 | 证据上链 ≠ 已 slash；公式在应用侧 |
| 不变量 26 | 先写两票谓词和谁执行，再谈罚金 |
| 不变量 46 / ASA-2024-004 | 证据窗必须长于解绑；过期是「且」 |
| EigenLayer 过滤器 | AVS 罚没不必客观可归属 |
| 本页 | **待执行罚没必须跟着质押走；再委托 ≠ 洗白** |

## 3. 被破坏的 invariant

- 待执行的罚没必须跟着当时参与过错的质押走（不变量 72）
- 再委托不得写成待执行惩罚已经消失
- 「验证者还没被 slash」不是委托人已经干净

## 4. 为什么测试没发现

幸福路径：过错发生后立刻 slash，中间没有再委托。  
只测「证据上了、当前委托被罚」会绿，看不见「待执行窗口里把质押挪走」。  
再委托被当成普通资金流动。

## 5. 修复

官方：增加额外校验，限制该再委托行为。升级到补丁版本。  
把证据窗加长 ≠ 本条已经写清。窗管的是「还能交证据」；本条管的是「罚没对象是不是还认得出那份质押」。

## 6. 「不确定」若同类

1. 若做委托 / 再委托：必须写清待执行罚没的对象是**过错当时的质押份额**，不是「现在还挂在谁名下」。
2. 再委托、解绑、转委托都必须先问：这笔钱是否还带着未执行惩罚。
3. 这和上链≠slash（21）、两票谓词（26）、默认证据窗（46）不是同一句。
4. 不要把咨询的 Low 写成可以不做。躲开惩罚是经济层失败，不是「不严重」。
5. 第一版可以不做再委托。若做，必须有回归：待执行 slash 期间再委托仍能罚到原份额。

## 7. 回归测试

形状（不是利用包）：文案把再委托写成待执行罚没已消失必须红。过错后、slash 前再委托、原份额仍标未罚且 PASS 必须红。只测「当前还挂着的委托被罚」不得标「再委托已安全」。
