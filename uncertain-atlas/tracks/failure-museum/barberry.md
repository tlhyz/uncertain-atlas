# 失败案：Barberry 别人把你的地址初始化成只进不出不是还没开户所以安全

层：**协议 + 实现 + 经济**（账户类型必须由权利人初始化；不是被挡模块账户停链，也不是授权代发漏检查）

官方披露：

- GitHub：[Barberry / GHSA-j2cr-jc39-wpx5](https://github.com/cosmos/cosmos-sdk/security/advisories/GHSA-j2cr-jc39-wpx5)。徽章标 **Moderate**。受影响：`x/auth` 定期归属，`>= v0.46.0, <= v0.46.12` 与 `>= v0.47.0, <= 0.47.2`。补丁：`v0.46.13`、`v0.47.3`。本页不另编 CVE——咨询写 No known CVE。
- 论坛公告：[Cosmos SDK Security Advisory Barberry](https://forum.cosmos.network/t/cosmos-sdk-security-advisory-barberry/10825)（2023-06-07）。公告正文称 **high-severity**。两级都记，不选边。

**事实（官方原文能对上的句子）：**

- 在 `x/auth` 的 `PeriodicVestingAccount` 里，攻击者可以把**受害者的账户**初始化成一份**恶意归属账户**：允许存款，**不允许取款**。
- 受害者随后把钱存进去，这些钱被**永久锁住**，取不出来。
- 若某条链把定期归属**回移**到更早的 SDK，那些网同样受影响。
- **没有绕过**。必须立刻升级。
- 论坛：跑 v0.46 / v0.47 的链受影响；v0.45 及以下若回移了模块功能，**可能**也脆弱。
- 论坛补丁说明：所有用 SDK v0.46.0 / v0.47.0 及以上的链必须立刻升到 v0.46.13 / v0.47.3。
- 论坛：投票权 **33%+1** 升完，这条链「不受该漏洞影响」；**66%+1** 升完，这条链「不会因这次升级停」。滚动升级或协调升级都可以，选更快到 66%+1 的那种。
- 论坛另写机制：不同、互不兼容的二进制若同时在跑——少数派（<33% 投票权在一边）会看到 **AppHash** 错；投票权差落在 33%–66% 则可能**停链**。不要把这两句抄成不确定法定人数。

本页不写怎样把别人的地址初始化成归属账户、不抄版本号、不把 33/66 写成不确定门槛、不把 Cosmovisor / ics23 热补当成同一对象。第一版可以不装定期归属。

## 1. 发生了什么

地址还空着。  
别人先替你建了一本「只进不出」的归属户口。  
你后来把钱打进去。  
钱进得去，出不来。  
空地址不是还没人动过，所以安全。

## 2. 根因

「这个地址还没有账户对象」被当成「只有本人能决定它是哪种账户」。  
定期归属允许先写类型、后等入金。类型若能被外人写成只进不出，入金就是送锁。

这不是：

| 案 | 对象 |
|----|------|
| 不变量 75 / ASA-2024-003 | 未初始化的**被挡模块账户**不是可归属的地址；叫到会停链 |
| 不变量 81 / Elderflower | 授权代发漏掉 ValidateBasic ≠ 内层已认证 |
| 不变量 14 | 升级不得静默改供给解释 |
| 不变量 79 / Dragonberry | +⅓ 打补丁让 ICS-23 利用变成可见停链 |
| 本页 | **别人把你的地址初始化成只进不出 ≠ 还没开户所以安全；入金 ≠ 还能取出** |

## 3. 被破坏的 invariant

- 他人不得把尚未由权利人初始化的地址写成只进不出的归属账户（不变量 83）
- 入金不是还能取出
- 空地址不是「还没有账户类型」

## 4. 为什么测试没发现

幸福路径：本人先开普通账户，再自己建归属，钱按期解锁。  
只测「定期归属能存能取」会绿，看不见「别人先写类型、你后存钱」。  
空地址测试常常从零开始建本人账户，不测「地址已被外人写成另一种对象」。

## 5. 修复

官方：升到补丁版。无绕过。回移了定期归属的更早线也要升。  
33%+1 投票权升完，官方说不再受**这个洞**影响；66%+1 才说不会因**版本不一致**停。前一句不是后一句。  
滚动升级不是已经全网同一二进制。

## 6. 「不确定」若同类

1. 第一版可以不装定期归属 / 他人可初始化的账户子类型。
2. 若装：账户类型必须由权利人（或创世）初始化。外人不得把空地址写成只进不出。
3. 入金路径必须在「这是可花费余额」还是「这是锁仓」上拒绝未知类型，而不是默默收下。
4. 不要把「地址还空」写成安全。不要把 33% / 66% 抄进不确定法定人数。
5. 这和被挡模块账户停链（75）、授权代发漏检查（81）、升级改供给（14）不是同一句。
6. 不要抄 vesting。不要写怎样初始化别人的地址。

## 7. 回归测试

形状（不是利用包）：文案把「地址还空」写成不能被外人写成归属账户必须红。他人初始化只进不出、随后入金取不出来仍标 PASS 必须红。把 33%+1 升完写成全网已齐 / 不会停必须红。把本页与 ASA-2024-003（被挡模块账户停链）糊成一句必须红。
