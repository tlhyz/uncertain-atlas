# 失败案：ISA-2025-002 可选模块的 EndBlocker 出错不是局部失败

层：**协议 + 实现 + 部署**（EndBlocker 里的错误会停链；不是解码递归，也不是治理改启用高度）

官方披露：Cosmos SDK [ISA-2025-002 / GHSA-47ww-ff84-4jrg](https://github.com/cosmos/cosmos-sdk/security/advisories/GHSA-47ww-ff84-4jrg)。咨询标 **High**。受影响：`<= v0.47.16`、`<= v0.50.12`。补丁：`v0.47.17`、`v0.50.13`。咨询写无已知绕过。本页不另编 CVE——咨询未给 CVE ID。

**事实（官方原文能对上的句子）：**

- 群组模块里，**恶意提案**会在该模块的 **end blocker** 触发错误，可能导致**整条链停摆**。
- **任何能与群组模块交互的用户集合**都可能引入这种状态。
- 受影响的是使用 `x/group` 的未打补丁链。

亲戚（不另立不变量）：同模块更早的 [ASA-2025-003 / GHSA-x5vx-95h7-rv4p](https://github.com/cosmos/cosmos-sdk/security/advisories/GHSA-x5vx-95h7-rv4p)（High）——恶意提案导致**除零**，随后因该错误停链；能与模块交互的用户可引入。补丁在 `v0.50.12` / `v0.47.16`。除零是那一页的实现细节，不是本页的全部。

本页不写提案怎么拼、不写 end blocker 里哪一行出错、不抄 ACM 分数、不把官方测试过的其它链名写成那些链的规范保证。

## 1. 发生了什么

群组模块看起来像「一群人投票办事」的可选插件。  
有人丢进一份坏提案。  
错误发生在**出块结尾的 EndBlocker**，不是某笔交易自己被标 Code。  
交易里的失败可以只红这一笔。EndBlocker 失败会让高度走不下去。  
能跟这个模块说话的人，就是能把停链状态送进全网的人。

## 2. 根因

Begin/EndBlock 跑在高度提交路径上。这里的错误不是「这一笔无效」，是「这一高卡住」。  
可选模块一旦挂上 EndBlocker，它的故障面就是共识活性面。  
「只是治理/群组」不是局部失败。

这不是：

| 案 | 对象 |
|----|------|
| 不变量 58 / ASA-2024-001 | 治理改扩展启用高度，验证写错则 panic |
| 不变量 60 / ASA-2025-003（CometBFT 位图） | 结构未验完就流言，最坏停网 |
| 不变量 69 | Prepare 提出 Process 拒的块，出块减少 |
| 不变量 70 / ASA-2024-0012 | 外层交易上限不是内层解码已有界 |
| 本页 | **可选模块 EndBlocker 出错 ≠ 局部失败；能交互的用户集合 = 能引入停链状态的集合** |

## 3. 被破坏的 invariant

- 可选模块的 EndBlocker 出错必须当成会停链（不变量 71）
- 能提交该模块提案的用户集合就是能引入停链状态的集合
- 「模块可选」不是「失败可跳过」

## 4. 为什么测试没发现

幸福路径：提案形状正常，EndBlocker 返回空错误。  
只测「模块交易 Code=0」会绿，看不见「结尾钩子一炸，高度停」。  
可选模块被当成可以晚一点再审的插件。

## 5. 修复

官方：升级到补丁版本。咨询写无已知绕过。  
关掉或不用 `x/group` 是部署选择，不是「EndBlocker 出错已经不会停链」这句产品句已经写清。亲戚 ASA-2025-003 的除零补丁 ≠ 本条已经修完——官方仍出了后一页。

## 6. 「不确定」若同类

1. 第一版可以不装带 EndBlocker 的可选模块。
2. 若装：必须写清——该模块错误路径是停链，还是只红提案。默认按停链审。
3. 能与该模块交互的主体，必须写成活性对手，不是「只是治理用户」。
4. 这和启用高度治理 panic（58）、位图先流言（60）、序号装箱（69）、外层解码（70）不是同一句。
5. 后量子对象更大、模块更多时，更不能把「可选」写成「失败可吞」。

## 7. 回归测试

形状（不是利用包）：文案把「可选群组/治理模块」写成局部失败必须红。能与该模块交互的用户引入 EndBlocker 错误、链仍标 PASS 必须红。只测模块交易成功不得标「EndBlocker 已安全」。不要用亲戚除零页代替本条。
