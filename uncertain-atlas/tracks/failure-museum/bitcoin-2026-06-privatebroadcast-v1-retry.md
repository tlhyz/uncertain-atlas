# 失败案：privatebroadcast 开关不是 IP 已经不暴露；v2 握手失败后的 v1 重连不是仍走代理

层：**实现 + 部署 + 网络**（`-privatebroadcast` 经 Tor 连宣称支持 BIP324 的清网对等节点；v2 握手失败后改 v1 直连，源 IP 暴露给接收方）

官方披露：

- Bitcoin Core 官方页：[Private Broadcast May Reveal Sender IP Address in Bitcoin Core 31.0](https://bitcoincore.org/en/2026/06/06/privatebroadcast-ip-leak/)（2026-06-06）。本页只采用该文已写出的句子。无 CVE 写入该页。

**事实（官方原文能对上的句子）：**

- 新功能 `-privatebroadcast` 的隐私保证写在发行说明：接收方**永远不知道**发起者 IP。该保证在某一发布线上可破。
- 条件合取：打开该功能；用 `sendrawtransaction` 广播（钱包常用发送 RPC **不**走这条，不受影响）；Tor 可用于出站；清网 IPv4/IPv6 仍能直连；未关 BIP324 v2。
- 选中宣称支持 v2 的清网对等节点时，**第一次**连接按预期走 Tor。v2 握手失败后，实现改走 v1 **重连**；这次重连**不**走 Tor，直连对等节点，源 IP 暴露给接收方。
- 一开始就走 v1（对等节点未宣称 v2）的连接仍走 Tor，不受影响。洋葱 / I2P 对等节点的 v1 重试仍走各自代理，不暴露清网 IP。
- 官方：诚实 v2 对等节点很少握手失败；最可能是恶意对等节点故意关掉握手，逼出 v1 重试。
- 修法随下一小版本。热修可关该功能、关 v2、或把清网出站也走代理——各有官方写明的代价。不要把热修旋钮抄进不确定默认。

本页不写怎样关握手、不抄版本 / 端口进不确定常量。开关开着，不是 IP 已经不暴露。

## 1. 发生了什么

门上写：送信不露地址。  
第一趟绕路走。  
对面把门一关，说加密握手没成。  
第二趟抄近路，门牌号送给了对面。  
近路，不是还在绕路。  
开关还在「隐私广播」。  
开关还在，不是地址已经藏住。

## 2. 根因

「经代理出发」必须盖住**每一次**出站尝试，包括失败后的协议降级。  
v2 失败 → v1 重连是另一条连接，不是第一次连接的继续。  
第一次走了 Tor，不是第二次已经走 Tor。  
功能名 / 发行说明保证，不是降级路径已覆盖。

这不是：

| 案 | 对象 |
|----|------|
| 不变量 54 / CVE-2017-18350 | 出站代理是另一信任对象；本页是**本该走代理的重连没走** |
| 不变量 55 | 付款 URI；本页是广播路径 |
| 不变量 111 | 钱包加载泄 TXID；本页是清网 IP |
| 不变量 36 | 宣布 ≠ 收到；本页是隐私 hop |
| 本页 | **privatebroadcast 开关 ≠ IP 已经不暴露；v2 失败后的 v1 重连 ≠ 仍走代理；第一次走 Tor ≠ 降级已覆盖** |

## 3. 被破坏的 invariant

- 宣称不暴露源 IP 的广播路径，每一次出站（含握手失败后的降级）必须仍走同一代理谓词（不变量 112）
- 发行说明保证不是降级重连已覆盖
- 钱包发送 RPC 不走该路径，不是该功能已经安全

## 4. 为什么测试没发现

幸福路径：v2 握手成功，或对等节点从不宣称 v2。  
绿测试只覆盖「第一次连接走 Tor」。  
边角要：宣称 v2 的清网对等节点在握手后断开；第二次连接的源地址是不是清网。

## 5. 修复

官方：下一小版本修。此前可关功能、关 v2、或清网也走代理。  
关 v2 / 全走退出节点，官方写了指纹与日蚀代价。热修不是谓词已齐。

## 6. 「不确定」若同类

1. 第一版可以不提供「隐私广播 / 单笔另开连接」开关。默认全节点经既有出站策略传播。
2. 若提供：每一次重连 / 降级必须复用同一代理谓词。产品句不得只写开关名。
3. 第一次走代理不是降级已覆盖。恶意对等节点关掉握手按设计内对手审。
4. 这和「代理是另一信任对象」（54）、付款 URI（55）、钱包泄 TXID（111）不是同一句。
5. 不要写怎样关握手。不要抄版本 / 端口。

## 7. 回归测试

形状（不是利用包）：文案把 privatebroadcast 开关写成 IP 已经不暴露必须红。把 v2 失败后的 v1 重连写成仍走代理必须红。把第一次走 Tor 写成降级已覆盖必须红。把钱包发送 RPC 不受影响写成该功能已经安全必须红。与 54 / 55 糊成一句必须红。
