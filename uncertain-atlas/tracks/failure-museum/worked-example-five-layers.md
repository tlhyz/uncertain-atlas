# 实例：同一通胀案，五层各说什么

目的 A。不是考试，不复现利用。  
先修：L0.8、博物馆 [CVE-2018-17144](cve-2018-17144.md)、语料 C01/C02。

同一句话「2018 年 Bitcoin 差点凭空出币」，五层的答案不一样。混写成「链不安全」，就是 L0.8 禁止的假句。

---

## 故事（已归档事实，不新编）

特制交易让**当时的 Bitcoin Core** 接受同一输入被花费两次的块。协议意图仍是：不能双花、供给有上限。漏洞在被广泛用于主网通胀前修复。编号 CVE-2018-17144。

---

## 五层各钉在哪

| 层 | 对本案 | 不是 |
|---|---|---|
| 密码学 | 哈希与交易签名假设可以仍然成立。没人需要伪造签才能构造重复 vin | 「椭圆曲线被破了」 |
| 协议 | 规则句没变：一输出一花费、供给守恒 | 「Nakamoto 允许双花」 |
| 实现 | 某条检查路径没把重复输入挡死。这是本案的钉子 | 「全节点文化所以代码等于规范」 |
| 部署 | 未升级的节点会跟着错块走；升级是社会/运营过程 | 「部署拓扑发明了通胀」 |
| 经济 | 若错块被挖出且经济节点承认，持币人被稀释。本案在广泛利用前修好 | 「有人愿意通胀所以协议允许」 |

**事实：** 绿测试覆盖了幸福路径，没覆盖「恶意重复 vin」。测试通过 ≠ 五层都成立。  
**推断：** 当时若有第二实现且对同一块拒绝，差分会先红。  
**建议：** 「不确定」把 C01/C02 写成每块必跑、不得 skip 当 PASS。

---

## 和隔壁案对照（防止记成同一个故事）

| 案 | 主要坏在 |
|---|---|
| CVE-2018-17144 | 实现没守住协议的「无双花」 |
| CVE-2010-5139 | 实现把输出求和溢出成了合法余额 |
| BIP 50 | 实现资源上限变成未写明的共识 |
| CVE-2012-2459 | 协议构造允许不同叶列表同根；实现还可能拉黑合法块 |
| CVE-2019-7167 | 密码学：Sprout 可靠性破，验证明通过仍可能伪造币 |
| CVE-2021-39137 | 实现：一家 EVM 把返回缓冲和内存别名，算出错根 |

对照方法：L9.9。语料表：[`../../libraries/adversarial-corpus/README.md`](../../libraries/adversarial-corpus/README.md)。

## 对「不确定」

结算文案若写「不会凭空出币」，必须能指出：

1. 协议句在哪；  
2. 哪条自动测试看守实现；  
3. 未升级节点跟错块时，用户哪句承诺作废。

答不出第 2 条，就是还在靠「我们觉得 Core 很小心」。
