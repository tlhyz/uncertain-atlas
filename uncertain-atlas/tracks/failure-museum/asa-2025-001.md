# 失败案：ASA-2025-001 blocksync 目标高度必须可归因，且可随来源撤回

层：**实现 + 网络**（加入网络时的 blocksync；共识没有改块规则）

官方披露：[ASA-2025-001 / GHSA-22qq-3xwm-r5x4](https://github.com/cometbft/cometbft/security/advisories/GHSA-22qq-3xwm-r5x4)。咨询最初标 Medium；**2026-03-06 官方改口**为 Informational（Negligible Impact）。GitHub 页现标 Low。本页三档都记下，不另抬一级。咨询未在本页抓到的正文里给 CVE ID——不编。

**事实（官方原文能对上的句子）：**

- 恶意对等节点可干扰本节点用 blocksync 追尖。
- 对等节点连上时报告 `base` 与 `latest`。`base` 是它有的最低高度；`latest` 告诉同步者网络尖。
- 正常情况：同一对等节点只报**递增**的 `latest`。
- 若对等节点交不出 latest 块，它被移除，目标高度按**其他**节点的 `latest` 重算。
- 以前不检查：同一对等节点先报 `latest = X`，紧接着报 `Y`，且 **X > Y**。同步者会无限去追那个更高的 X。即使该对等节点断开，目标高度**也不会重算**，因为本节点「不知道 那个 X 是从哪来的」。
- 资格限定（官方）：发送端须引入恶意代码，先报一个不存在的 `latest`，再报更低的 `latest`；且受害者正在走 blocksync。
- 修复：v1.0.1、v0.38.17。
- 绕过：从日志认出那条「非法高度」，在 p2p 层 ban。改口后官方还写：blocksync 期间别连恶意对等节点即可避开。

亲戚（更薄、不单开谓词）：[ASA-2024-008](https://github.com/cometbft/cometbft/security/advisories/GHSA-hg58-rf2h-6rr7) 只写恶意对等节点可让 blocksync panic / 进入灾难状态 / 永远切不进共识。本页钉的是**目标高度的归因与回退**，不是那句泛化不稳。

本页不写怎样连报 X 再报 Y。咨询示例高度不是不确定常量。

## 1. 发生了什么

新生节点问邻居：尖在哪。一个邻居先报一个很高的尖，再改口报低的。节点把第一声当成全网目标，邻居走了目标还在。blocksync 追一个没人认领的高度，进不了共识。

对等节点报的 `latest` 不是全网尖。

## 2. 根因

目标高度被写成一个无来源的整数。  
来源断开后，数字还在。  
「别人交不出块就换人重算」只覆盖了**当前**交不出的人，没覆盖「这个数字是谁留下的」。

这不是：

| 案 | 对象 |
|----|------|
| CVE-2024-52922 / 不变量 36 | 宣布新块 ≠ 已收到 |
| 不变量 38 / 56 | state sync 的 AppHash / 提议者日程 |
| ASA-2025-002 / 59 | 分片下标与证明下标 |
| 本页 | **blocksync 目标高度不可归因、来源走了还不回退** |

## 3. 被破坏的 invariant

- 同步目标高度必须可归因到仍连着的对等节点，且来源撤回或改低时必须重算（不变量 62）
- 对等节点的 `latest` ≠ 全网尖
- 官方改口 Informational ≠ 谓词可以不写

## 4. 为什么测试没发现

幸福路径：邻居只报递增 `latest`，或断连后碰巧另有人报过更高值。  
只测「交不出块就踢人」会绿。  
不测「先高后低，然后断开」。

## 5. 修复

- v1.0.1 / v0.38.17：官方写已修。
- 绕过：ban 那一个对等节点。绕过 ≠ 目标已可归因。

升级补的是目标数字的寿命。改口降低严重度，没有把「可以无限追一个没来源的高度」写成功能。

## 6. 「不确定」若同类

1. 若提供 blocksync / 追尖：每个目标高度必须记住是谁报的。来源断开、改低、或交不出，必须重算，不得留下孤儿目标。
2. 不要把邻居的 `latest` 写成「链的高度」。
3. p2p ban 和「别连坏人」是部署句，不是谓词。
4. 不要抄咨询示例高度。不要因为后来标 Informational 就从清单删掉。
5. 这和宣布≠收到（36）是亲戚：那边是块对象，这边是**高度数字**。

## 7. 回归测试

形状（不是利用包）：同一对等节点先报更高 `latest` 再报更低；随后断开 → 目标必须重算，不得无限追已无来源的高度。文案把邻居 `latest` 写成全网尖必须红。只测递增报告不得标 PASS。
