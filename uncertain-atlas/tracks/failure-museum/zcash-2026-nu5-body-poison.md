# 失败案：体可变拒绝先于授权承诺不是头已经绑死；诚实头被永久拉黑不是块已经非法

层：**协议 + 实现**（NU5 起 v5 授权数据由头的 `hashBlockCommitments` / `hashAuthDataRoot` 承诺，不由 `hashMerkleRoot`；体推导出的拒绝若先于授权承诺检查，可把诚实头永久标非法）

官方披露：

- Zcash 规范级 ZIP：[ZIP 256](https://zips.z.cash/zip-0256)。本页只采用 ZIP 已写出的句子。无独立 CVE 号写入本条。官方点名触发路径类名，本页只记类名，不写怎么走。

**事实（官方原文能对上的句子）：**

- NU5 及以后，v5 交易的**授权数据**由头字段 `hashBlockCommitments`（经 `hashAuthDataRoot`）承诺，**不是** `hashMerkleRoot`。
- **体推导出的拒绝**若在授权承诺检查**之前**开火，可以把**诚实头**永久标成非法。
- 修法：在活动尖路径上，任何体可变检查之前先预检 `hashBlockCommitments`；侧链情形按「体可替换」处理。官方写这关掉整类，包括 `bad-blk-sigops`、`bad-cb-length`、`bad-blk-length`。
- 官方写这是实现与规范对齐，**不是**新共识规则。诚实块与诚实交易仍有效。

本页不写怎样改体、不转触发路径、不抄发布线版本进不确定常量。体可变拒绝先开火，不是头已经绑死。

## 1. 发生了什么

头上锁的是授权根，不是 Merkle 根那一把。  
有人先拿可换的身体去撞门卫。  
门卫按身体拒了，并把头的名字写进黑名单。  
身体可以换。头是诚实的。  
黑名单上的名字，以后诚实身体也进不来。  
拒了身体，不是头已经绑死、也不是这块已经非法。

## 2. 根因

头身份与体可变检查不是同一对象。  
NU5 之后，授权数据的承诺在 `hashBlockCommitments`，不在 `hashMerkleRoot`。  
若先跑会随体变的拒绝（签名操作计数、coinbase 长度、块长度……），失败会被记到头哈希上。  
体换一份，头还可以是同一份诚实承诺。永久拉黑头 = 把可变拒绝当成头已非法。

这不是：

| 案 | 对象 |
|----|------|
| 不变量 12 / CVE-2012-2459 | 同根不同列表；变异必须拒且不得永久拉黑**同哈希合法块**。本页是授权根 ≠ Merkle 根，体可变拒绝抢跑 |
| 不变量 39 / CVE-2024-52921 | 变异块清掉别人的下载状态；本页是本节点把诚实头标非法 |
| 不变量 96 | Engine API 尺寸分裂；本页是检查顺序与承诺对象 |
| 不变量 104 | 重复头复位跟踪；本页是拒绝顺序 |
| 不变量 105 | 归一化 ≠ 编码；本页是体检查 ≠ 授权承诺 |
| 本页 | **体可变拒绝先于授权承诺 ≠ 头已经绑死；诚实头被永久拉黑 ≠ 块已经非法；Merkle 根对上 ≠ 授权数据已承诺** |

## 3. 被破坏的 invariant

- 会随体变的拒绝不得先于授权承诺检查，把诚实头永久标非法（不变量 106）
- `hashMerkleRoot` 对上不是授权数据已绑定
- 侧链 / 可替换体必须按「体可换、头另验」处理，不得把体失败写成头哈希已死

## 4. 为什么测试没发现

幸福路径：体与头一起到，先验承诺再验体，失败只丢这一份体。  
绿测试只覆盖「坏体、坏头」或「好体、好头」。  
边角要：诚实头 + 可替换坏体；拒绝是否写到头的永久非法表；活动尖与侧链是否同一条路径。

## 5. 修复

官方：活动尖上，体可变检查之前先预检 `hashBlockCommitments`；侧链按体可替换。  
分两次发布才结构关掉整类。预检不是 Merkle 根已经够。

## 6. 「不确定」若同类

1. 第一版可以不做第二承诺根 / 授权数据与交易列表分承诺。
2. 若头承诺两个根：每个根对应的检查必须先于会污染该头身份的拒绝。
3. 永久非法表必须点名绑的是头还是这一份体。体失败不得写头哈希。
4. 这和同根不同列表（12）、变异清别人下载（39）、Engine API 尺寸（96）、跟踪复位（104）、归一化（105）不是同一句。
5. 不要写怎样改体。不要抄版本 / 触发路径细节。

## 7. 回归测试

形状（不是利用包）：文案把体可变拒绝先于授权承诺写成头已经绑死必须红。把诚实头写进永久非法表写成块已经非法必须红。把 Merkle 根对上写成授权数据已承诺必须红。把本条与 2012-2459 / 52921 糊成「变异块」一句必须红。

**事实来源：** [ZIP 256](https://zips.z.cash/zip-0256)。
