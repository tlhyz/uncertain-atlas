# 失败案：x/crisis 停链交易不是链已经停

层：**协议 + 实现 + 部署**（交易内 panic 可被恢复；EndBlock 里的同类检查才会停节点）

官方披露：Cosmos SDK [GHSA-qfc5-6r3j-jj22](https://github.com/cosmos/cosmos-sdk/security/advisories/GHSA-qfc5-6r3j-jj22)，标题原文 *x/crisis does NOT cause chain halt*。咨询标 **Low**。受影响：`x/crisis` **所有版本**、Cosmos SDK **所有版本**。官方：**不会发布补丁**。本页不另编 CVE——咨询写 No known CVE。

**事实（官方原文能对上的句子）：**

- `x/crisis` 本应让任何人在不变量失败时发 `MsgVerifyInvariant` **停链**。处理该消息本应让节点 **panic**。
- 因为 panic 发生在**交易内**，被 SDK **内置 panic 恢复**接住，只变成普通「无效交易」（非零 ABCI Code）。节点**继续出块**。
- 不变量失败可以用这条交易**确认**，但**不会**让任何节点停。
- 用 `start --inv-check-period X` 启动的节点，在 **EndBlock** 跑周期检查时**会** panic 并崩溃。这条 panic **不在**交易恢复范围内。咨询写：生产上大概很少开，因为检查很慢，且每 X 块跑**全部**不变量。
- 官方决定不修停链语义。模块原意是「安全优先于活性」；链成熟后停机代价变高，该停哪些不变量要自己选。需要真停时，验证者应**链下协调**——咨询写这已是安全补丁的既有做法。模块将在新模块接手后弃用。

本页不写怎样让不变量失败，不抄 `X` 或检查耗时，不把「不修」写成「不确定可以没有停机谓词」。

## 1. 发生了什么

说明书上写：账本坏了，任何人发一封「停」的信，全网关机。  
信发出去了。节点喊了一声，被交易笼子接住，当成「这笔无效」。  
块还在出。  
只有那些自己打开「每隔一阵在结尾检查全部不变量」开关的节点，才会在 EndBlock 真的倒下。那是另一条路，不是这封信。

## 2. 根因

停机谓词必须写清**在哪一层爆炸**：交易里，还是高度提交路径上。  
交易有恢复。EndBlock 没有同一只笼子。  
「模块名叫 crisis、消息名叫 VerifyInvariant」不是已经停链。

这不是：

| 案 | 对象 |
|----|------|
| 不变量 71 / ISA-2025-002 | 可选模块 EndBlocker **出错会停链** |
| 不变量 58 / ASA-2024-001 | 治理改启用高度，验证写错则 panic |
| 不变量 5 | 崩溃后高度必须原子 |
| 本页 | **停链交易 ≠ 已停链；交易内 panic 可恢复，EndBlock 检查才会停节点** |

## 3. 被破坏的 invariant

- 「发停链交易」不是链已经停（不变量 73）
- 交易内 panic 可被恢复，不得写成全网关机
- EndBlock 周期检查停的是开了该开关的节点，不是 `MsgVerifyInvariant` 的语义已兑现

## 4. 为什么测试没发现

幸福路径：不变量没坏，crisis 交易很少发。  
只测「消息能进块、Code ≠ 0」会绿，看不见「说明书保证的停机没有发生」。  
模块名被当成规范保证。

## 5. 修复

官方：**不发补丁**。需要真停则链下协调。模块将弃用。  
关掉 `x/crisis` ≠ 已经有「不变量失败则停」的产品句。自己写停机谓词时，必须点名在交易外、恢复笼外。

## 6. 「不确定」若同类

1. 第一版可以不装「任何人发消息就停链」的模块。
2. 若要安全优先于活性：停机必须发生在交易恢复笼**外**（例如 EndBlock / 共识之外的操作员程序），并写清谁有权触发。
3. 不要把 `MsgVerifyInvariant` 或同类交易写成已经停机。不要抄 `--inv-check-period`。
4. 这和可选模块 EndBlocker 出错会停（71）是**对照句**：同一条提交路径，出错可以停；交易内 panic 可以不停。
5. 咨询 Low 不是「可以假装有停机按钮」。文案写了停、实现吞了，是假保证。

## 7. 回归测试

形状（不是利用包）：文案把 `MsgVerifyInvariant` 写成链已停必须红。交易内 panic 被恢复、节点继续出块仍标「停机模块已安全」必须红。只测 EndBlock 周期检查不得标「crisis 消息已兑现」。
