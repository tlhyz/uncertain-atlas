# 失败案：DKG 按设计关掉不是重启后还记得；失败裁决未落盘不是随机性已经关闭

层：**协议 + 实现 + 部署**（纪元初 DKG 参与不够则本纪元关掉随机性；裁决不写盘，重启后当没失败过；随机性队列排不空，纪元关不了）

官方披露：

- Sui 官方复盘：[Sui Mainnet Halts Resolved After Major Upgrade](https://www.sui.io/blog/sui-mainnet-halts-resolved-after-major-upgrade)（2026-05-29 第三次停机）。无 CVE。本页只采用该页已写出的句子。同页第一、二次停机（取消后仍砸气费）另立。

**事实（官方原文能对上的句子）：**

- 周五下午预定换纪元失败，**第三次停机**。条件由上一轮重启（为打上第二次气费补丁）布置好。
- 每个纪元开始，验证者跑 **DKG**，给依赖链上随机数的交易引导随机信标。DKG 的参与门槛**高于普通共识**；参与不够，则**本纪元其余时间关掉随机性**——官方写这是按设计。
- 验证者为打 Part 2 补丁重启时，下一纪元 DKG 参与不够，按设计关掉。潜在漏洞：这次**失败裁决从未写盘**。后续再重启，每台验证者上来都**不知道 DKG 已经失败**。
- DKG 还在跑时，依赖随机性的交易期望**要么执行、要么取消**。验证者不再记得失败，两件事都做不成，暂停队列变长。**纪元结束逻辑必须先排空该队列才能关纪元**，于是空等一个永远不会来的 DKG。
- 修法两段：把 DKG 状态**持久化**，跨重启仍在；加一个让验证者在协调点**强制关掉卡住纪元**的机制。后者这次用了一次，网络进入新纪元，随机性恢复。
- 官方：已有部分换纪元「安全模式」，这次说明覆盖面可能太窄。要把优雅降级扩到整条重配置路径，并把强制关闭做成常备运维能力。

本页不写怎样让 DKG 参与不够，不抄钟点进不确定常量。按设计关掉，不是重启后还记得。

## 1. 发生了什么

换班要先抽一副新随机牌。  
到的人不够，屋子按规定这班不打牌。  
这张「不打了」的条子没写进抽屉。  
为修气费，人进出几次。  
每次进门都当还能打牌。  
等随机数的单子越排越长。  
下班铃响了，队列不空，门关不上。  
DKG 按设计关掉，不是重启后还记得。

## 2. 根因

「参与不够 → 本纪元关掉随机性」是协议句。  
「关掉」必须是崩溃后仍能读到的对象。只在内存里，重启就当没关过。  
依赖随机性的交易只有执行或取消两条路。两条都走不成，队列只增。  
纪元结束若必须排空该队列，队列排不空就是停。  
为打另一个补丁而重启，是布置条件，不是气费洞本身。

这不是：

| 案 | 对象 |
|----|------|
| 不变量 92 / 同周第一、二次 | 取消后仍砸气费；本页是 DKG 裁决 |
| 不变量 5 | 崩溃原子高度；本页是随机性开关未持久 |
| 不变量 80 | 升级下载管家；本页不是换二进制通道 |
| 不变量 91 / 2026-01-14 | 检查点隔离拒证 |
| L1.6 | 一般确定性；本页是随机信标开关 |
| 本页 | **DKG 按设计关掉 ≠ 重启后还记得；失败裁决未落盘 ≠ 随机性已关；等一个永远不会来的 DKG ≠ 安全模式已覆盖换纪元；强制关纪元用了一次 ≠ 常备能力已有** |

## 3. 被破坏的 invariant

- DKG / 随机性开关的失败裁决必须落盘，重启后仍有效（不变量 93）
- 按设计关掉不是已经关掉——若下一进程读不到
- 依赖随机性的交易必须仍能取消；两条路都走不成，纪元结束会停
- 换纪元安全模式不是整条重配置路径已降级

## 4. 为什么测试没发现

幸福路径：DKG 一次成功，或失败后进程不重启。  
只测「参与不够则关掉随机性」会绿——内存里是关的。  
边角要：失败 + 重启 + 队列里已有依赖随机性的交易 + 纪元结束要排空。  
气费补丁的重启把边角摆上台，单测气费看不见。

## 5. 修复

官方：持久化 DKG 状态；加协调点强制关纪元（这次用了一次）。随机性在新纪元恢复。没有回滚已提交交易。  
强制关一次不是已经有常备能力。安全模式覆盖面官方自己写可能太窄。

## 6. 「不确定」若同类

1. 第一版可以不提供链上随机信标 / DKG。结算不必等随机数。
2. 若提供：开关与失败裁决必须落盘，崩溃恢复后仍有效。内存里的「已关」不是已关。
3. 依赖该开关的交易在「已关 / 未知」时必须能取消，不得只挂起。
4. 纪元结束不得无界等待一条可能永远不来的队列。排不空必须有规范写明的强制关闭。
5. 为打另一个补丁而重启，必须重放「开关是否还在」的测试。不要抄门槛数字。不要写怎样让 DKG 凑不齐。
6. 这和取消后仍砸气费（92）、崩溃原子高度（5）、检查点隔离（91）不是同一句。

## 7. 回归测试

形状（不是利用包）：文案把「DKG 按设计关掉」写成重启后仍关必须红。把失败裁决只在内存写成已持久必须红。把纪元结束写成总会排空随机性队列必须红。把一次强制关闭写成常备能力必须红。与同周气费停机糊成一句必须红。
