# 失败案：ASA-2024-003 未初始化的被挡账户不是可归属的地址

层：**协议 + 实现 + 部署**（模块账户必须先存在；不是 EndBlocker 提案出错，也不是奖励池溢出）

官方披露：Cosmos SDK [ASA-2024-003 / GHSA-4j93-fm92-rp4m](https://github.com/cosmos/cosmos-sdk/security/advisories/GHSA-4j93-fm92-rp4m)。咨询正文标 **Low**，GitHub 徽章标 **Moderate**，影响写成 Denial of Service。受影响：`<= 0.50.3`、`<= 0.47.8`。补丁：`0.50.4`、`0.47.9`。本页不另编 CVE——咨询未给 CVE ID。

**事实（官方原文能对上的句子）：**

- `x/auth/vesting` 允许用户在**被挡住的地址**上创建**定期归属账户**，例如一个**尚未初始化的模块账户**。
- 修法：增加校验，阻止在这种场景创建定期归属账户。
- 若该未初始化账户后来被某个模块的 `Begin`/`EndBlock` 里的 `GetModuleAccount` 叫到，**有可能停链**。
- 咨询写：未初始化的被挡模块账户这种组合**并不常见**。
- 部署建议：若链上已有未初始化的被挡模块账户，应**主动初始化**；它们常常在迁链或 `init genesis` 时被初始化。
- 附录：`x/authz` 与 `x/feegrant` 有**变体触发**。缓解与父咨询相同——尚未初始化的模块账户要主动初始化。

本页不写怎样往被挡地址上建归属账户，不把「并不常见」写成「不确定可以不初始化」，不抄版本号。

## 1. 发生了什么

系统账户（模块账户）本该在创世就有户口。  
有人把一份「以后才解锁」的归属账户建在一个**还没开户、又被挡住**的地址上。  
平时没事。某天 Begin/EndBlock 去叫这个模块账户，户口对不上，高度停。  
authz / feegrant 后来被发现能走同一扇门。

## 2. 根因

被挡住的地址回答的是「用户不许往这里转普通钱」。  
模块账户回答的是「这个名字必须已经在状态里」。  
两句没钉死时，归属/授权/手续费代付可以把一颗定时炸弹种在空户口上。炸弹在 Begin/EndBlock 响，不在那笔创建交易里。

这不是：

| 案 | 对象 |
|----|------|
| 不变量 71 / ISA-2025-002 | 可选模块 EndBlocker 出错会停链 |
| 不变量 73 / x/crisis | 停链交易不是已经停 |
| 不变量 74 / ISA-2025-005 | 奖励池入金溢出可以停链 |
| 不变量 81 / Elderflower | 授权代发漏掉 ValidateBasic ≠ 内层已认证 |
| 本页 | **未初始化的被挡模块账户不是可归属的地址；GetModuleAccount 叫到空户口可以停链** |

## 3. 被破坏的 invariant

- 被挡住的模块账户必须先初始化，才能被 vesting / authz / feegrant 碰到（不变量 75）
- 未初始化账户在 Begin/EndBlock 被 `GetModuleAccount` 叫到可以停链
- 「并不常见」不是创世可以不初始化

## 4. 为什么测试没发现

幸福路径：模块账户在 genesis 都建好了，没人往它们上面挂归属。  
只测「定期归属能建在普通地址」会绿，看不见「空模块户口 + 结尾钩子」。  
被挡地址被当成「已经安全」。

## 5. 修复

官方：加校验，禁止在该场景创建定期归属账户；已有空户口的链主动初始化。  
升级 vesting 校验 ≠ authz / feegrant 变体已经审过。附录要求同样主动初始化。

## 6. 「不确定」若同类

1. 第一版：所有模块账户在创世初始化。没有「以后再用到再开户」。
2. 若有被挡地址 / 归属 / 授权 / 代付：创建路径必须拒「往未初始化的被挡地址上挂对象」。
3. 这和可选模块 EndBlocker（71）、停链交易（73）、奖励池溢出（74）不是同一句。
4. 不要把「并不常见」写成产品已安全。迁链后必须再扫一遍模块账户表。
5. 不要抄 `x/auth/vesting`。

## 7. 回归测试

形状（不是利用包）：文案把被挡地址写成已经不能挂归属必须红。未初始化模块账户被 Begin/EndBlock 的 `GetModuleAccount` 叫到、高度停仍标 PASS 必须红。只测普通地址归属不得标「模块账户已安全」。authz / feegrant 未扫不得标「变体已修」。
