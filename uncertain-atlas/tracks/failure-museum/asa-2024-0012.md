# 失败案：ASA-2024-0012 / 0013 外层交易上限不是内层解码已有界

层：**实现 + 协议**（进门字节上限管的是外层序列化交易；不是嵌套展开已经有界）

官方披露：Cosmos SDK [ASA-2024-0012 / ASA-2024-0013 · GHSA-8wcc-m6j2-qxvm](https://github.com/cosmos/cosmos-sdk/security/advisories/GHSA-8wcc-m6j2-qxvm)。咨询把两条写在同一页，都标 **High**。受影响：`<= v0.50.10`、`<= v0.47.14`。补丁：`v0.50.11`、`v0.47.15`。本页不另编 CVE——咨询未给 CVE ID。

**事实（官方原文能对上的句子）：**

- **0012：** 解码一份**恶意构造、深层嵌套**的包时，可能**栈溢出**，导致**网络停摆**。修法：解码时加**递归上限**。
- **0013：** 交易里的**嵌套消息**在 `UnpackAny` 上可消耗**指数级** CPU 与内存。`max_tx_bytes` 给**外层交易**设限，**不**应用于 wasm 合约放出的内部消息，也**不**应用于恶意验证者块放出的内部消息。节点可能因资源耗尽崩溃。修法：增加额外校验，阻止该条件。

本页不写怎样嵌套、不写递归深度数字、不写 `UnpackAny` 的内部循环、不抄版本号当不确定常量。两条不是同一句实现细节，但共用一句产品句：外层够短 ≠ 内层已有界。

## 1. 发生了什么

门上写着：进来的交易不能超过 `max_tx_bytes`。  
门卫量的是**整包外皮**。  
包里还有盒子套盒子。每打开一层（官方点名 `UnpackAny`），工作量可以涨一截。  
外皮没超标。盒子太深：栈先炸（0012），或 CPU/内存被指数吃掉（0013）。  
更糟：有些消息根本不走这扇门——合约内部放出的、或不诚实验证者直接放进块里的。外层上限管不到它们。

## 2. 根因

字节上限回答的是「这串进来的字节有多长」。  
解码递归与嵌套展开回答的是「打开之后要做多少工作」。  
两句不是同一把尺。内部消息另有入口，不会自动继承外层上限。

这不是：

| 案 | 对象 |
|----|------|
| 不变量 33 / Req 2 | Prepare 返回总字节不得超过本次 `max_tx_bytes`（外层提案） |
| 不变量 48 / CVE-2015-3641 | 最大序列化长度不是读载荷前的接收分配 |
| 不变量 51 / CVE-2025-46597 | 尺寸检查必须用固定宽度整数 |
| 不变量 60 / ASA-2025-003 | 带内部长度的结构必须先验再流言 |
| 不变量 63 / ASA-2023-002 | 默认块 MaxBytes 不是第一轮活性 SLA |
| 本页 | **外层交易上限 ≠ 内层解码 / 内部消息已有界** |

## 3. 被破坏的 invariant

- 外层交易字节上限不是内层消息已有界（不变量 70）
- 解码递归必须有上限
- wasm / 恶意验证者块放出的内部消息必须另写界，不得假装已被 `max_tx_bytes` 管住

## 4. 为什么测试没发现

幸福路径：扁平交易、几乎不嵌套，外层上限碰巧也挡住了展开。  
只测「外层 ≤ max_tx_bytes」会绿，看不见深嵌套栈溢出，也看不见内部消息绕过外层门。  
`max_tx_bytes` 被当成「解析器已经有配额」。

## 5. 修复

官方：解码加递归上限；对会指数展开的嵌套加额外校验。升级到补丁版本。  
换掉外层上限数字 ≠ 内部消息已经有界。自己写 Any / 内部消息路径仍要重审。

## 6. 「不确定」若同类

1. 若消息可嵌套（Any / 内部消息 / 合约放出的消息）：必须**两把尺**——外层序列化上限，加解码递归 / 展开代价上限。
2. 内部消息与不诚实提议者直接放进块的消息，必须另写界。不要写「我们有 max_tx_bytes」。
3. 这和四门 Req 2（33）、接收分配（48）、固定宽度（51）、位图先验（60）、默认 MaxBytes SLA（63）不是同一句。
4. 后量子对象更肥、包装层更多时，更不能把外层字节当成展开配额。
5. 不要抄咨询里的递归深度——咨询没给数字。自己写深度，并测「外层刚过、内层很深」。

## 7. 回归测试

形状（不是利用包）：文案把 `max_tx_bytes` 写成嵌套 `UnpackAny` 已有界必须红。深嵌套解码无递归上限仍标 PASS 必须红。内部消息或恶意验证者块放出的消息不受外层上限仍标 PASS 必须红。只测扁平短交易不得标「解码已安全」。
