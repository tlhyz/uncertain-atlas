# 失败案：StateDB 的可花余额不是归属锁定已经从同一笔写回里排除；回绕后的数不是银行账已经对齐

层：**协议 + 实现 + 经济**（EVM `StateDB` 只看见可花余额；SDK 归属账户还有锁定；质押 / 质押预编译允许把锁定一起委托；写回按全部委托额去减较小的可花数，无符号下溢回绕；回绕后的余额被当成合法可转）

官方披露：

- Cosmos Labs 官方复盘：[Cosmos EVM GHSA-7g4w-cg88-2cq2 Post-Mortem](https://github.com/cosmos/security/blob/main/communications/cosmos_evm_GHSA-7g4w-cg88-2cq2_post_mortem.md)（2026-08-28）。
- 咨询：[GHSA-7g4w-cg88-2cq2](https://github.com/cosmos/evm/security/advisories/GHSA-7g4w-cg88-2cq2)（Critical）。无 CVE。官方写生产链被利用。

**事实（官方原文能对上的句子）：**

- Cosmos EVM 用 `StateDB` 与 SDK `x/bank` 对账。`StateDB` **只**跟踪可花余额。归属账户在 SDK 里同时有可花与锁定。`x/staking` 与质押预编译允许把锁定一起委托。
- 委托额大于可花时，写回的 `SubBalance` 按**全部委托额**去减较小的可花数。减法未检查下溢，余额回绕。
- 官方：回绕后的余额当时被视为合法，可再转给他人；与另一条溢出路径合在同一笔里，能从归属账户抽走近真实代币，而总供给净变化为 0。本页不写那条组合怎么拼。
- 两条发行线行为不同：一条经 SDK 账本铸/销，大额铸造会供给溢出而停链；另一条直接改 `x/bank`，只要过得了有符号转换就收下。
- 赏金报告先被判「当时支持版本、已知生产小数配置下不会丢资金」，按无资金风险的静默公开补丁走；补丁进了主分支，**没有**立刻回移到发布线，因为改状态、要协调升级。后来独立报告才确认**所有** Cosmos EVM 链、不论小数配置都中。官方：代码经过内外审计，本洞审计没发现。
- 无配置-only 缓解。不能立刻升级则停链。关掉质押预编译去掉主触发路径，**不是**补丁替代。

本页不写怎样委托锁定、怎样拼同一笔、怎样对准地址。不抄金额 / 链名 / 版本 / 位宽数字进不确定常量。可花视图，不是锁定已经从写回里排除。

## 1. 发生了什么

EVM 本子上只写「现在能花多少」。  
SDK 本子上还锁着一笔。  
质押门口允许把锁着的也押出去。  
回来销账时，按全部押额去减那本只看见可花的账。  
数不够减，回绕成一个看起来极大的合法数。  
极大的数，不是银行已经多印了，也不是银行已经对上。  
审计过、主分支有补丁，不是发布线已经打上。

## 2. 根因

两本账不是同一对象。可花 ≠ 可花 + 锁定。  
允许锁定去质押的模块，写回必须用同一本账的同一字段，或拒绝「委托额 > 可花视图」。  
未检查的无符号减，不是金额已经守恒。  
回绕后的余额能过「存在且合法」，不是供给已经对齐。  
「在我们测过的生产配置上复现不了偷币」，不是生产资金已经无险。静默补丁进主分支，不是用户已经升到发布线。

这不是：

| 案 | 对象 |
|----|------|
| 不变量 7 | 输出求和拒回绕；本页是 EVM 可花视图减锁定委托 |
| 不变量 74 | 奖励池溢出入金停链；本页是写回下溢再当合法余额 |
| 不变量 76 | Int/Dec 位宽；本页是两模块对同一账户两套余额 |
| 不变量 83 / Barberry | 空地址不是还没有归属类型；本页是类型已在、两本账 |
| 不变量 75 | 未初始化被挡账户；本页是已有归属账户的对账 |
| 本页 | **StateDB 可花 ≠ 锁定已经从同一笔写回排除；回绕后的数 ≠ 银行账已经对齐** |

## 3. 被破坏的 invariant

- 若执行引擎只看见可花，写回不得按「可花 + 锁定」的委托额去减这本更窄的账（不变量 115）
- 回绕后的余额不得当合法可转；两本账对不上必须拒
- 主分支静默补丁不是发布线已经打上，也不是「测过的配置」已经覆盖全部生产

## 4. 为什么测试没发现

幸福路径：普通账户无锁定，委托额不超过可花，两本账碰巧一样。  
绿审计与赏金复现当时只覆盖部分发行线 / 部分小数配置。  
边角要：归属账户委托大于可花视图；写回是否下溢；回绕后的数能否再转；两条发行线铸销 vs 直接改银行是否同一拒绝。

## 5. 修复

官方：`SubBalance` 写回加下溢守卫。改状态，必须协调升级。  
不能立刻升级则停链。关质押预编译不是补丁。  
过程：扩大「报告范围可能大于第一份 PoC」的分诊，不再只因复现失败就当生产无险。那是过程，不是谓词已齐。

## 6. 「不确定」若同类

1. 第一版可以不做通用 EVM、质押预编译、定期归属、双账本对账。
2. 若一层引擎只看见可花、另一层允许锁定去质押：写回必须用同一对象，委托额大于视图必须拒。
3. 回绕必须当非法。供给净零不是两本账已经对齐。
4. 「在我们的生产配置上复现不了」不得单独充当已无资金风险。主分支补丁不是用户已经升级。
5. 这和求和拒回绕（7）、奖励池溢出（74）、空地址归属（83）、被挡账户（75）不是同一句。
6. 不要写怎样委托锁定或怎样拼同一笔。不要抄金额 / 链名 / 版本 / 位宽。

## 7. 回归测试

形状（不是利用包）：文案把 StateDB 可花写成锁定已经从同一笔写回排除必须红。把回绕后的数写成银行账已经对齐必须红。把主分支静默补丁写成发布线已经打上 / 生产已经安全必须红。把「测过的小数配置复现不了」写成资金已经无险必须红。与 7 / 74 / 83 糊成「余额回绕」一句必须红。
