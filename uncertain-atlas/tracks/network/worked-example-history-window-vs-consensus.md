## 1. 核心问题

阿比看见新版线协议握手里带了最早块和最晚块，以为共识已经允许删历史；或看见收据线上不再带布隆，以为共识收据编码已经改了；或看见握手不再报总难度，以为已经能靠这个判断对等节点同步完没完；或看见规范编号 7642，以为必须硬分叉，或已经是 blob 服务窗，或已经是 assumevalid，或已经是状态里的历史哈希。

官方句（事实）：

- EIP-7642：改 `eth` 点对点协议。让节点宣布自己还服务哪一段历史块。同时简化握手，去掉合并之后不再使用的总难度。另外建议线上收据不再带布隆字段。
- 历史过期工作组的决定是：客户端**可以**在某个约定之后丢掉合并前历史。本页是让还想靠 `eth` 协议拉历史的人，先知道对等节点还服不服老历史。看见本页，不是共识已经删历史。
- 各家客户端本地本来就不存收据布隆，因为可以现算。旧线协议却要求网上必须带上。同步的人会把这份现算出来的布隆再传一遍、再验一遍、再丢掉。
- 新通知用来让对等节点知道对方手里还有哪一段。可以用来看同步进度，并据此改拉取。
- 新握手不再带总难度，改带创世、分叉识别，以及最早块、最晚块、最晚块哈希。
- 新收据线上是扁平字段列表：类型、状态或根、累积气、日志。不再带布隆。
- 合并之后，握手里的总难度没有意义：合并后的块难度是 0。理论上曾被用来区分同步完没完，但分叉识别也能做这件事。
- 最早块字段对历史过期**不是技术上必须**。它方便找还愿意给历史的对等节点，方便普查有多少人开着历史，也为以后窗口变成动态做准备。没有这个字段，只能先发一请求、失败再猜「大概没有」。
- 收收据的一方必须自己重算布隆，才能完整核对收据哈希。重算不很吃 CPU。线协议从此**偏离**共识用的收据编码；共识里旧式收据和类型收据的包法本来就不一样，网上没必要再复刻那套贵编码。
- 本页**不改** EVM 共识规则，**不要求**硬分叉。旧客户端可以继续走旧版线协议。
- 规范**没有**把宣布历史窗写成共识已经删历史，也没有把线上不带布隆写成共识收据已经改，也没有把去掉总难度写成已经能判断同步完没完，也没有把换线协议版本写成已经硬分叉，也没有把本页写成不变量 23、25 或 195。

对等节点还服哪一段、共识还认哪一段、线上收据长什么样，是三件事。

## 2. 直觉（ELI15）

图书馆在门口挂牌：本馆只外借某一年之后的书。  
这不是法律已经改成「更早的书不算书」。  
借条上少印一栏印章，不是馆藏目录的格式已经改了。  
换了借书证版本，不是整座城重新立法。

## 4. 最小案例

一条 Ethereum 要对齐「这一口气历史还在哪一层」。

1. 看见握手带了最早块。规范：这个对等节点宣布自己还服务哪一段。不是共识已经删历史。
2. 看见收据线上没有布隆。规范：网上不再传可现算字段。收的人要自己重算才能核收据哈希。不是共识收据已经改。
3. 看见握手没有总难度。规范：合并后该字段没意义。不是已经能判断同步完没完。
4. 看见换了线协议版本。规范：旧客户端仍可走旧版。不是已经硬分叉。
5. 有人把这听成不变量 23。那是 blob 短时服务窗。本页是 `eth` 线协议宣布的块范围。
6. 有人把这听成不变量 25。那是 IBD 跳哪条规则。本页是对等节点还服不服老历史。
7. 有人把这听成不变量 195。那是状态里的历史执行哈希。本页是网上宣布的服务范围。

「看见历史窗 = 共识已删 / 线上无布隆 = 共识收据已改 / 去掉 TD = 已判断同步 / 7642 = 硬分叉 / 7642 = 23」是假学习。

## 5. 五层

| 层 | 本页 |
|---|---|
| 密码学 | 收据哈希仍要核；布隆可现算不是已经核过 |
| 协议 | 必须点名问的是线协议服务窗、共识历史，还是收据编码 |
| 实现 | 多版本线协议可以并存；宣布的窗必须和真正能给的段对齐 |
| 部署 | 不把工作组约定日期抄进不确定；不把「可以丢」写成已经丢 |
| 经济 | 不把省带宽写成已经更安全 |

**推断：** 产品句若只写「历史可以过期了」，读者会把对等节点挂牌听成共识已经删书，或把线上收据听成账本收据已经改。  
**建议：** 第一版必须写清全节点默认可从创世拉到哪。若允许剪历史，必须分开「这个对等节点还服哪一段」和「共识还认哪一段」。可以跳过「看见 7642 就已经改了共识历史」。207 history-window vs consensus bundled unbundling 完成（1488 item 1 / 1489 item 2 / 1490 item 3）；精读 [`worked-example-hwin-notcons-vs-bundled.md`](worked-example-hwin-notcons-vs-bundled.md)（不变量 1488 item 1）、[`worked-example-hwin-notenc-vs-bundled.md`](worked-example-hwin-notenc-vs-bundled.md)（不变量 1489 item 2）、[`worked-example-hwin-notsync-vs-bundled.md`](worked-example-hwin-notsync-vs-bundled.md)（不变量 1490 item 3）。不要发明「看见 7642 就已经改了共识历史」。不要抄截止日期 / 带宽估算。不要把 7642 写成硬分叉。

## 6. 和另外几句不是同一句

1. **短时承诺 ≠ 永存 DA**（不变量 23）：blob 服务窗。本页是 `eth` 线协议块范围。
2. **跳过须点名**（不变量 25）：IBD 跳脚本或 UTXO 重放。本页是对等节点还服不服老历史。
3. **历史执行哈希 ≠ BLOCKHASH**（不变量 195）：状态里的哈希窗。本页是网上宣布的服务范围。
4. **类型信封 ≠ 已经解开内层**（不变量 167）：交易编码。本页是收据线上编码偏离共识编码。

不要抄服务截止日期、带宽估算、每纪元块数、消息号、布隆宽度。不要写怎样丢历史，或怎样谎报最早块。不编博物馆页。不另写 19 节。不转无效调用样本。blob 服务窗、assumevalid、状态历史哈希、硬分叉是另一对象。短时 DA 精读：[`../light-clients/worked-example-blob-vs-das.md`](../light-clients/worked-example-blob-vs-das.md)（不变量 23）。
