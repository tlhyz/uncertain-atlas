# 实例：阿比的六个邻居都是同一个人

目的 A。不是考试。  
先修：L9.1、L3.4、L3.5。轻节点精读。

---

## 故事

阿安付 1。阿比的钱包连着「全网」。其实出边只有六个对等点，六个都由对手开。  
对手给他看一条自己的最重链（或自己的 BFT 视图），上面阿安的 1 已经到了。真网络上这笔还在别人的池里，或在另一条历史上。

阿比放货。签名公式没废。  
**层：部署 / 网络。** 协议的「诚实节点最终能收到」前提被日蚀拿走了。

分区是亲戚：帘子两边各自诚实，各自有一份「到了」。日蚀是：阿比以为自己在全班，其实在对手的小房间。  
调整钟是第三种：图还在，钟歪了，真块被拒，见 [`worked-example-adjusted-time.md`](worked-example-adjusted-time.md)。

---

## 五层

| 层 | 本故事 |
|---|---|
| 密码 | 路径/签名可以对对手给的那条链为真 |
| 协议 | 最重链 / QC 在**阿比看见的图**上仍可自洽 |
| 实现 | 对等点选择、驱逐、锚点 |
| 部署 | 引导节点、NAT、出边数、只连排序者 |
| 经济 | 日蚀一台收款人的成本 ≪ 攻全网算力/质押 |

## 「不确定」测试句（建议）

```text
默认结算角色 = 全节点 + 多样化出边
出边集合可被单实体填满 ⇒ 不得显示「最终」
产品句必须能区分：分区停机 vs 日蚀假确认
```
