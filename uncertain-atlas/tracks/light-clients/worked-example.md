# 实例：阿比只看了「头」就放货

目的 A。不是考试。数字是结构。  
先修：L3.5、L7.2、L8.3、L9.6。反模式 header-equals-settlement、rpc-as-verification。

---

## 故事

阿安付 1。阿比的手机显示绿勾，货出门。  
绿勾来自四种不同的「我少下了数据」——假设不同，能翻的方式不同。

| 阿比实际做了什么 | 他少下了 | 他多信了 | 货还能怎么没了 |
|---|---|---|---|
| 全节点复算 | 不 | 实现+自己连的网 | 实现错、被日蚀、自己跟错策略 |
| SPV：头 + Merkle 路径 | 块体与脚本复算 | 多数工作量、路径对着**那条**最重头 | 日蚀喂一条假最重链；路径对、脚本其实无效 |
| 状态证明：根 + 账户路径 | 全状态 | **根的来源** | RPC 给一条非 canonical 根；路径对根、根不对历史 |
| DAS：抽到几格 | 全体 | 编码、抽样参数、诚实抽样 | 抽到了仍可能没执行对；数据被扣则无法复算 |
| 递归小证明 | 历史重放 | 电路 + 证明系统 | 电路通胀；证明小 ≠ 自己的那一页还在（L8.3） |
| 只信 RPC / 浏览器 | 一切 | 服务商 | 服务商说「到了」 |
| BFT 轻跳过（CometBFT） | 中间头 | 信任期 + 旧 `NextValidators` 重叠 | 只数新委员会自己的 2/3 |
| Altair 同步委员会 | 全验证者集合与执行层 | 512 抽样的超多数 + 独立域 | 把抽样 2/3 写成 Casper 最终 |
| 4844 blob / PeerDAS | 袋里的字节与 L2 执行 | versioned hash 或抽到的列 | 把 KZG 写成 DAS，或过窗仍说可重建 |

**层：** 用户看见的绿勾常常是**部署**（连谁）加上**协议假设没写进产品句**。密码学路径可以对，货仍能没。

---

## 五层（同一笔 1）

| 层 | 本故事 |
|---|---|
| 密码 | Merkle / 证明可以仍对 |
| 协议 | SPV 从未声称「验证了脚本」；DAS 从未声称「执行正确」 |
| 实现 | 路径算错、抽样实现偏置 |
| 部署 | 日蚀、RPC、只连排序者 |
| 经济 | 攻击一条 SPV 视图的成本 ≠ 攻击全网 |

## 「不确定」测试句（建议）

```text
默认结算角色 = 全节点复算
若角色 = SPV | 状态证明 | DAS | 递归证明 | BFT 跳过 | 同步委员会抽样
    ⇒ 产品句必须点名多信的对象（全集重叠 ≠ 固定抽样）
无体或不满足抽样 ⇒ 不得显示「最终」
根来自 RPC ⇒ 不得显示「已验证」
```

后量子头和路径都会变贵，会有人更积极推销「只下头」。句子必须先写死。
