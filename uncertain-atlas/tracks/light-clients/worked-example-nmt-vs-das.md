## 1. 核心问题

阿比看见「Celestia 有 NMT，又有 DAS」，以为验过自己这条命名空间，整块就已经可用；或者抽了几格，就已经拿到自己的 blob，编码也已经诚实，历史也已经有人存。

官方句（事实）：

- 同一页把 DAS 和 NMT 写成**两个**关键零件。DAS：轻节点不用下完块，也能查「这份数据此刻发出来了没有」。NMT：执行 / 结算层只下自己关心的命名空间。
- NMT 必须能证两件事：给的份额在块里；**这一命名空间的全部份额都给了**。内部节点带子孙的命名空间区间。只给中间几片、却把区间里还含该命名空间的兄弟节点当齐，应用能看出来缺。
- DAS：轻节点在扩展方阵上随机要坐标和对应 Merkle 证明。每次都答得上，才有「整块大概率可用」。够多轻节点一起抽，诚实桥节点才能从收集到的份额重建。
- 扩展编错时：即使抽到了够多不重复份额，**原数据仍可能拼不回来**。要靠「错误扩展」的欺诈证明。日蚀可以打断「至少连着一个诚实桥节点」这条假设。
- `celestia-app` 对 blob **既不验证也不存储**。状态机跑的是 PoS / 治理，不是租户字节。
- FAQ：新块 DA ≠ 历史检索。历史只要 1-of-N 诚实保管者。官方写：保证永存不是 DA 层的职责，Celestia 不为此发激励。

NMT 齐了，问的是「我这条命名空间有没有被扣了一截」。DAS 问的是「扩展方阵此刻能不能被网络重建」。两问可以一个绿、一个红。

## 2. 直觉（ELI15）

走廊里有一本拆开的练习册，按班级贴了标签。

- NMT：你只要三年二班那几页。对方必须证明「二班的都在这儿，没有藏在别的夹层」。这不证明一年级、四年级的页还在架上。
- DAS：你随机抽几个格子。抽到了，只说明整本大概率还在楼里。你口袋里仍没有二班的作文。
- 编码欺诈证明：有人把格子印错了。你抽到的格子对得上假目录，整本仍拼不回真作业。要有人拿着一整行去揭穿。
- 历史检索：今天能抽，不是十年后图书馆还开着。官方把「此刻发布」和「以后还能借」写成两件事。

## 3. 对象

| 名字 | 是什么 | 不是什么 |
|---|---|---|
| DAS | 对方阵随机坐标要份额 + 证明 | 已经拿到自己的命名空间；编码已经诚实 |
| NMT 完备性 | 这一 namespace 的叶都给了，且对上头里的根 | 整块扩展方阵已经可用 |
| 行/列承诺 | 扩展方阵每一行、每一列各有一棵根，再收成头里的数据根 | 应用状态已经执行 |
| 错误编码欺诈证明 | 证明扩展与原数据对不上 | DAS 绿勾已经包含这条 |
| 诚实桥节点 | 能重建、能出欺诈证明的角色 | 任意 RPC |
| 历史检索 | 旧块还能被至少一方拿出 | 新块 DA；Celestia 已发永存激励 |
| celestia-app | 对 blob 数据无关的 PoS 应用 | 已经验过 / 存过租户字节 |

头里的数据根可以同时服务 DAS 和 NMT。一个根，两套问法。

---

## 4. 最小案例

租户 R 的批次进命名空间 N，和别的租户挤在同一块。

1. 共识 commit 了带数据根的头。这是排序，不是 R 已经结算，也不是方阵已经抽样。
2. R 的节点用 NMT 要 N。证明齐：N 的份额都在，对得上根。**别的命名空间此时仍可被扣。**
3. 轻钱包只做了 DAS：随机格子都答上了。它仍没有 N 的字节，除非再去取。
4. 出块者把扩展印错。抽样仍可能绿。没有诚实桥节点把错误扩展揭出来，原数据可以不可重建。
5. 一年后有人要重放 R。新块 DA 当时绿过，不是档案室已经付过钱。官方：这是检索，不是 DA。

「有头」「N 齐了」「抽过了」「历史还在」四盏灯，必须分开拨。

## 5. 五层

| 层 | 本页 |
|---|---|
| 密码学 | NMT 改的是带命名空间区间的哈希；纠删是编码，不是签名 |
| 协议 | DAS、NMT 完备性、错误扩展欺诈证明、历史 1-of-N 是四条假设 |
| 实现 | 抽样客户端必须真抽；NMT 验证必须看区间，不得只对叶 |
| 部署 | 日蚀可打断诚实桥；只连一家 RPC 不是已抽样 |
| 经济 | 永存检索要另找保管者；不要把「模块化 DA」写成已付档案费 |

**推断：** 产品句若只写「Celestia DA」，读者会把四问糊成一盏绿灯。  
**建议：** 不确定第一版不要先当别人的 DA 房东。结算轻客户端必须写：无体或不满足自己点名的那一问 ⇒ 不得显示最终。

## 7. 「不确定」测试句（建议）

```text
NMT 证明命名空间齐了 ≠ 扩展方阵已经可用
DAS 抽样过关 ≠ 已经拿到自己的 blob
DAS 抽样过关 ≠ 扩展编码已经诚实
未连诚实桥 / 被日蚀 ≠ 欺诈证明路径还在
新块 DA 绿 ≠ 历史已经有人存
celestia-app commit ≠ 应用已验 / 已存租户字节
头最终 ≠ 租户已经结算
```

语料：[C128](../../libraries/adversarial-corpus/README.md)。

## 精密检查

**边界：** 不讲 Reed-Solomon 多项式；不抄方阵边长 / 中间根个数 / 示例份额标签 / FAQ 百分比。Celestia 档案 §15 仍无官方主网七问，本页不编事故。不把 Matcha / mocha 升级当事故页。
