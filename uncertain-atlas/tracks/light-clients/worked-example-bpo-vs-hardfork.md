## 1. 核心问题

阿比看见一种「只改 blob 参数」的分叉，以为执行规则已经一起改了；或看见参数写在节点配置里，以为已经不需要分叉；或看见分叉摘要掺进了当前 blob 上限，以为分叉版本号已经换了；或看见规范编号 7892，以为就是 7691 那种常规分叉抬日程，或已经是 7918 底价，或已经是 PeerDAS。

官方句（事实）：

- EIP-7892：定义一种只改 blob 相关参数的专用硬分叉。改的是目标、上限、以及 blob 基础费怎么跟着超额调。
- 和常规硬分叉不同：常规硬分叉要大范围协调，还会带进更广的协议改动。本页这种分叉只动 blob 参数。
- 定义：只通过配置改这些参数，**不要求**客户端改代码。新参数在写明的激活时刻立刻生效。
- 常规硬分叉若也改这几项，必须往同一份 blob 日程配置里加一条。
- 执行层和共识层必须共用同一套这种专用分叉日程。两边对不齐，不是已经安全。
- 算分叉摘要时要把当前适用的 blob 上限算进去。可以先把这套机制铺上，同时还不改参数。
- 流言主题会因为摘要变了而跟着转。主题结构本身不改。
- 官方不选链上投票来改这些参数：那要更多代码、更多测试、还要争治理结构。本页是更简单、更可预期的一条路。
- 官方写：不引入向后兼容问题；没有点名安全风险。
- 规范**没有**把看见本页写成已经改了执行规则，也没有把配置里的日程写成已经不需要分叉，也没有把摘要掺进上限写成已经换了版本号，也没有把本页写成不变量 200、201 或 23。

只改 blob 参数、常规硬分叉、抽样方案，是三件事。

## 2. 直觉（ELI15）

图书馆只改「每天外借几本」这块牌子，不改借书法。  
牌子写在门口配置里，不是已经不用立法。  
门口印章换了一角，不是整座城改了年号。  
换牌子不是已经盖了新书库，也不是已经改了罚款公式。

| 名字 | 是什么 | 不是什么 |
|---|---|---|
| 只改 blob 的专用分叉 | 只动目标 / 上限 / 调价分母 | 已经改了执行规则 |
| 配置里的日程 | 参数写在节点配置 | 已经不需要分叉 |
| 摘要掺进上限 | 对等层域分离跟着当前上限走 | 已经换了分叉版本号 |
| 7892 | 改参数的专用分叉机制 | 7691 常规抬日程；7918 底价；PeerDAS |

## 4. 最小案例

一条 Ethereum 要对齐「这一口气 blob 容量在哪一层改」。

1. 看见只改 blob 参数的专用分叉。规范：只动目标、上限、调价分母。不是已经改了执行规则。
2. 看见参数写在配置里。规范：不要求改客户端代码。不是已经不需要分叉。
3. 看见分叉摘要掺进了当前上限。规范：对等层域分离跟着走。不是已经换了分叉版本号。
4. 看见官方不选链上投票。规范：那是另一条、更重的路。不是已经有治理。
5. 有人把这听成不变量 200。那是常规分叉里抬高目标/上限。本页是以后怎么只改这几项。
6. 有人把这听成不变量 201。那是执行费托住的底价。本页不改底价公式。
7. 有人把这听成不变量 23。那是抽样。本页不改抽样。

「看见 BPO = 已经改执行 / 配置里有日程 = 已经不用分叉 / 摘要变了 = 版本号已换 / 7892 = 7691」是假学习。

## 5. 五层

| 层 | 本页 |
|---|---|
| 密码学 | 摘要掺进上限是对等层域分离，不是已经换了签名方案 |
| 协议 | 必须点名问的是专用分叉、常规硬分叉，还是抽样 |
| 实现 | 执行层和共识层必须同一套日程；对不齐不是已经安全 |
| 部署 | 不把示例条数 / 激活时间抄进不确定 |
| 经济 | 不把「更能跟上需求」写成已经更安全 |

**推断：** 产品句若只写「blob 可以随时加容量」，读者会把专用分叉听成执行已经改了，或把配置听成已经不用分叉。  
**建议：** 第一版不要把短时 blob 当默认 DA。若对照，必须分开专用分叉、常规抬日程、底价、抽样。不要发明「看见 7892 就已经改了执行」。不要抄目标条数 / 上限条数。不要写怎样把两边日程对不齐。

## 6. 和另外几句不是同一句

1. **抬高日程 ≠ 已改气种**（不变量 200）：常规分叉里抬目标/上限。本页是以后怎么只改这几项。
2. **底价 ≠ 已并账**（不变量 201）：执行费托住的储备。本页不改底价公式。
3. **短时承诺 ≠ 永存 DA**（不变量 23）：抽样。本页不改抽样。
4. **对等窗 ≠ 已改共识**（不变量 207）：线协议历史窗。本页是 blob 参数专用分叉。

不要抄目标条数、上限条数、调价分母、激活时间、示例日程。不要写怎样把执行层和共识层的日程对不齐。不编博物馆页。不另写 19 节。不转示例配置。常规抬日程、底价、抽样、7840 日程对象是另一对象。日程精读：[`worked-example-blob-schedule-vs-4844.md`](worked-example-blob-schedule-vs-4844.md)（不变量 200）。
