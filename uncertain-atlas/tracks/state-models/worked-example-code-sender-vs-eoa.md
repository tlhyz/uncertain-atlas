# 工作实例：发送者已有代码不是已经能当 EOA 发交易

> **事实 / 推断 / 建议** 已分开。
> 对照：[L2.2](../../courses/level-02-state/L02-M02-account.md)、[L5.1](../../courses/level-05-ethereum/L05-M01-evm-and-gas.md)、[后来的自毁 ≠ 已删](worked-example-selfdestruct-vs-delete.md)、[chainId ≠ 已签](../crypto/worked-example-chainid-vs-signed.md)。
> 主文献：[EIP-3607](https://eips.ethereum.org/EIPS/eip-3607) Reject transactions from senders with deployed code。官方 EIP。不另写 19 节。
> 本页钉 **发送者已有代码 ≠ 已经能当 EOA 发交易**、**从该地址发出的交易 ≠ 已经合法**、**块里收了它 ≠ 块已经合法**、**RPC 模拟放行 ≠ 共识已经放行**。不抄碰撞工作量 / 空代码哈希 / 例钥。不写怎样找地址碰撞。

## 1. 核心问题

阿比看见一个地址能验出私钥，以为已经能当 EOA 发交易；或看见合约后来调过自毁，以为代码没了就能发；或看见 `eth_call` 放行，以为共识已经放行。

官方句（事实）：

- EIP-3607：不允许 `tx.sender` **已经部署了任何代码** 的交易。
- 发送者的代码哈希若不是空代码哈希，该交易**必须**判非法。客户端必须拒绝，不得收进块。含这种交易的块**必须**判非法。
- 规范把自己写成：澄清以前没写清的情况，而不是另起一套升级故事。过去默认「160 位地址够抗碰撞，这种情况不会发生」。
- 官方写：合约账户的行为应由合约代码约束，资金不应突然能被某把私钥花掉。
- 本页**没有**排除所有碰撞面，只挡最严重的那一种（已部署、看起来安全的合约，再用同一地址的 EOA 钥把钱花走）。规范另列了更难、收益更低的几种，不当成本页已经修完。
- 兼容节：客户端可以在 `eth_call` / `eth_estimateGas` 这类 RPC **关掉**本规则。那不是共识已经放行。
- 安全节：这是严格收紧：以前可能算合法的交易，现在非法。没有正当用例。可以当软分叉，因为新合法集是旧合法集的真子集。
- 规范**没有**把「能恢复出私钥」写成已经能发，也没有把后来的自毁写成已经变成 EOA，也没有把 RPC 模拟写成已经进块。

有代码、能恢复钥、RPC 绿勾，是三件事。

## 2. 直觉（ELI15）

门上挂了店规，店里的钱就只能按店规动。  
你就算另外配了一把外形一样的家门钥匙，也不能当店已经变成私宅。  
柜台后面的演习可以假装，不等于街上已经让你这样开门。

---

## 3. 对象

| 名字 | 是什么 | 不是什么 |
|---|---|---|
| 已部署代码的发送者 | `CODEHASH` 不是空；交易必须拒 | 已经是能发交易的 EOA |
| 空代码哈希 | 才允许当发送者 | 后来自毁已经清空（见 160） |
| 含该交易的块 | 必须非法 | 已经只是策略拒绝 |
| RPC 模拟放行 | 实现可选，方便多重签名预演 | 共识已经放行 |

---

## 4. 最小案例

一条以太坊要对齐「这一口气谁能当发送者」。

1. 地址上已有合约代码。规范：从它发出的交易必须拒；进块则块非法。
2. 同一地址能恢复出一把钥。规范：不能因此当 EOA 发。
3. 合约后来调过 `SELFDESTRUCT`（不变量 160）。非创建当笔不删代码。本页：代码还在，仍不能当发送者。
4. 有人把这听成签名没罩住链（不变量 161）。本页是发送者账户有没有代码，不是预像有没有 chainid。
5. 有人把这听成 OOG 空账户（不变量 103）。本页是故意拒有代码的发送者。
6. 钱包 `eth_call` 绿了。规范：RPC 可以关本规则。不是已经能进块。
7. 有人把「澄清」听成以前规范已经写死。官方：黄皮书没写清；本页才钉死。

「看见私钥对得上所以已经能发 / 自毁过了所以已经是 EOA」是假学习。

## 5. 五层

| 层 | 本页 |
|---|---|
| 密码学 | 能恢复钥 ≠ 协议允许该地址当发送者 |
| 协议 | 必须点名问的是发送者有没有代码 |
| 实现 | 验 nonce 之后查代码哈希；两客户端必须同拒 |
| 部署 | RPC 模拟可以关；共识不能关 |
| 经济 | 合约资金应按代码约束，不能突然被钥花掉 |

**推断：** 产品句若只写「有钥就能发」，读者会把合约地址听成 EOA。  
**建议：** 第一版必须拒「发送者已有代码」的交易。不要发明「地址长得像 EOA 就能发」。不要抄碰撞工作量。不要把 RPC 预演写成共识。

---

## 6. 和另外几句不是同一句

1. **后来的自毁 ≠ 已删**（不变量 160）：代码还在。本页：还在就不能当发送者。
2. **JSON chainId ≠ 已签**（不变量 161）：预像绑链。本页是发送者种类。
3. **OOG ≠ 空账户删除已回滚**（不变量 103）：失败路径。本页是准入。
4. **投票域**（不变量 6）：角色。本页是账户有没有代码。
5. **策略 ≠ 共识**（不变量 144）：本页是共识非法，不是本地策略。
6. **上限 ≠ 还能加**（不变量 175）：序号顶。本页是发送者种类。
7. **授权名单 ≠ 已委托**（不变量 190）：7702 只把有效委托指示加进可发起集合。指示不是已经解除 3607。本页仍是「任意其它代码不得发起」。

不要抄碰撞工作量 / 空代码哈希 / 例址 / 例钥。不要写怎样找碰撞或怎样在部署前诱转入金。不编博物馆页。不另写 19 节。256 位地址、RPC 预演细则、状态通道「先打款再部署」标成另一对象。EIP-7702 委托指示见不变量 190。

## 7. 「不确定」测试句（建议）

```text
发送者已有代码 ≠ 已经能当 EOA 发交易
从该地址发出的交易 ≠ 已经合法
块里收了它 ≠ 块已经合法
RPC 模拟放行 ≠ 共识已经放行
后来自毁 ≠ 已经变成可发送的 EOA
```

## 精密检查

**禁止假学习：** 「有钥 = 已经能发。」「自毁过了 = 已经是 EOA。」「`eth_call` 绿 = 已经能进块。」「澄清 = 以前已经写死。」  
**边界：** 不抄碰撞数字。不另写 19 节。不写怎样找碰撞。后来自毁见 **C164**。签名链绑定见 **C165**。委托指示见 **C194**。
