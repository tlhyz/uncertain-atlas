## 1. 核心问题

阿比看见「空账户」，以为状态里已经没有这个地址；或看见「死账户」，以为已经和「不存在」是同一个词；或看见规范编号 161，以为就是链绑定那一页，或已经是 2016 年 OOG 没撤回删除的那次分叉。

官方句（事实）：

- EIP-161：清状态树，且自称不打破若干不变量。
- **空**：没有代码，且 nonce 为 0，且余额为 0。
- **死**：不存在，或者空。两盏灯，不是一盏。
- **碰到**：卷入任何可能改状态的操作。官方写明：收一笔零值转账也算碰到。
- 任何账户都不得从不存在变成「存在但是空」。若某操作会变成这样，账户必须继续不存在。
- 一笔交易结束时，被碰到且现在是空的账户，必须变成不存在（删掉）。发生在自毁名单执行完之后、算收据状态根之前。
- 创建交易和 `CREATE`：跑初始化代码**之前**，先把 nonce 在正常起始值之上再加一。官方写：避免「刚创建到一半就被收割」这种怪相。
- 新建账户那笔气：以前目的地不存在就收；本页改成只在**转账大于 0 且目的地是死的**时收。
- 2017 补记：状态回滚时，空账户删除也必须回滚。那是不变量 103 的分叉，不是本页已经在讲 journaling。
- 规范**没有**把「空」写成已经不存在，也没有把「碰到」写成已经付过钱，也没有把本页写成链绑定或不变量 103。

空、不存在、死，是三件事。

## 2. 直觉（ELI15）

户口本上有一页，三项都是零，不是已经把这一页撕掉。  
「没这个人」和「有一页但是空的」可以都被叫做「死」，不是已经同一种灯。  
有人路过门牌号、哪怕没塞钱，也算碰到了这一页。交易结束若仍是空页，才撕掉。

---

## 3. 对象

| 名字 | 是什么 | 不是什么 |
|---|---|---|
| 空 | 无代码、nonce 0、余额 0 | 已经不存在 |
| 不存在 | 状态里没有这一户 | 已经是空；已经是死的唯一含义 |
| 死 | 不存在，或空 | 已经一种对象 |
| 碰到 | 卷入可能改状态的操作，含收零值 | 已经付过钱；已经创建 |

---

## 4. 最小案例

一条 Ethereum 要对齐「这一口气账户卡在哪」。

1. 地址三项都是零。规范：空。不是已经不存在。
2. 状态里没有这一户。规范：不存在。不是已经是空。
3. 死 = 上面两种之一。规范：两盏灯。不是已经同一种。
4. 收了一笔零值。规范：算碰到。不是已经付过钱。
5. 某操作会从不存在变成「存在但是空」。规范：必须继续不存在。
6. 交易结束，被碰到且现在空。规范：变成不存在。不是已经是 103 那次漏撤。
7. 有人把规范编号 161 听成不变量 161。那是签名里的链绑定。本页是账户空不空。
8. 有人把这听成后来自毁（不变量 160）。那是以后只转余额。本页是空 / 不存在 / 死。

「空 = 已经没了 / 死 = 一种对象 / 161 = 链绑定 / 161 = 103」是假学习。

## 5. 五层

| 层 | 本页 |
|---|---|
| 密码学 | 无新原语 |
| 协议 | 必须点名问的是空、不存在，还是死 |
| 实现 | 两家必须同一套：空的三项、碰到含零值、存在但是空不得出现 |
| 部署 | 网络升级；补记回滚删除是另一页 |
| 经济 | 不抄新建账户气价；零值碰到不是已经转过账 |

**推断：** 产品句若只写「空账户会清掉」，读者会把空听成已经不存在，或把碰到听成已经付过钱。  
**建议：** 第一版若自动删空账户，必须分开空、不存在、死，并写清碰到含不含零值。不要发明「空 = 已经没了」。不要抄分叉高度。不要把规范 EIP-161 写成不变量 161。

## 6. 和另外几句不是同一句

1. **OOG ≠ 空户已回滚**（不变量 103）：失败时删除撤没撤干净。本页是空 / 不存在 / 死三盏灯。
2. **自毁 ≠ 已删**（不变量 160）：后来只转余额。本页不是自毁指令。
3. **上限 ≠ 还能加**（不变量 175）：序号顶。本页创建前先加 nonce，不是上限。
4. **chainId ≠ 已签**（不变量 161）：签名链绑定。编号碰巧都叫 161，不是同一页。

不要抄分叉高度 / 新建账户气价 / 链号 / 例账户。不要写怎样碰一下清户，或怎样造存在但是空的账户。不编博物馆页。不另写 19 节。2016-11 OOG 分叉、后来自毁、链绑定是另一对象。

## 精密检查

**禁止假学习：** 「空 = 已经没了。」「死 = 一种对象。」「零值转账 = 已经付过钱。」「161 = 103。」「规范 161 = 不变量 161。」  
**边界：** 不抄分叉高度。不另写 19 节。不写怎样清户。OOG 漏撤见不变量 **103**。链绑定见 **C165**。
