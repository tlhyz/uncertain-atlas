# 工作实例：后来的 SELFDESTRUCT 不是账户已经删掉

> **事实 / 推断 / 建议** 已分开。
> 对照：[L2.2](../../courses/level-02-state/L02-M02-account.md)、[L5.1](../../courses/level-05-ethereum/L05-M01-evm-and-gas.md)、[瞬时 ≠ 持久](worked-example-transient-vs-storage.md)、[OOG ≠ 空账户删除已回滚](../failure-museum/ethereum-2016-11-oog-empty-account.md)。
> 主文献：[EIP-6780](https://eips.ethereum.org/EIPS/eip-6780) SELFDESTRUCT only in same transaction。官方 EIP。不另写 19 节。
> 本页钉 **后来的 SELFDESTRUCT ≠ 账户已经删掉**、**只转走余额 ≠ 代码和存储已经清**、**同笔创建再销毁 ≠ 以后任意一笔还能拆户**、**自己当收款人 ≠ 已经烧掉**。不抄气价 / 退款。不写怎样用 CREATE2 重占地址或怎样烧币。

## 1. 核心问题

阿比看见合约调了 `SELFDESTRUCT`，或看见余额转到了目标，以为账户已经拆掉；或看见规范写「同笔创建仍按旧行为」，以为以后任意一笔还能拆户；或看见自己当收款人，以为币已经烧掉。

官方句（事实）：

- EIP-6780：改 `SELFDESTRUCT` 的功能。新功能**只把账户里全部 Ether 送给目标**；**只有**在创建该合约的**同一笔交易**里调用，才保留旧行为。
- **不是**创建当笔：当前执行帧停。不删除任何数据（含存储键、代码、账户本身）。把全部余额转给目标。目标若是自己，余额净变化为零；与旧规范不同，这时**不会**烧币。
- **就是**创建当笔：继续按该 EIP 之前的行为，包括删除数据、转走余额、再把调用者账户余额置 0。目标若是自己，币**会**烧掉。
- 合约被视为创建：从一笔创建交易开始，或从 `CREATE` / `CREATE2`（以及以后部署合约的同类操作）开始执行。新地址上若已有余额，仍算合约创建。
- 该操作码仍按 EIP-6049 **弃用**。即使考虑了新行为，新部署合约也强烈不建议再用；以后的 EVM 还可能再收紧。
- 兼容节：依赖 `CREATE2` 在 `SELFDESTRUCT` 之后、**同一地址再部署**的合约，若创建后没有在**同一笔**里调用 `SELFDESTRUCT`，将不再按预期工作。
- 规范**没有**把后来的 `SELFDESTRUCT` 写成已经删账户，也没有把转走余额写成代码已经清，也没有把「同笔仍能拆」写成以后任意一笔还能拆。

转走余额、删账户、同笔创建拆户，是三件事。

## 2. 直觉（ELI15）

搬家当天把新房拆掉，木头还能清走。  
房子已经住了几年再喊拆，只准把桌上的现金拿走，墙和房契还在。  
把现金塞回自己口袋，不是钱已经扔进火里。

看见现金被拿走，不是房子已经没了。

## 3. 对象

| 名字 | 是什么 | 不是什么 |
|---|---|---|
| 后来的 `SELFDESTRUCT` | 停本帧；转走全部余额；不删数据 | 账户已经删；代码已经清；已经烧掉 |
| 同笔创建再销毁 | 仍按旧行为删数据 | 以后任意一笔还能拆户 |
| 自己当收款人（非创建当笔） | 余额净零；不烧 | 已经销毁供给 |
| `CREATE2` 再占同址 | 旧用法：拆完再部署 | 没有同笔拆就还能重占 |

---

## 4. 最小案例

一条以太坊要对齐「这一口气账户还在不在」。

1. 旧合约后来调 `SELFDESTRUCT`。规范：钱走了；代码和存储还在；账户还在。
2. 同一笔里 `CREATE` 再立刻销毁。规范：仍按旧行为删。
3. 有人把「钱走了」听成供给已经少（不变量 2）。非创建当笔、自己当收款人：规范写不烧。
4. 有人把这听成 OOG 空账户删除回滚（不变量 103）。本页是故意改寿命，不是失败路径漏撤。
5. 有人把这听成瞬时店没进账户（不变量 159）。本页是账户本身删不删，不是第三本账。
6. 有人把委托调用听成预编译信任（不变量 119）。本页不解释谁被当成调用者。
7. 有人把这听成还能用 `CREATE2` 当升级。规范：没有同笔拆就不再按预期工作。

「看见 SELFDESTRUCT 所以账户已经没了 / 钱走了所以代码已经清」是假学习。

## 5. 五层

| 层 | 本页 |
|---|---|
| 密码学 | 不决定账户寿命 |
| 协议 | 必须点名问的是转余额、删账户，还是同笔创建拆户 |
| 实现 | 两客户端必须同：非创建当笔不得删数据 |
| 部署 | 操作码已弃用；新合约强烈不建议再用 |
| 经济 | 转走 ≠ 烧掉；拆户 ≠ 已经能同址再部署 |

**推断：** 产品句若只写「有自毁」，读者会把后来的转账听成账户已经拆。  
**建议：** 第一版可以不上自毁指令。若做账户删除，必须写清是创建当笔拆户，还是以后只准转余额。不要发明「`SELFDESTRUCT` = 账户已经没了」。

## 6. 和另外几句不是同一句

1. **OOG ≠ 空账户删除已回滚**（不变量 103）：失败路径怎么撤。本页是操作码寿命被改。
2. **瞬时 ≠ 持久**（不变量 159）：第三本账。本页是账户还在不在。
3. **供给守恒**（不变量 2）：非创建当笔自己收款不烧。
4. **委托语义 ≠ 预编译信任**（不变量 119）：谁是调用者。本页不解释。
5. **`store` ≠ 顶层**（不变量 151）：Move 能力。本页是 EVM 账户删除。

不要抄气价 / 退款 / 访问列表热冷。不要写怎样用 CREATE2 重占地址或怎样烧币。不编博物馆页。不另写 19 节。EIP-6049 弃用细则、EIP-3529 退款表、EIP-2929 访问列表、ERC-2535 代理、Verkle 账户键布局标成另一对象。

## 精密检查

**禁止假学习：** 「`SELFDESTRUCT` = 账户已经没了。」「钱走了 = 代码已经清。」「同笔还能拆 = 以后还能拆。」「自己当收款人 = 已经烧掉。」  
**边界：** 不讲某一硬分叉的气价表。不另写 19 节。不写怎样重占地址。瞬时店见 **C163**。空账户回滚见不变量 103。
