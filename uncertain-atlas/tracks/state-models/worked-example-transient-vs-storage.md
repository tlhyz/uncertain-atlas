# 工作实例：瞬时存储不是已经进了账户

> **事实 / 推断 / 建议** 已分开。
> 对照：[L2.2](../../courses/level-02-state/L02-M02-account.md)、[L5.1](../../courses/level-05-ethereum/L05-M01-evm-and-gas.md)、[内层改过 ≠ 外层已经看见](../failure-museum/asa-2026-002.md)、[谓词 ≠ 脚本](../parallelism/worked-example-utxo-access-list.md)。

## 1. 核心问题

阿比看见合约写了 `TSTORE`，或本笔稍后还能 `TLOAD` 读到，以为已经写进账户；或看见规范写「交易结束丢掉」，以为本笔里从未存在；或把它听成 memory，以为一帧返回就清空。

官方句（事实）：

- EIP-1153：增加操作瞬时状态的指令。这份状态**行为几乎与 storage 相同**，但**每笔交易结束后丢掉**。
- 瞬时存储的值**从不**从持久存储反序列化进来，也**从不**序列化出去。因此更便宜：从不要求磁盘访问。
- 寻址与 `SLOAD` / `SSTORE` 相同：每个地址指向一个字。
- **一笔交易结束，瞬时存储里所有值都丢掉。**
- 瞬时存储**私有**于拥有它的合约，和持久存储一样。只有该合约自己的帧能访问。同一合约的**所有帧共用同一份**瞬时店，和持久存储一样，**和 memory 不一样**。
- `DELEGATECALL` / `CALLCODE`：拥有者是发出委托的合约（调用方），与持久存储相同。`CALL` / `STATICCALL`：拥有者是被调合约。
- 一帧 revert：从进入该帧到返回之间的瞬时写入全部撤回，包括内层调用。这**模仿**持久存储。
- `STATICCALL` 里 `TSTORE` 必须异常；`TLOAD` 允许。
- 规范注释：用「交易标识 + 普通 storage」**不能**代替本页；两特征正交。
- 安全节：瞬时存储**不是**在一次调用返回或 revert 时像 memory 那样丢掉。交易结束才清。
- 规范**没有**把 `TSTORE` 写成已经进账户，也没有把「交易结束丢掉」写成本笔里从未存在，也没有把共用一份瞬时店写成 memory。

瞬时存储、持久存储、memory，是三件事。

## 3. 对象

| 名字 | 是什么 | 不是什么 |
|---|---|---|
| 瞬时存储 | 本笔内、按合约私有的字地址店；交易结束丢掉 | 已经进账户；已经跨笔 |
| 持久存储 | 账户上的 `SSTORE` 店；要落盘 | 已经等于 `TSTORE`；已经更便宜所以同一对象 |
| memory | 单帧线性内存；返回即丢 | 同合约各帧共用；交易级映射 |
| 帧 revert | 撤回本帧及其内层的瞬时写入 | 已经提交；已经像 memory 只清本帧、外层看不见 |

---

## 4. 最小案例

一条以太坊要对齐「这一口气写到哪本账」。

1. 合约做了 `TSTORE`。规范：本笔里能读；交易结束丢掉；不进持久存储。
2. 同一合约稍后被再进入。规范：各帧看见同一份瞬时店，不是每人一份 memory。
3. 内层调用 revert。规范：那一段瞬时写入撤回，像持久存储的回滚，不是已经落盘。
4. 有人把这听成「storage 退款做完了瞬时用例」（不变量 103 的亲戚 / EIP-3529）。规范：本页是另一套指令，不走退款计数器。
5. 有人把这听成内层模块状态外层已经看见（不变量 118）。本页是 EVM 瞬时店与持久店，不是跨模块提交可见性。
6. 有人把这听成 Fuel 脚本没有持久存储（不变量 143）。本页是账户合约上的第三本账，不是 UTXO 脚本。
7. 有人把委托调用听成预编译信任已经改过（不变量 119）。本页只钉瞬时店的拥有者跟持久存储走同一套调用者规则。

「看见 `TSTORE` 所以账户已经改了 / 下课要擦所以这节课没写过」是假学习。

## 5. 五层

| 层 | 本页 |
|---|---|
| 密码学 | 不决定寿命 |
| 协议 | 必须点名问的是瞬时店、持久店，还是 memory |
| 实现 | 本笔内要能按帧回滚；两客户端必须同 |
| 部署 | 旧合约行为不变；这是新指令 |
| 经济 | 更便宜 ≠ 已经是同一对象；交易结束丢掉 ≠ 本笔里免费无界 |

**推断：** 产品句若只写「有瞬时存储所以不用落盘」，读者会把本笔还活着的值听成从未存在，或把共用一份店听成 memory。  
**建议：** 第一版可以不上瞬时存储指令。若做交易级草稿，必须写清问的是单帧 memory、本笔合约店，还是账户持久店。不要抄气价。不要发明「`TSTORE` = 已经进账户」。

## 6. 和另外几句不是同一句

1. **OOG ≠ 空账户删除已回滚**（不变量 103）：失败路径怎么撤持久改动。本页是另一本账的寿命。
2. **内层改过 ≠ 外层已经看见**（不变量 118）：跨模块提交可见性。本页是同一 EVM 合约的瞬时店。
3. **委托语义 ≠ 预编译信任**（不变量 119）：谁被当成调用者。本页只借用「拥有者跟持久存储走同一规则」。
4. **脚本没有持久存储**（不变量 143）：Fuel 一次性脚本。本页是账户合约的第三本账。
5. **`store` ≠ 顶层资源**（不变量 151）：Move 能力。本页是 EVM 字地址店的寿命。

不要抄操作码号 / 气价 / 退款比例 / 津贴。不要写怎样灌瞬时槽、怎样留未清的重入锁。不编博物馆页。不另写 19 节。EIP-2200 / EIP-3529 退款表、Solidity `transient` 限定符、CREATE2 工厂读参、临时授权模式标成另一对象。

## 精密检查

**禁止假学习：** 「`TSTORE` = 已经进账户。」「交易结束丢掉 = 本笔里从未存在。」「瞬时 = memory。」「更便宜 = 同一对象。」  
**边界：** 不讲某一硬分叉的气价表。不抄操作码号。不另写 19 节。不写怎样灌槽。退款规则见 EIP-3529，标成另一对象。委托拥有者规则见不变量 119，只借用「跟持久存储同一套」。
