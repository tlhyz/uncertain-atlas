# 协议档案模板

复制到 `protocols/<name>/report.md`。节标题不要改。

每节结尾能标的标：**事实 / 推断 / 建议**。

1. 一句话定义
2. 它解决的问题
3. 架构图（mermaid 或 ASCII）
4. 一笔交易完整生命周期
5. 状态模型
6. 共识
7. 执行
8. 网络
9. 存储
10. 密码学 primitive
11. 安全假设（假设失效则什么失效）
12. 最大结构性优势（只找结构性的）
13. 最大具体缺陷
14. Trade-off（每个优势问：拿什么换的）
15. 历史事故（原始出处）
16. 源码入口（1 / 2 / 3）
17. 关键函数（输入 → 逻辑 → 输出 → invariant）
18. 如何测试核心协议
19. 「不确定」适用性四档
