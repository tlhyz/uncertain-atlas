# 协议档案轨

一条链一份档案，**固定 19 节**，禁止各自发明目录。

课程讲原理。这里讲「这个项目具体怎么选、付了什么代价」。

## 19 节

1. 一句话定义（禁止营销）
2. 它解决的问题
3. 架构图
4. 一笔交易完整生命周期
5. 状态模型
6. 共识
7. 执行
8. 网络
9. 存储
10. 密码学 primitive
11. 安全假设
12. 最大结构性优势
13. 最大具体缺陷
14. Trade-off
15. 历史事故
16. 源码入口（第 1 / 2 / 3 份）
17. 关键函数
18. 如何测试核心协议
19. 「不确定」：强烈建议 / 可以参考 / 暂时不需要 / 不建议采用
