# SOXL 网格回测 — 使用注意事项

优化后的脚本已经在私有库 `tlhyz/gate-grid-martingale`（分支 `cursor/unified-tech-crypto-framework-cbaf`，PR #8）。  
**逐笔 CSV 故意不在 git 里**（大约 3 GB），只留本机 `cache/`。

这份是开跑前必看的。看板结论见 [`README.md`](README.md)，改参步骤见 [`scripts/README.md`](scripts/README.md)。

---

## 1. 先搞清这是什么、不是什么

- 这是 **Binance UM `SOXLUSDT` 历史回测**，不是实盘下单，也不是 Gate 撮合。
- 默认按你的规则：5x 逐仓、200 格等差、移动带宽、多 5k + 空 5k。
- **不要拿回测数字去实盘。** 已跑过的全窗结论：独立多空 FAIL（多头爆、空头裸奔）；移动对冲在 **2026-07-28 停机**，后面 45 天 `daily_pnl=0` 是空仓，不是对冲还在赚钱。
- `+15.6% / −6.0%` 好看，是因为停在空头赚钱那天。不是撑满 58 天的对冲。

## 2. 逐笔为什么没推、换机器怎么办

| 在 git 里 | 不在 git 里 |
|-----------|-------------|
| 脚本、YAML、复核日志、日收益 CSV/JSON | `cache/binance_futures_SOXLUSDT_aggTrades_*.csv`（约 3 GB） |

原因：仓库 `DATA_POLICY` 禁止原始行情入库；单日文件也能到十几 MB；数据在 Binance Vision 上可重下。

换一台机器：

```bash
git clone git@github.com:tlhyz/gate-grid-martingale.git
cd gate-grid-martingale
git checkout cursor/unified-tech-crypto-framework-cbaf

# 只下 SOXL 上市日后的逐笔（2026-05-15 起；再早 Vision 404）
python3 scripts/download_soxl_listing_prefix.py
python3 soxl-lab/scripts/run_grid.py --list-cache
python3 soxl-lab/scripts/run_grid.py --check
```

`--list-cache` 必须看到窗口里的天都在，再 `--check`，再开跑。缺天默认 **拒绝**，不要加 `--allow-empty-ticks`。

## 3. 每次改参的正确顺序

```bash
# ① 看本机有哪些天
python3 soxl-lab/scripts/run_grid.py --list-cache

# ② 改 params/run.yaml，或只在命令行盖一层
# ③ 先检查，不跑引擎
python3 soxl-lab/scripts/run_grid.py --check

# ④ 确认 fills: tick 再跑（结论用逐笔）
python3 soxl-lab/scripts/run_grid.py
```

全窗逐笔（几十天 × 每天几十万笔）会跑很久。先用 `--fills bar --start … --end …` 试参数，**数字不要当结论**。

## 4. 参数怎么改、哪些会踩坑

改 [`params/run.yaml`](params/run.yaml)。命令行同名参数覆盖 YAML。

| 项 | 注意 |
|----|------|
| `range.mode: usdt` + `usdt: 20` | **±20 USDT**，不是 ±20% |
| `mode: pct` + `pct: 0.20` | 才是 ±20%。`0.20` 不是 20 |
| `hedge: flatten_survivor` | 你的「移动 + 多空对冲」。一边爆仓就平另一边并停 |
| `hedge: independent` | 两本独立账。多头爆了空头继续裸奔（P7-05 那种） |
| `hedge: restart_survivor` | 爆仓后用**剩余权益**对半再开。P7-19 三次爆仓、期末库存 14 倍，**不要用** |
| `--sides long` / `short` | 只做一边，不是对冲 |
| `fee: base` | 2 bps。要更苛刻用 `conservative`（4 bps） |
| `fills: tick` | 结论必须用这个 |
| `fills: bar` | 影线会虚高，P7-03 的 +18.8% 已被推翻 |
| `n_grids` | 必须 ≥ 2 |
| 起止日 | UTC 日历日；必须 `start ≤ end`；且 cache 里天天有文件 |
| `01_yours_moving_grid.yaml` | 底稿，也能 `--config`；`fills: tick_precise_aggTrades` 会被当成 tick |

`--capital 3000` 会 **同时** 改多空两边。只改一边用 `--capital-long` / `--capital-short`。

## 5. 怎么读结果（最容易误读的地方）

输出目录：`soxl-lab/results/runs/<对冲_带宽_杠杆_格数_本金_成交_起止日>/`

先看 `README.md`，再看 `daily.csv`。

- `pair_stopped: true`：策略已经停。后面一长串收益为 0 是空仓。
- `liquidated_long` / `liquidated_short`：爆仓那一边权益清零。
- `zero_days` 很多：先对一下停机日期，不要当成「很稳」。
- 短窗（1～3 天）的 +4%、+1% **不能**外推到全窗。
- 目录名带窗口，换日期不会覆盖上一次；自己跑的结果默认不入库（`results/runs/` 已 gitignore）。

不要和这些数字混在一起：

| 数字 | 为什么不能当「你的网格」 |
|------|--------------------------|
| 同标 L+S +12.3% / −17.7% | 空腿是 K 线，不是逐笔 |
| SOXL+SOXS −6.0% | 价格反向 ≠ 网格对冲 |
| 日频 50/50 +2.9% | 没有网格 |
| BAR +18.8% | 已推翻 |

## 6. 数据边界

- SOXLUSDT Vision **最早 2026-05-15**。2024、2025 不是没下，是交易所没有。
- 本机全量（写这篇时）：2026-05-15 → 2026-09-11，120 天无缺口。
- 没有 1h K 线缓存时，脚本会从逐笔重采样 1h；要强制重采样用 `--bars-from-ticks`。
- 默认 **cache_only**，不会偷偷去外网补 tick。K 线也优先用本地。

---

## 7. 明确不要做的事

1. 不要 `git add cache/` 或任何 `aggTrades_*.csv`。
2. 不要用 `--allow-empty-ticks` 硬跑缺天窗口。
3. 不要把 `bar` 结果写进结论。
4. 不要把停机之后的空仓天数算进「对冲胜率」。
5. 不要和 SOXS / SNXX / BTC 账本混在同一份 YAML 里跑这个入口。
6. 不要把研究模板 `params/02_research_atr.yaml` 当成你的 5x/200 格。

## 8. 以后要改什么（可扩展）

默认这套（5x / 200 格等差 / ±20U / remap 重锚 / flatten_survivor）**不改代码也能换**。调度和引擎是分开的：数字走 YAML，规则走注册表。

| 你要改的 | 怎么改 | 不用动 |
|----------|--------|--------|
| 杠杆、格数、±U / ±%、本金、窗口、tag、手续费 | 改 `params/run.yaml` 或命令行 | 引擎 |
| 一次试好几组 | `--sweep soxl-lab/params/sweep.yaml` | 引擎 |
| 换 cache 里已有的合约 | `--symbol SOXSUSDT` | 引擎 |
| 只做多 / 只做空 | `--sides long` | 引擎 |
| 每格名义（均仓 / 马丁 / 固定 U） | `sizer: equal\|martingale\|fixed` + `--set martingale_ratio=1.3` | 成交循环 |
| 命令行临时加一个键 | `--set 键=值`（进 extras） | YAML |
| 新的对冲停机规则 | `soxl-lab/extensions/xxx.py` 里 `register_hedge` | `soxl_grid_cli.main` |
| 新的格子排法 | `register_grid_kind("名字", fn)` | `user_levels` 本体 |
| 新的带宽（不是 ±U / ±%） | `register_range("名字", fn)` | 调度 |
| 新的走出带策略 | `register_reanchor("名字", fn)` | 调度 |
| 新的每格仓位公式 | `register_sizer("名字", fn)` | `_dir_pending` |
| YAML 里多一个自己的键 | 进 `extras`（`register_yaml_keys` 只是去掉「未登记」提示，**不会从 extras 删掉**） | — |

```bash
python3 soxl-lab/scripts/run_grid.py --list-extensions
python3 soxl-lab/scripts/run_grid.py --sweep soxl-lab/params/sweep.yaml --check
python3 soxl-lab/scripts/run_grid.py --sizer martingale --set martingale_ratio=1.3 --check
```

`--check` 把 extras 分成两类：已 `register_yaml_keys` 的「插件键」和「未登记」。**两类都会传给引擎/插件**，未登记只是提示你可能写错了名字。调度自己不读未登记键。

新对冲函数签名对齐 `run_user_hedge_pair(bars, **engine_kwargs)`（含 `extras`、`sizer`）。模板：[`extensions/_template_hedge.py`](extensions/_template_hedge.py)。说明：[`extensions/README.md`](extensions/README.md)。

还没有插件接口的：新成交模型（不是 tick/bar）。那要改引擎。

## 9. 出问题对照

| 现象 | 原因 / 处理 |
|------|-------------|
| `找不到配置` | 在仓库根目录跑，或给 `--config` 绝对路径 |
| `窗口缺逐笔 N 天` | `--list-cache`；缺的天重新下载 |
| 结果跑到奇怪目录 | 用 `soxl-lab/scripts/run_grid.py` 或根目录 `scripts/run_soxl_grid.py`，不要拷贝单文件到别处 |
| `--help` | 可用；带宽说明里的 % 已转义 |
| 独立账进度日期走两遍 | 先整段多头、再整段空头，正常 |
| 想只要 8 月 | `--start 2026-08-01 --end 2026-08-31 --tag aug` |
