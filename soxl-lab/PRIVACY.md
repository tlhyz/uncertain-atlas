# Privacy / private-lab rules

This folder is the **SOXL-only personal lab**. It is not a public product.

- No API keys, no exchange accounts, no personal identifiers.
- Tick CSVs stay on the machine (`cache/` of the research checkout). Never commit them.
- Do not add SNXX, BTC, ETH, SOL, or SOXS raw ticks here.
- Pair-grid JSON is kept only as a FAIL control; this is not a SOXS book.
- To host as a **private GitHub repo**, see `EXTRACT_PRIVATE_REPO.md`.

This environment cannot create that private remote (`gh` is read-only).
