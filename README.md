# 不确定图谱 · Uncertain Atlas

全球区块链架构图谱，也是「不确定」链的设计参考库。

用来把一条链从钱包到最终确认讲清楚，并给「不确定」的后量子结算设计攒可对照的材料。  
不是交易软件，没有网格、马丁、回测或下单。
